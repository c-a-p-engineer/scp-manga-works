## 今後決める項目

- 呼称、年齢、性別、性格、主人公との関係
- 外見（髪・目・服装・体格）、勤務時の服装ルール
- 主要人物それぞれの通常時の話し方・リアクション
- 漫画生成で使うCharacter Sheetと参照パス
- 話をまたぐ小物・衣装・関係性の変化

## 画像一貫性

同じ人物を別人として生成しないよう、確定後に参照画像と服装状態を管理します。人物の外見・意図の正本と、ページごとのポーズ・コマ割り指定は混同しません。
