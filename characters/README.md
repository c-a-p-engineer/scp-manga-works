# 登場人物・固定キャスト

固定キャストの**呼称・主要属性**をここで管理します。主人公・主任・エージェントは共通して重度の喫煙者であり、全員がそれぞれの分野で非常に優秀です。

> **確定**：ユーザー指定の要素と呼び名。**仮**：提案段階の姓名の未指定部分、細部の容姿、年齢の正確な数字。仮設定を承認なしで確定にしないこと。

## CHAR-003 — 峰

- 女性、40歳前後。**成熟した美貌と、現場の実績を持つ優秀なエージェント**
- 銘柄は**峰（ミネ）**。名字・作中での呼称ともに**峰**
- 高難度の任務や現場対応に強いが、任務中は喫煙できない状況が多い
- そのため、**吸える研究室を居心地のよい拠点**として大切にしている
- 研究者2人にはない現場視点・即応能力を持つ。静かな物腰と容赦ない仕事ぶりを両立
- **行動原理**：現場を無事に終わらせ、馴染みの仲間と一服できる場所へ戻る
- 下の名「紫乃」は暫定候補。髪型・服装・口調は未決

## 人間関係の中核

- **バット ↔ セッター**：研究能力を認める師弟。仕事を減らしたい新人と、仕事を抱え込む主任の対照性で笑いを作る
- **バット ↔ 峰**：研究室と現場で異なる専門性を持つ。喫煙仲間でありつつ、危険時は峰が新人を守る
- **セッター ↔ 峰**：互いの能力を知る古参の仕事仲間。研究判断と現場判断の違いがドラマを作る

## 作中の喫煙ルール

喫煙を全エリアで許される万能設定にはしない。**認可された喫煙可能区画と収容区画を区別**し、オブジェクトごとの収容手順が優先される。吸えない状況での3人の不満・工夫・会話がコメディの材料になる。現実の喫煙の健康影響を否定する設定ではない。

## 画像一貫性

名前・呼称・衣装の変更履歴を話数間で管理する。**バット・セッターの個別Character Sheetは作成済み**。人物同一性の正規基準画像は [バット](assets/CHAR-001_BAT_reference-v1.png) と [セッター](assets/CHAR-002_SETTER_reference-v1.png)。必要に応じて角度別の補助画像も使う。各話の生成でこれらの画像実体を紐付ける。髪・目・体格などの固定特徴と、場面に応じた服装状態を区別する。
