# 登場人物・固定キャスト

固定キャストの**呼称・主要属性**をここで管理します。主人公・主任・エージェントは共通して重度の喫煙者であり、全員がそれぞれの分野で非常に優秀です。

> **確定**：ユーザー指定の要素と呼び名。**仮**：提案段階の姓名の未指定部分、細部の容姿、年齢の正確な数字。仮設定を承認なしで確定にしないこと。

## CHAR-001 — バット

- 女性、20代前半、身長約150cm、**金髪・赤目**（確定）
- 優秀な研究者。重度の愛煙家で、とくに**ゴールデンバット**を好む
- 財団スカウトへの承諾理由に、**喫煙できる環境があること**が大きく関わる
- 基本的に怠惰。**楽をするためには勤勉を厭わず、面倒を減らすために仕事を極限まで効率化する**
- 本人の白衣や髪に紙巻きタバコの強い匂いが染みついている
- 低身長の理由を周囲が喫煙に結びつけてからかう、という**作中の噂**は可能。ただし医学的事実・成長停止の確定原因にはしない
- **行動原理**：一刻も早く仕事を終えて、好きな時間に一服してだらけたい。危機には高い実力で対応する
- 外見の未決事項：髪型・仕事着の詳細・表情の通常状態
- 本名候補：**Goldie Bateman（ゴールディ・ベイトマン）**。英語名としての自然さと、姓の `Bat` を両立する案

- 激務の中でタバコが研究の能率を上げると**本人は信じている**。実際の認知能力への効果を作品の客観的事実にはしない

## 人間関係の中核

- **バット ↔ セッター**：研究能力を認める師弟。仕事を減らしたい新人と、仕事を抱え込む主任の対照性で笑いを作る
- **バット ↔ 峰**：研究室と現場で異なる専門性を持つ。喫煙仲間でありつつ、危険時は峰が新人を守る
- **セッター ↔ 峰**：互いの能力を知る古参の仕事仲間。研究判断と現場判断の違いがドラマを作る

## 作中の喫煙ルール

喫煙を全エリアで許される万能設定にはしない。**認可された喫煙可能区画と収容区画を区別**し、オブジェクトごとの収容手順が優先される。吸えない状況での3人の不満・工夫・会話がコメディの材料になる。現実の喫煙の健康影響を否定する設定ではない。

## 画像一貫性

名前・呼称・衣装の変更履歴を話数間で管理し、確定後に必要なCharacter Sheetを追加する。髪・目・体格などの固定特徴と、場面に応じた服装状態を区別する。
