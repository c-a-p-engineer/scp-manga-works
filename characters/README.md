# 登場人物・固定キャスト

固定キャストの**呼称・主要属性**をここで管理します。主人公・主任・エージェントは共通して重度の喫煙者であり、全員がそれぞれの分野で非常に優秀です。

> **確定**：ユーザー指定の要素と呼び名。**仮**：提案段階の姓名の未指定部分、細部の容姿、年齢の正確な数字。仮設定を承認なしで確定にしないこと。

## 人間関係の中核

- **バット ↔ セッター**：研究能力を認める師弟。仕事を減らしたい新人と、仕事を抱え込む主任の対照性で笑いを作る
- **バット ↔ 峰**：研究室と現場で異なる専門性を持つ喫煙仲間。危険時は峰が情報収集と予防・撤収判断で新人を守る
- **セッター ↔ 峰**：互いの能力を知る古参の仕事仲間。研究判断と現場判断の違いがドラマを作る

## 作中の喫煙ルール

喫煙を全エリアで許される万能設定にはしない。研究室に**隣接する専用喫煙室**と研究区画を分離し、研究室の**出入口にエアシャワー**を設置。白衣等は常に清潔に管理する。オブジェクトごとの収容手順が優先される。吸えない状況での3人の不満・工夫・会話がコメディの材料になる。現実の喫煙の健康影響を否定する設定ではない。

## 画像一貫性

名前・呼称・衣装の変更履歴を話数間で管理する。**バット・セッター・峰の個別Character Sheetを作成済み**。人物同一性の参照は [バット](assets/CHAR-001_BAT_reference-v1.png)、[セッター](assets/CHAR-002_SETTER_reference-v1.png)、[峰](assets/CHAR-003_MINE_reference-v1.png)。峰の喫煙状態は[別画像](assets/CHAR-003_MINE_smoking-v1.png)で補助する。必要に応じて角度別の補助画像も使う。各話の生成でこれらの画像実体を紐付ける。髪・目・体格などの固定特徴と、場面に応じた服装状態を区別する。
