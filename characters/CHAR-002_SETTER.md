## 2. 顔・髪・眼鏡

- **輪郭**：骨格がしっかりした、やや四角めの大きな顔。顎・首が太め。怖さだけでなく頼もしさがある。
- **目・眉**：重めのまぶた、眠そうで疲れた目、濃い眉。ふだんは無愛想だが、重要な判断では目が鋭くなる。
- **眼鏡**：**黒縁寄りの中程度の太さのスクエア型**。採用画像の形を維持。眼鏡を外した姿を基本にしない。
- **無精髭**：口周り・顎・頬に自然な剃り残し。長い髭や整えたデザイン髭ではない。
- **髪型**：**黒髪のやや長めの無造作ヘア**。前髪が少し額や眼鏡にかかり、毛量が多く、少し乱れている。
- **白髪**：こめかみ周辺に**少量**。全体を白髪頭にはしない。
- **表情**：基本は倦怠感のある半目。顔つきは大人の渋さと生活感を備える。過剰な凶悪顔、極端な老化表現は避ける。

## 3. 体格・シルエット

- **190cm／約100kg**。肩幅・胸郭・背中に厚みがあり、腕・手も大きい。**熊のようにどっしりしたガタイの良さ**が一目で伝わる。
- **痩せ型にはしない**。反対にボディビルダーのような彫刻的な筋肉誇張も避ける。
- やや猫背・少し前傾した脱力姿勢。静止していても大きさが伝わる。
- ゴールディ（約150cm）と並ぶ場合、**約40cmの身長差**と明白な骨格差を維持。演出で成人男性の大きさを消さない。

## 5. 喫煙動作・状態差分

| 状態 | 表情／所作 |
| --- | --- |
| `default` | 疲れた半目、少し猫背、落ち着いた低い圧 |
| `smoking` | くわえタバコが似合い、ジッポを自然に扱う。無言で少し落ち着く |
| `no_smoking` | 苛立ちが眉間に出るが、収容・安全ルールには従う |
| `research_focus` | 眠たげな目が鋭くなり、迅速で的確な判断を行う |
| `angry` | 大声ではなく低い声・鋭い視線で圧を出す |
| `relieved` | 口角がわずかに緩み、重い肩の力が抜ける |

- 煙草の銘柄は**セブンスター**。ライターは**使い込まれたジッポ**。
- くわえタバコはこの人物を示す特徴だが、**全コマ・全場所に無条件で描かない**。
- SCP収容区画・実験区画では安全手順を優先し、指定喫煙可能区画以外では喫煙しない。事故につながる場面での喫煙は避ける。

## 6. 性格・研究室での役割

- 財団の研究と収容判断において非常に優秀。大きな責任を負う主任。
- 面倒を減らしたいゴールディとは反対に、**仕事を引き受けて抱え込みがち**。
- 昇進よりも、現場への関与と喫煙できる自分の居場所を優先する。
- 寡黙・無愛想・くたびれた風貌だが、部下の実力を信じて任せる。
- 有事には落ち着いた指示と実務能力で周囲を安心させる。

## 7. 描画・生成の固定条件

**必須**：成人40代前半／190cm・100kgの熊体型／肩幅と太い腕／無造作黒髪＋こめかみ白髪少し／スクエア黒縁眼鏡／短い無精髭／重い疲れ目／袖まくりした白衣／開襟シャツ＋緩い濃紺ネクタイ／黒スラックス／金属ジッポ。

**禁止**：細身の若者体型、筋肉の極端な誇張、若返り、眼鏡の消失、整髪された髪、白髪の増量、長い整え髭、ネクタイをきっちり締め直す、一般的な100円ライターへの交換、人物が別人になる改変。

**画像参照は人物のidentityのため**。原画の喫煙ポーズ・白衣ポケットの内容・背景・構図を全コマへ機械的に複製しない。
