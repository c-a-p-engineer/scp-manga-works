- 表情は柔和。警戒・調査中も不用意に威圧しない。
- **非戦闘型**。主戦術は目立たず近づく・聞き出す・観察・検証・危険の回避。格闘や制圧の達人として描かない。

## 2. 喫煙状態の補助参照

![峰の喫煙所作・表情・横顔の資料](assets/CHAR-003_MINE_smoking-v1.png)

[喫煙シーンPNG](assets/CHAR-003_MINE_smoking-v1.png)

- 愛煙の銘柄は**峰（ミネ）**。指定喫煙可能区画でのみ描く。
- 肩の力を抜き、片手で煙草を自然に持ち、細い垂れ目を和らげて一服する。
- 吐煙・指の位置・顔の角度は補助資料。**毎回同じポーズや喫煙場面を複製しない**。
- 所作の画像が人物本体と食い違う場合、人物・衣装の第一参照と確定文面を優先する。

## 3. 禁止するドリフト

吊り目化／若い美少女化／筋骨隆々の戦闘員化／ボディスーツ化／ハイヒール化／ブラウス・スカートの根拠なき消失／派手な諜報装備／喫煙を無条件にどこでも行う／画像のラベル内数値を確定設定へ無断昇格。

## 4. Manga Blueprint Studio handoff

- キャラクター識別：`CHAR-003`、通称「峰」。
- **Character Sheet実画像**（人物用v1 PNG）をidentity参照へ添付する。喫煙コマのときのみ喫煙画像も追加する。

- 生成後は目・髪・体型・通常衣装・非戦闘的な雰囲気、喫煙ルール、漫画の各コマの一貫性を検査する。
