## 2. 外見・シルエット

- **細目で垂れ目**。目がやさしく下がった、おっとりした印象。鋭い眼光や威圧感で「強いエージェント」を表さない。
- **柔らかい体つき**。筋張った戦闘員体型や極端なモデル体型ではなく、自然で落ち着いた成人女性の体格。
- **成熟した、親しみやすい顔立ち**。通常は微笑みか穏やかな無表情。家庭的な雰囲気は外見上の比喩であり、既婚／子持ちの設定ではない。
- 髪はv1資料上では**ダークブラウン系の長めの髪を低い位置でゆるくまとめ、顔まわりに後れ毛**。髪色・留め具の細部・長さは暫定的な画像準拠。
- 姿勢は力みが少なく自然体。威圧せず、周囲に溶け込む佇まい。

## 4. 職務・能力

- **専門**：潜入、調査、聞き込み、対人接触、観察、情報の突合・収集。疑われず自然に現場へ溶け込む。
- **仕事ぶり**：穏やかな会話の中で不整合に気づき、相手を刺激せず必要な情報を回収する。段取りと撤収判断に優れる。
- **非戦闘主体**：**荒事は基本的にしない**。危険を予見し、回避・連絡・撤収・専門部署との連携を優先する。強さを格闘・制圧・銃撃の腕で説明しない。
- **気質**：普段はおっとり穏やかだが、判断は遅くない。優しさと観察眼を両立し、状況を不用意に荒立てない。
- **行動原理**：現場を無事に終え、馴染みの仲間と一服できる研究室に戻る。

## 5. 喫煙・状態差分

| 状態 | 表情・所作 |
| --- | --- |
| `default` | 細い垂れ目、穏やかな薄い微笑み、脱力した自然体 |
| `investigating` | 表情は大きく変わらず、視線・質問・間から観察力が伝わる |
| `infiltration` | 目立たない服装と距離感を選ぶ。周囲の動きに自然に合わせる |
| `smoking` | 慣れた自然な指持ち。肩を緩め、静かに煙を吐く。喫煙画像を所作参照に使う |
| `no_smoking` | 任務・収容手順に従う。任務を終えて一服できる時間を楽しみにする |
| `alert` | 戦闘的な顔へ急変せず、落ち着いて危険を察知し回避・撤収を判断 |

煙草の銘柄は**峰（ミネ）**。ライターの種類・持ち手・吸い方の細かな癖は未定。**指定された喫煙可能区域のみ**で喫煙し、SCP収容・実験の安全規則に優先させない。

## 6. 3人の中での役割

- **バット**：研究・分析・効率化の天才。峰は外部で得た事実と文脈を提供する。
- **セッター**：研究室の主任。峰は現場の判断材料を持ち帰り、セッターは研究・収容方針を取りまとめる。
- **峰**：対人調査・現地観察・潜入・安全な情報回収の専門家。「敵を倒す人」ではなく「問題を荒立てず真相をつかむ人」。

## 7. 描画時の守るべき点

**必須**：40歳前後の成人女性／細く垂れた柔らかな目／親しみやすい表情／柔らかな体つき／落ち着いた私服／柔らかいブラウス・スカート・低めのヒール／非戦闘型の姿勢と雰囲気。

**避ける**：鋭いツリ目、戦闘員風の筋肉、過剰な若返り、タイトなボディスーツ、ハイヒール、軍装、銃や格闘を常時持ち込む、「実は武闘派」としての安易なギャップ設定。喫煙を禁止区域で描くこと。

**画像の権限**：第一参照は顔と衣装、喫煙参照は喫煙状態、ネーム・Blueprintはポーズ／演出／視線を担当。画像ファイルパスだけを生成モデルに書いても画像入力にはならないため、実際のPNGを添付する。
