# EP001 / P001 文章ネーム（草稿）

> **未確定の制作案**。前の会話で作った「見てないと来る」の導入・説明・油断・出現という4ビートを移植したメモです。固定キャストの正式設定や原作条件の整合確認を行うまで、確定ネームや生成指示として使用しません。

- 仮タイトル：見てないと来る
- 形式：日本式縦長1P、右→左、縦書き想定
- 目標：新人の「たいしたことなさそう」という認識が、SCP-650の出現で逆転する
- 出演：新人研究員、先輩研究員、監視担当者、SCP-650（人物名は全員仮）

## 仮の4ビート

### 1. 導入（右上）
**画**：SCP-650収容エリア。黒い人型像を眺める新人、説明する先輩、監視業務中の職員。  
**新人**：「これがSCP-650……ただの像に見えますけど」  
**先輩**：「そう見えるうちはな」

### 2. 異常性の説明（左上）
**画**：まったく動かないSCP-650。先輩の硬い表情と、新人の戸惑い。  
**先輩**：「見られていない隙に、背後へ回り込む」  
**新人**：「えっ」

### 3. 油断（右下）
**画**：監視者を含む職員たちは像を注視。新人が一息ついて、軽口をたたこうとする。  
**新人**：「なら、見てれば平気ですね……」

### 4. 出現・反応（左下）
**画**：**全員が一瞬視認できなくなる理由が必要**（照明トラブル等を候補として検討）。視界が戻ると、新人の背後にSCP-650が迫っている。  
**新人**：「うわあああ！」  
**先輩**：「……だから油断するなと」

## 確定前に修正する事項

1. 原作では **3名以上の監視と相互視認** が必要。上のラフは正しい監視の配置、逸脱原因、職員反応を未確定とする。
2. SCP-650の基本外見（黒い、無貌・手のない彫像、通常姿勢）と移動時の無音を維持する。
3. 出現の演出を「瞬間移動を見せる」とせず、未観測区間とその後の状態を見せる案も比較する。
4. 主要キャラの名前・外見・性格は [キャラクター一覧](../../../characters/README.md) の決定を待つ。
5. コマ数と最終コマの大きさは仮。正式なネームとBlueprintで調整する。
