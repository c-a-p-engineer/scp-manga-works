# EP001 の画像保存場所

画像ファイルはまだありません。実際に生成して採用したものから追加します。

```text
images/
├── drafts/
│   ├── P001-v01.png   # 必要な生成候補だけ
│   └── P001-v02.png
└── final/
    └── P001.png       # 最終レビューを通した採用版
```

- 新規PNGには対応ページ番号 `P001` を含めます。
- `drafts/` は試行画像を**無制限に保管する場所ではありません**。比較用に残す価値がある版だけ保存します。
- `final/` へ移す前に、ネーム・コマ順（右→左）・人物・SCPの形状・セリフ・文字方向を画像の実物で確認します。
- 画像を採用・完成扱いにしたら、[エピソード管理](../README.md) と [一覧表](../../README.md) を更新します。
- 完成画像は1枚2MB程度を想定。大きく増えてきたらGit履歴サイズを確認してから保存戦略を見直します。

`drafts/` や `final/` は最初のPNG追加時に作成されます（Gitは空フォルダを保持しないため）。
