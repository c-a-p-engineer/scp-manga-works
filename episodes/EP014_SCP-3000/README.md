## 物語
P001 巨大なSCP-3000を紹介。P002 分泌物Y-909が一部の記憶処理薬の原料であると説明。P003 Dクラス職員を利用した回収方法。P004 ゴールディが長く煙を吐いて沈黙し、七星は堪えたと誤解するが、ゴールディは「何人前の天ぷらになるか」と発想を飛躍させる。
