# SCPと一服 — SCP-024-JP「東弊カラオケ」
## P001 — カラオケ行きたい！

**文章ネーム 第5稿（生成画像対応）｜5コマ｜喫煙室｜P001の作画はマスターがOK寄りと判断**

### 作画と読み順
日本式RTL、縦書き。上段全幅① → 中段右② → 中段左③ → 下段右④ → 下段左⑤。
低彩度モノクロ基調。参照人物はゴールディ（金髪・赤目・小柄）、七星（黒髪・眼鏡・無精髭・大柄）。
煙草の状態: ①②喫煙中、③灰皿で消す、④⑤消火済み。④⑤で口・手に煙草を復活させない。

### 1コマ目｜上段全幅・喫煙室の二人
右に七星、左にゴールディ。二人とも座って一服。シリーズタイトルと話題のSCP番号はここだけ。
- タイトル「SCPと一服」
- サブタイトル「SCP-024-JP 東弊カラオケ」
- ゴールディ「KARAOKE行きたい！」

### 2コマ目｜中段右・会話の寄り
七星は右手の煙草を口から離して話す。ゴールディは目を見開く。
- 七星「すぐ近くにあるぞー」
- ゴールディ「えっ、本当ですか！」
吹き出しの尻尾はそれぞれの話者へ一つずつ。

### 3コマ目｜中段左・手元の小ゴマ
七星の手が吸い終えた煙草を灰皿に押し付ける。ゴールディの煙草も消火済み。
- 効果音「ジュッ」
- 地の文「――数分後――」

### 4コマ目｜下段右・七星が立つ
立ち上がり、喫煙室の出口へ。両手は空、口元も空。
- 七星「おし、行くぞ！」

### 5コマ目｜下段左・ゴールディの驚き
七星は出入口付近で画面外から一言。ゴールディの表情を強く見せる。
- ゴールディ「え？ 今から！？」
- ゴールディ「業務時間ですよ？」
- 七星（コマ外）「大丈夫だって。ついてこい」

### ページ終端の状態
二人とも煙草なし。喫煙室から保管室へ移動。次ページも禁煙。
