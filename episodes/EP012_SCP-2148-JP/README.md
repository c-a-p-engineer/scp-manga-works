# EP012 — SCP-2148-JP「喫煙治療計画」

**状態：2026-10-22 pixiv公開済み（作者報告）／作者がルート直下に置いた完成原稿5ページをPNGバイナリ変更なしで整理済み。**

- 作品：**SCPと一服**／第12話
- 原典：[SCP-2148-JP「喫煙治療計画」](https://scp-jp.wikidot.com/scp-2148-jp)（nasubi_itame）
- 公開作品：[pixiv 151120131](https://www.pixiv.net/artworks/151120131)
- 形式：フルカラー、全5ページ（P001〜P005）、日本語縦書き、右上→左下、日本の右→左読み。
- 主演：七星とゴールディ。互いを作中で名前・肩書き呼びしない。
- 前大道博士：インタビューの話者だが、原典にない容姿を確定しないため画面外で表現。Dクラス・職員も容姿の捏造を控える。
- オチ（作者確定A案）：デフォルメゴールディ「私たちと仲良くなれそうですね！」／七星は無言。
