# P002 — 装置と実験記録

カラー縦長。日本式右→左、縦書き、全4コマ。

1. 上段横長: 喫煙室で七星が煙をゆっくり吐く。「ふぅ……」「SCP-914がどんな装置か、分かってるのか？」。ゴールディは黙って聞く。強い「バカが！」は削除済み。
2. 中段右: 過去の資料映像としてSCP-914の全景。七星（画面外）「投入した物を、設定に応じて変化させる装置だ」
3. 中段左: 設定ダイヤル。Rough, Coarse, 1:1, Fine, Very Fine。七星（画面外）「だが、出てくる物は予測できん」
4. 下段横長: 実験914-0260の記録、右に1:1、左にFine。七星（画面外）「実際に、タバコを投入した記録もある」。

注意: 安全性を一般化しない。原典の一実験の結果のみ。
