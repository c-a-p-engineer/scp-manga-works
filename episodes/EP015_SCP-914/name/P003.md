# P003 — ドラゴンと本音

カラー縦長。日本式右→左、縦書き、全4コマ。

1. 右側縦長: 過去の実験914-0260、「Very Fine」の出力から紙・厚紙の小さなドラゴンが生まれ、煙を吐いて飛ぶ。
2. 左上: ドラゴンは数時間後死亡。七星（画面外）「だが、生まれたドラゴンは数時間後に死んだ……」。記録表示「死因：肺がん」。
3. 左中: 喫煙室に戻る。七星「……俺も昔、同じ申請をしたんだがな」「生成物を職員に使わせるなと、却下されてな……」。ゴールディは意外そうに話を聞く。
4. 下段横長: 二人で喫煙。ゴールディ（薄赤吹き出し）「難しいですねー」。七星は無言。煙は上向き。

追加規則: 七星は大柄・無精髭・眼鏡。ゴールディは金髪赤目。二人は互いを名前で呼ばない。ドラゴンは生体の鱗ではなく紙製。画像の実際の台詞や配置は公開原稿を正本とする。
