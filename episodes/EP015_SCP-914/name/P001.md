# P001 — 実験申請

カラー縦長。日本式右→左、縦書き、全5コマ。喫煙室。

1. 上段横長: ゴールディが実験申請書を差し出す。「SCP-914の実験許可を！」。一枚目タイトル「ぜんまい仕掛け」、サブタイトル「SCP-914」。ゴールディの吹き出しは薄赤。
2. 中段右: 七星が書類を無言で見る。「……」
3. 中段左: 七星「ダメだ」
4. 下段右: ゴールディ「良いじゃないですか！？」
5. 下段左または全幅: 七星が申請目的「希少なタバコや害のないタバコを作って財団内職員での共有」を読み上げる。書類を中心に描く。
