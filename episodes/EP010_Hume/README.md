## 出典・制作上の留意点

- 原典の現実性の説明は砂の比喩。本作の煙は創作上の説明比喩であって、喫煙によってヒューム値が変化するという設定ではない。
- SCP-239「本人500／周囲30」はSCP-239の個別記事ではなく、ヒュームFAQに記載される数値例。全現実改変能力者の絶対則ではない。
- P003のタブレットに描かれた少女や補助文は画像生成による説明イメージ。**SCP-239の原典描写の再現・実験記録の忠実な引用ではない**。原典と視覚上の差分を公開画像に残すが、原作設定として追加しない。
- 東弊重工が実際に「いつでも喫煙できる装置」を製造した証拠はない。ゴールディの希望的発言。
- キャラクター参照は [連載設定](../../series/README.md) と [人物シート](../../characters/README.md) を正本とする。
