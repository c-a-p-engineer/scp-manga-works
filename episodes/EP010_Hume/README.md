## 解説の正確性について
- ヒュームの原典比喩は「砂の量」。本作の**煙の濃淡は創作上の比喩**。煙を濃くしてもヒューム値は操作できない。
- 本人の高ヒューム・周囲の低ヒュームは**現実改変者の典型的傾向**。どんな対象も「濃い方が必ず勝つ」「高ヒュームだけで確実に能力者」とは描かない。
- SCP-239の「周囲30／本人500」は**ヒュームFAQ中の数値**。SCP-239個別記事中の実測記録と誤って説明しない。
- 東弊重工の「いつでも喫煙できる現実改変装置」は実在確認していない。ゴールディの希望的な発言だけとする。
