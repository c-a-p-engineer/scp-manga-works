## 作画上の固定条件

- P001の1コマ目：**「SCPと一服」＋「SCP-4999『私たちを見守るもの』」**。
- P002の3コマ目：エージェント「**今回はこの映像の解析依頼です**」。
- P002の4コマ目：SCP説明、死後も高齢患者の遺体はベッド上に残す。
- P002のラスト大ゴマ：**新人（右）→主任（中央）→エージェント（左）→主任（左下小吹き出し）**。
- 最後のセリフは正確に「**とりあえず吸いに行くか**」。
- **人物の顔・髪・体格は承認済みCharacter SheetとEP001公開画像を優先**。SCP-4999試作画像は塗り以外の同一性根拠にしない。
