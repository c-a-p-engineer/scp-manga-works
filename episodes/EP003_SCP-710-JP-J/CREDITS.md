## 一次原作と照合した6技（原作の名称・意味を維持）

| 名称 | 内容の要約 |
| --- | --- |
| **共振パンチ** | 共振現象で、より硬い物体を破壊する |
| **共振遠当て** | 手を振動させて音波を生じさせ、離れた物体を共振破壊する |
| **テレポ遠当て** | 量子もつれ現象を利用して離れた物体を破壊する |
| **爆風キャンセリング** | 正拳突きの衝撃波の波形を爆風に合わせて衝撃を相殺する |
| **確率論的回避** | 銃弾の軌道を確率的に予測して回避する |
| **量子歩法** | 特殊な歩き方でトンネル効果を生じさせ、壁をすり抜ける／物体を回避する |

- **敵の名称（重要）**：原作記事後半の「**SCP-710-JP-J伝承者を名乗る一人**」。正表記は**伝承者**。以前の草稿にあった異なる呼称は誤りとして破棄し、今後のネーム・生成用本文・公開用説明でも原作表記を採用する。
- 原作でA〜Cクラス職員が秘伝の巻物コピーを自由に入手できる。就業時間中の訓練は許可を得た職員に対して1日3時間まで。
- 原作のカオス・インサージェンシー襲撃において、伝承者を名乗る相手が登場する。記事は戦いの決着まで描写していない。

## 最新ネームの採用範囲
- **本編で可視化する技は3つ**：P001「量子歩法」、P002「共振パンチ」「爆風キャンセリング」。原作の6技一覧は正しいまま保存するが、今回の漫画では全部を実演させない。
- **共振遠当て／テレポ遠当て／確率論的回避**は原作にあるが、ページの可読性と迫力を優先して今回の2Pから省く。
- **最終煽りは「主任 VS 伝承者」**。伝承者は暗いスーツと目深の帽子、顔を完全に隠す影で描く（漫画独自の外見指定）。
- 会話内で作成した以前の試作画像には、原作・新しい文章ネームに対する構図／術理／呼称の不一致があり、完成画像としては未採用。

## この漫画の創作要素と留保
- 原作の研究員の代わりに連載登場人物・**七星**が技を使用し、**ゴールディ**が驚く。
- 七星は喫煙室で一服してから、くわえタバコで緊急迎撃する。シリーズ一般の分煙規則とは別の、ユーザー指定による今回限りの演出。
- 採用3技の使用順、破壊する敵装備、爆発への対応、伝承者との対峙は漫画用の再構成。**原作の実戦記録を逐語的に再現するものではない**。
- 幕間で七星が「職員なら誰でも学べる」と要約するのは会話の脚色。原作のクラス別資料取得・許可制の訓練は変えない。
- 「量子」「共振」等の説明は**架空のジョークSCP内の設定**。現実の科学で武術が可能という主張ではない。
