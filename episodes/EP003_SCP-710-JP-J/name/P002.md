# SCPと一服 / SCP-710-JP-J「財団神拳」 — 本編 P002「主任 VS 伝承者」

**状態：文章ネーム草稿 v6／本編2ページ目／正式EP003／pixiv公開済み**  
**媒体：縦長ページ漫画／日本式右上→左下（RTL）／縦書き／全3コマ**  
**登場：主任（七星）、ゴールディ、カオス・インサージェンシー構成員、財団神拳の伝承者**

## ページの狙い
技を詰め込むことをやめ、**共振パンチと爆風キャンセリングの大きな寄り2コマ＋伝承者との対峙大ゴマ**へ再構成。旧構成の**独立した伝承者登場コマ・説明専用コマは廃止**。技の演出文字を活用し、最後は俯瞰で主任の後ろにゴールディがいる位置関係を明示する。

## コマ割りと読む順
- **1コマ目：上段右・大きめの寄り＝共振パンチ**。拳と盾の接触点が主役。ゴールディは不在。
- **2コマ目：上段左・大きめの寄り＝爆風キャンセリング**。ゴールディが通常の迂回通路から到着した直後に主任が**「下がって」**と警告し、拳の衝撃波と爆風の波面を相殺。ゴールディは初見で驚く。
- **3コマ目：下段・ページ最大の俯瞰対峙＝主任 VS 伝承者**。登場・名乗り・主任の反応までこの一コマに統合。
- コマ面積を均等に割らない。上段2コマを小窓にせず迫力を確保、下段を最大。台詞は右→左、技名も読順を侵さない。

### 1コマ目 — 共振パンチ／接触面の極端な寄り
**画**：壁の向こうへ先行した主任が、人間の武装した侵入者の堅い防護盾に**直接**拳を叩き込み、共振によって砕く。構図は**拳と盾の衝突位置に最大限寄る**。盾の亀裂・破片、腕の重量感、拳の遠近短縮を大きく見せる。黒縁眼鏡・無精髭・袖をまくった白衣・同じ一本のくわえタバコが見える。装甲の向こうに人間の顔・手を確認でき、ロボットにはしない。
**主任／技名**「共振パンチ！」
**SFX**「バキィッ!!」
**小解説（余白のみ）**「共振パンチ：共振現象で硬い物体を破壊する。」
**ゴールディ**：この場にいない。**この技を目撃していない**。
**レタリング**：技名は**display lettering（描き文字）**。黒主体・白い太フチ・角張った硬質の字形、ひび割れ／共振の細いブレ。接触点を中心に放射する視覚方向へ配置。**SFXとは別階層**にして、文字で拳を隠さない。

### 2コマ目 — 爆風キャンセリング／衝撃波の相殺面に寄る
**画**：別の人間の襲撃者による爆発。主任は**正拳突きで衝撃波**を作り、迫る爆風の波形と重ねて**衝撃を相殺**する。カメラは突き出した拳の横から波面へ強く寄り、波が正面衝突する境界を大きく見せる。**爆炎は消さず、衝撃だけが打ち消される**。通常の迂回通路の**開いた扉**から、ゴールディがようやく到着し足を止める。扉と位置関係は読み取れるようにする。彼女は先ほどの共振パンチを見ておらず、主任が爆風に拳を突き出す**この瞬間が初見**。
**主任／警告（技の発動前・ゴールディに向けて）**「下がって」
**主任／技名（警告の後・大きな描き文字）**「爆風キャンセリング！」
**ゴールディ（目を見開き、思わず）**「爆風を殴った！？」
**小解説（余白のみ）**「爆風キャンセリング：正拳突きの衝撃波で爆風を相殺する。」
**レタリング**：**「下がって」→「爆風キャンセリング！」→拳・波面の相殺→ゴールディ「爆風を殴った！？」**を順に読ませる。最初の「下がって」はゴールディへ向けた**短い通常吹き出し**（発話者の七星へ明確な尻尾）。技名は白い楕円吹き出しに収めず、**display lettering**で大きく。共振パンチの硬質な文字と区別し、**円弧・波面に沿う、流れのある太字**。爆風の衝突方向へ伸ばす。ゴールディの驚きの吹き出しは**開いた迂回通路の扉にいる本人から伸ばし**、技名と衝撃波を隠さない。コマ内で先行の共振パンチを見たかのような発言はさせない。

### 3コマ目 — ページ最大の3/4俯瞰／伝承者が現れ、対峙
**画**：戦闘音が途切れ、廊下奥から**スーツを着て目深に帽子をかぶった伝承者**が現れる。帽子の陰で**顔・目・鼻・口は一切見えない**。登場専用のコマは設けず、この大ゴマに登場・会話・最後の引きをすべて収める。高めの**3/4俯瞰**で、**画面右奥に伝承者、画面左手前に七星（主任）、そのすぐ後方・左下寄りにゴールディ**を配置する。ゴールディは**七星の背後に身を寄せ、慌てて彼の白衣に手を伸ばす／身を縮めて二人を見比べる**。大きく見開いた目、引きつった口元、汗、固くなった肩で焦りを表現する。**ただ静かに突っ立っているようにはしない**。新しい台詞は足さず、表情と所作で慌てさせる。主任は疲れた落ち着きと警戒を残し、くわえタバコを維持。拳はまだ交わさない。

**台詞：以下の4つを2段構成で右上→左上→右中段→左中段の順に読む（改変しない）**
1. **右上／伝承者（低く）**「お前も使うのか……」――**右奥の帽子の人物**へ吹き出しの尻尾を向ける。
2. **左上／主任（驚きつつ警戒）**「まさか……門外不出の財団神拳を……」――**左手前の七星**へ尻尾を向ける。
3. **右中段／伝承者（堂々と名乗る）**「私は財団神拳の伝承者だ！」――**右奥の同じ人物**へ尻尾を向ける。
4. **左中段／主任（脱力した小声）**「同門対決……面倒だな」――**左手前の七星**へ尻尾を向ける。

**吹き出し位置ロック**：**上段［右①→左②］、その下［右③→左④］、最下部に煽り文字**。四つが同じ高さで散乱したり、③が②より先に読まれたり、吹き出しの尻尾がゴールディへ向いたりする構図は禁止。読み順と発話者を決めてから俯瞰の人物位置を調整する。

**煽り（台詞を読み終わる下部の余白・大きく）**「主任 VS 伝承者」
**追い煽り（余白が残る場合のみ）**「今、戦いの幕が上がる！」

**レタリング**：
- 「お前も使うのか……」＝**low / quiet**、小さめの通常縦書き吹き出し。沈黙の間を持たせる。
- 「まさか……」＝**restrained surprise**、ためらいの余白。主任の口元／目元を隠さない。
- 「私は……伝承者だ！」＝**assertive / shout**、大きめで力強い文字・輪郭。顔を隠す帽子の陰を潰さない。
- 「同門対決……面倒だな」＝**dry / flat**、抑えた小さめの吹き出し。大仰な相手との落差で笑いを作る。
- 「主任 VS 伝承者」＝**final display lettering**。二人の対面軸とゴールディの位置が読み取れるまま、下部に大きく。
- **4つの吹き出しを置く空間を先に確保して俯瞰の人物を配置**。各吹き出しの尻尾は**伝承者／七星の正しい話者**に向け、後ろにいるゴールディへ誤接続しない。吹き出しの読順が逆転する場合は左右配置と上下の段差を再調整し、コマを勝手に増やさない。
- **ゴールディの芝居**：画面左手前の七星の**後ろ**で、半歩身を引いて手を伸ばし、焦った表情。**伝承者と同じ横列へ立たせない**。無言の驚きは姿勢で読ませる。

## 制作・連続性
- P001の二人の喫煙、ゴールディの上向きに煙を吐くとろんとした表情、壁が無傷の量子歩法を引き継ぐ。
- P001で主任だけ壁をすり抜け、ゴールディは残る。P002で**共振パンチは未目撃→爆風キャンセリングの直前に合流→主任が「下がって」と警告→初めて技を見て「爆風を殴った！？」→対峙では主任の背後で慌てる**。
- **正規の術名・会話は「財団神拳」**（原作の漢字）。敵は「伝承者」。原作にない六技の強制登場はしない。
- 参照画像は2026-10-13添付のゴールディ／主任のキャラクター画像と既存Character Sheet。ゴールディは金髪ハーフアップ、主任は大柄で黒縁眼鏡・無精髭。顔を別人化しない。
- タバコの銘柄・商品箱・ロゴは描かない。完成画像へページ番号や制作用の注記を描かない。
- 旧5コマ構成の画像は現在のネームと一致せず、修正版完成画像として採用しない。
