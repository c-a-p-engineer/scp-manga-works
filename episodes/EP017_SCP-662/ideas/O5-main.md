# EP017 O5メイン案 — 「O5って何です？」（企画v2）
**ステータス：作者採用前のネタ／2P文章プロット兼ラフネーム／画像未生成**
**主題：O5評議会とは何か。** SCP-662の報告書末尾にある「マース博士の私物に関する追加試験はO5監督者の承認を要する」という警告を発端にする。
**全編、現在の場面は喫煙室。** 説明用の最高幹部のイメージだけ、顔の分からない暗いシルエットに切り替える。SCP-662の実物、O5本人は現場に出さない。
**画風：シリーズ標準ライトセル塗り。RTLの日本語縦組み。七星＝白吹き出し／ゴールディ＝薄赤。ゴールディのタバコは右手に1本、七星は右手に1本。タブレットは七星の左手。**

## P001 — 「O5って何です？」（4コマ）
1. **上段右：喫煙室の日常**。七星がSCP-662の資料を見ながら一服。ゴールディの前には片づけていない灰皿。
   - 七星「マース博士、ベルの執事に洗濯まで頼んでるな」
   - ゴールディ「便利ですねぇ。うちの灰皿もお願いしたい」
2. **上段左：資料の一文**。SCP-662の実験記録末尾をタブレットで拡大。「私物の追加試験：O5の承認が必要／署名：O5-█」と読み取れる（要約表示）。
   - ゴールディ「ん？　O5って何です？」
3. **中段右：説明の開始**。七星が灰を落とす。文字量を抑えて胸上構図。
   - 七星「財団の最高意思決定機関だ」
   - ゴールディ「社長みたいな？」
4. **下段大コマ：権限の視覚化**。世界地図と施設の連なりの奥に、顔を描かない評議会のシルエット。人数は特定できない構図。
   - 七星（画面外）「世界中の財団の方針を決める、最高幹部たちだ」
   - ゴールディ（画面外）「えっ、そんなに偉い人！？」

## P002 — 「洗濯の件で」（5コマ）
1. **上段右：秘密**。黒い会議室、番号だけ並ぶ席札。人の顔・姿は匿名的。正規の本人像と断定させない説明イメージ。
   - 七星（画面外）「一般には十三人とされる。名前も顔も極秘だ」
   - ゴールディ（画面外）「会ったことあるんですか？」
2. **上段左：例外的な立場**。喫煙室の七星がタブレットを置く。O5の遠い世界と、目の前の一服を対比。
   - 七星「俺はない。原則、SCPとの直接接触も禁じられている」
   - ゴールディ「一番偉いのに！？」
3. **中段・大きめ：ギャップを発見**。ゴールディが資料の「O5による警告」部分を指差す。
   - ゴールディ「……そんな人たちが、洗濯物のことで怒ってるんですか？」
   - 七星「マース博士が私物の実験をやりすぎたんだろう」
4. **下段右：日常へ帰還**。七星が、ゴールディの片づけていない灰皿を見る。ゴールディは目を逸らす。
   - 七星「で、その灰皿はいつ片づける？」
5. **下段左・オチ**。ゴールディが灰皿を持ち上げず、何食わぬ顔で一服。
   - ゴールディ「O5の承認待ちです」
   - 七星「自分でやる分には要らん！」
   - オチでは七星だけ勢いのある吹き出し、ゴールディはしれっと薄赤。説明用の地の文を追加しない。

## 事実と創作の区別
- SCP-662記事の末尾には、**マース博士の私物**に関する追加実験へのO5承認条件が明記される。他のあらゆる実験・個人の灰皿清掃にO5承認が必要という意味ではない。
- O5は財団の最上位の評議会。一般的に13人と描かれ、番号はO5-1〜13。正式な身元は機密。一般的説明では異常存在に直接触れない。各作品・記事間でO5の具体的正体や人数には矛盾や不確実性がある。
- 「世界中の方針」「最高意思決定機関」「本人と会いにくい」の説明を主役とし、O5の実体・内部生活・喫煙習慣を創作で断定しない。
- ゴールディの言う「灰皿の承認待ち」は**冗談**であり財団規則ではない。実際にO5が灰皿問題を見たり警告したりした事実を描かない。
- 縦書き組版ではO5を「オーファイブ」と言い換える選択可。作中タブレット表示の「O5-█」は横組み。
- ページ／コマ番号は制作管理にのみ使い原稿へ印字しない。最初のヘッダー案：「SCPと一服」「EP017」「O5って何です？」（SCP-662は資料タイトル内に明記）。
