## 修正の重点

- ①⑦でゴールディを**右**、七星を**左**へ置き、右→左に質問→返答が読めるようにする。
- 最終コマの七星の地の文「（俺は喫煙可にしてる）」を**左下・最後・吹き出しなし**で固定。
- 原作通り、1円の部屋にはカラオケ機械・インターフォンを描かない。職員10人の私的利用は「疑い」に留める。
- 原作の自費規則はDクラス実験以外に適用。七星の短い返答だけから「私的利用限定」と誤解させない。
