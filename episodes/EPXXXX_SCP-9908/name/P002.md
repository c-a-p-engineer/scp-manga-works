# EPXXXX / P002 — 文章ネーム「研究ですね」

**作品：** SCPと一服／SCP-9908「喫煙。」  
**読み順：** 右上→左下（日本式RTL）／吹き出しは原則縦書き  
**状態：** 改訂文章ネーム／旧試作画像未採用（GitHub未登録）

## ページの狙い
七星とゴールディが**研究者としては優秀で、愛煙家としては同類**と分かる回収。セリフでオチを説明せず、最後は「何を吸ったか」を伏せた暗転で切る。**峰は描写も声も登場させない**。

## 改訂版コマ割り（2026-10-12 作画レビュー）

横長5段の反復は廃止。**二人の共犯的な笑み→材料の選択→無言の圧縮→黒ベタ大ゴマ**へ視覚重量を移す。

- **上段右：1コマ**。七星の大きな手と数枚の巻紙、眼鏡越しの「ﾆﾁｬｧ」。
- **上段左：2コマ**。ゴールディの目・口元を強調した対になる「ﾆﾁｬｧ」。同じバストアップの複製にはしない。
- **中段全幅：3コマ**。七星の差し出す巻紙と二人の視線が主役の横長コマ。会話のRTL読みを維持。
- **中下段全幅：4コマ**。二人の手が何かを取る細い無言コマ。取ったもの・完成品は見せない。
- **最下段全幅：5コマ**。ページ内最大の黒ベタ大ゴマ。**小さなオレンジ系の炎二つと「シュッ」二回、下端にSCP解説**を置く。4コマ→5コマで視覚的な解放を作る。
- ページ全体でコマの大小・人物占有率・黒量に意図的な差を付け、等高五段に戻さない。

### 1コマ目 — 上段右／七星の切り札・顔と手元
七星がニヤリとし、管理用の封筒からSCP-9908の巻紙を数枚見せる。あくまで実験用途として手続きしているという設定で、研究室で火を点けない。

- **七星：**「実験に使用すると言って」
- **七星：**「ここに数枚あるんだ」
- **表情・描き文字：**「ﾆﾁｬｧ……」

### 2コマ目 — 上段左／ゴールディも同類・目と口元
一瞬黙ったゴールディが、七星と同じ口元のゆがんだ笑みになる。二人のニヤケ顔はコメディ的誇張だが、基準キャラクターの輪郭・年齢・瞳は保持。

- **ゴールディ：**「……実験ですね」
- **表情・描き文字：**「ﾆﾁｬｧ……」

### 3コマ目 — 中段横長／好きなものを巻いて・場面転換
財団の許可された試験用区画へ移る。七星が数枚の巻紙を差し出す。机上には何か選べそうな日用品等があるが、**どれが最終的に選ばれたかは分からない**。

- **七星：**「では」
- **七星：**「好きなものを巻いてくれ」

### 4コマ目 — 中下段細い無言コマ／暗転直前
二人がそれぞれ何かを取り、作業に入る。画角は手元、光と影、二人のシルエット。**材料・完成したタバコの正体は隠す**。発火はまだしない。

- **台詞・描き文字：** なし
- **演出：** 次の黒ベタへ向け、明度と描写情報を絞る

### 5コマ目 — 最下段・黒ベタ大ゴマ／炎二つ・シュッ二回・SCP解説

二人の姿、巻いた素材、吸った後の結果は**描かない**。黒い画面の中に離れて浮かぶ**小さな炎を二つ**、それぞれに白の擬音を組み合わせる。炎だけ限定的な**赤橙／橙スポットカラー**、残りはモノクロ。

- **右の炎：** 「シュッ」
- **左の炎：** 「シュッ」
- **人物の台詞：** なし
- **読み順：** 右の着火音→左の着火音。2つの音と炎は一対一で対応させる。
- **説明位置：** **同一の黒ベタ最終コマの最下部**。小さめの明灰色文字で、炎と擬音の余韻を壊さない。解説後に追加の物語コマを設けない。

**ページ内のSCP説明文（可視文字・確定）**

> **SCP-9908「喫煙。」**  
> あらゆる固形物をタバコに加工できる異常な巻紙。吸引時の作用は素材ごとに異なり、その効果は予測できない。

解説は「これまでの映像の意味」を簡潔に補うもの。**何を吸ったか・どんな作用が起きたかは最後まで伏せる**。原作クレジットの完全表記は同話のCREDITS.mdと公開時の投稿本文に分離する。
