# EP002 幕間 / P001 — 文章ネーム「翌朝」

## 画面内に表示する題字（確定）

**1コマ目、冒頭の読み始め位置に必ず置く。**

- **シリーズ題字**：「SCPと一服」
- **その直下のサブタイトル**：「SCP-9908 幕間」

この2つの文字列は**見える漫画本文**として描画する。**「翌朝」**は制作管理上の仮題であり、特に指示がなければ大きな可視題字として追加しない。「EP002」「P001」「コマ1」などの作業情報は画像に載せない。

## ページ仕様・目的

- **作品**：SCPと一服／SCP-9908幕間（旧企画名「SCP財団 ヤニカス研究室」は現在の正式作品名ではない）
- **媒体**：pixiv向け日本漫画、縦長1ページ
- **読む順番**：右上→左下（RTL）、日本語の吹き出しは原則縦書き
- **コマ数**：6コマ。**最後の可視セリフは七星**。ゴールディの赤面アップに七星の言葉を重ねて締める。6段の均等割りにはしない。
- **時間軸**：EP002の翌朝。実際に二人が巻紙を使った後のゴールディの目覚め。
- **場面**：財団の休憩・観察スペースと、その隣にある換気・分離された専用喫煙ブース。寝床や研究室で喫煙しない。
- **ねらい**：EP002の「何を巻いたのか」という謎は保持し、吸った翌朝のゴールディの奇行だけ明かす。最後は、ゴールディの真っ赤な顔へ寄った画面で七星が記録の扱いを一言告げ、余韻を残して締める。
- **登場**：ゴールディ（成人女性）と七星のみ。峰や他職員は出さない。

## 全コマ共通のキャラクター・露出境界（絶対に固定）

- ゴールディは**最初から最後まで服を見せない**。服そのもの、脱いだ服、ボタン、ブラ、白衣などを画面へ入れない。
- 現在時点のゴールディは、**顔、首、裸の肩・鎖骨まで**を自然に見せる。胸元以下は常に厚い布団で完全に隠し、胸部や身体の輪郭を描かない。寝返りや起き上がりでも布団の隠蔽を維持する。
- 回想時はゴールディを黒一色の**ギャグ用の簡略シルエット**で表現し、裸体の詳細・胸・股間・臀部・乳首を描かない。「全裸」は七星の台詞でのみ説明する。
- 髪型、顔、深紅の瞳など人物の同一性は[ゴールディ正規Character Sheet](../../../../characters/CHAR-001_BAT.md)を優先。七星は[正規Character Sheet](../../../../characters/CHAR-002_SETTER.md)の眼鏡・無精髭・大柄な体格・白衣・ジッポを守る。
- 官能演出ではなく、**二日酔いのような頭痛・狼狽・ギャグ・羞恥**を扱う。

## ページの構成・読順

**コマ①上段横長の導入（シリーズ題字とサブタイトルを置く）**
→ **②右中・状況提示** → **③左中・気付き** → **④中下段・不安と説明**
→ **⑤回想を見せるやや大きめの変形コマ**
→ **⑥最下段大ゴマ・ゴールディの赤面アップに七星の最後の台詞を重ねる**。

①の題字が顔や台詞へ重ならないよう空白を取る。⑤は黒シルエットと英文で情報量を処理し、⑥の日本語会話・表情が読める面積を確保する。左右に分かれるコマは常に**右→左**で読む。

### ① 上段横長 — ガバッ！

財団の休憩・観察スペース。ゴールディが布団から**ガバッ**と上体を起こす。裸の肩が見えるが、胸から下は厚い布団に完全に覆われている。衣服・脱ぎ捨てたものは画面にない。

- **画面内題字**：「SCPと一服」
- **画面内サブタイトル**：「SCP-9908 幕間」
- **SFX**：「ガバッ」
- **ゴールディ**：「っ……頭がぁ……！」

### ② 右中 — おはよう

寝ぼけて視界が定まらないゴールディ。見えるのは休憩・観察スペースと、別区画の専用喫煙ブースで一服している七星。七星は少し疲れているが普段どおり。

- **ゴールディ**：「え……ここは……？」
- **七星**：「おはよう」

### ③ 左中 — 異変

ゴールディが服を着ていないことに気づき、慌てて布団を強く引き上げる。**顔・肩のみ**、胸元以下は布団で隠れたまま。衣類や裸の身体は映さない。

- **ゴールディ**：「えっ！？ なんで何も着てないの！？」

### ④ 中下段 — 昨夜の話

七星が片手で頭を抱える。心底疲れた様子。昨夜の騒ぎを思い出している。

- **七星**：「昨日お前、吸ったあと酷かったんだぜ……」
- **ゴールディ**：「SCPのせいか！？」
- **七星**：「まあな……熱い寒いって暴れるし、急に泣き出すし……」

### ⑤ 回想の大ゴマ — 奇行の暴露

七星の疲れた顔を前景に、昨夜のゴールディを**全身不透明の黒いデフォルメシルエット**と大きな文字で回想する。シルエットに身体の解剖学的ディテールは与えない。

- **七星**：「一番ひどかったのはな……」
- **回想のゴールディ／英語の叫び（各々独立した可視文字）**：
  - “I'M SORRY I WAS BORN!!”
  - “I'LL START OVER AS A BABY!!”
  - “BAAABOOO!!”
- **七星**：「ってお前、全裸でこれを叫んでたんだぞ」

**吹き出し順**：日本式RTLで七星の語り→英語回想→七星の説明と自然に読める位置へ。吹き出しを詰めて文字が欠ける場合は⑤のサイズを優先して確保する。

### ⑥ 最下段大ゴマ — ログは……？／ゴールディの顔アップ／七星の一言

**最後の読む順番と注目先を固定する。**

1. **ゴールディ**：「これって実験だから、ログは……？」
2. **ゴールディの顔のアップ**。布団を握ったまま、頬から耳まで真っ赤。恥ずかしさ、不安、わずかな期待が混ざった表情。顔・裸の肩以外は布団とフレーミングで完全に隠す。視線をこの表情へ集める。
3. **七星（画面外からの返答）**：「俺の権限で記録ミスにしておく」

**七星の言葉が漫画全体の最後の台詞。** 七星の姿へカットを切り替えず、**ゴールディの赤面アップを映したまま**、七星の吹き出しを画面外から重ねる。RTLで①問い→②顔アップ→③返答と伝わる吹き出し・視線配置にする。最後の台詞の後に、別の赤面コマ・無言コマ・モノローグ・後日談を設けない。

ゴールディの顔の赤みだけにスポットカラーを使い、衣装・胸元・裸体の身体部分は一切描かない。
