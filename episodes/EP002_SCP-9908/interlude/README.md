## 不変条件

1. **冒頭の1コマ目に「SCPと一服」、すぐ下に「SCP-9908 幕間」を必ず表示する。** 本編の「SCP-9908『喫煙。』」と混同しない。
2. ゴールディは**全編で服を一切見せない**。着衣描写や衣類の小物も画面に登場させない。現在時点では成人の顔、首、**裸の肩**まで見せ、胸から下は厚い布団に完全に隠す。
3. 昨夜の回想は**完全不透明の黒いデフォルメシルエット**で表現する。身体の細部や裸体の輪郭を見せず、裸だった事実は七星の台詞だけで説明する。性的・官能的な演出にしない。
4. 奇行の台詞は**英語で叫んでいたこと**が可視文字から分かるようにし、黒シルエットと組み合わせる。日本語の意味は「生まれてきてごめんなさーい！」「赤ちゃんからやり直す！」「バーブー！」。
5. 七星の告白は正確に「**ってお前、全裸でこれを叫んでたんだぞ**」。
6. ラストのやり取りはゴールディ「**これって実験だから、ログは……？**」→七星「**俺の権限で記録ミスにしておく**」。最後は**ゴールディの顔が真っ赤になる無言のリアクション**で閉じる。
7. 喫煙を見せる場合、研究室内・寝室内では喫煙させず、財団内の専用喫煙ブースにいる七星を別アングルで見せる。
