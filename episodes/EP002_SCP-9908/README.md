## 演出の固定事項

- P001の1コマ目に「**SCPと一服**」、その下に「**SCP-9908『喫煙。』**」。
- P001は研究室でのデータ解析。**研究室内では喫煙しない**。
- P002は七星が保管資料から**実験用の巻紙を数枚取り出し**、二人が同類の「ﾆﾁｬｧ」顔になる。
- **P001ラスト**：「……そうか。なら話が早い」を**一つの縦書き吹き出し**にまとめる。日本式RTLに反したセリフ逆順は不可。
- **P002ラスト**：選んだ物と結果を見せない**黒ベタ大ゴマ**に、小さな**橙色の炎2つ＋「シュッ」2回**、同一コマ下部に短い**SCP-9908の説明**を置く。追加の後日談・物語コマは置かない。
- **コマ構成**：P001は上段横長1→中段右2／左3→下段右4／左5。P002は上段右1／左2→中段横長3→中下段の細い無言4→下段大ゴマ5。単調な等高5段を避ける。
- 実験を実行するなら研究室ではなく財団の**許可された試験・喫煙用区画**。七星が入手したという展開は漫画独自の脚色で、正式な収容規則を変更した扱いにしない。
- キャラの顔・髪・体型・衣装の正本は [CHAR-001 バット](../../characters/CHAR-001_BAT.md)／[CHAR-002 セッター](../../characters/CHAR-002_SETTER.md)と採用済み基準PNG。SCP-4999の試作画像から顔を流用しない。
- 彩色は[シリーズ標準彩色](../../series/PIXIV_PUBLICATION_TEMPLATE.md#シリーズ標準彩色2026-10-12-採用)を既定とする（低彩度グレー、柔らかな陰影、必要なスポットカラー）。
- ネームはレビュー反映済み。改訂版の漫画画像候補が2枚生成・保管済み。ただし**現物を正式採用する最終受入は未実施**。StudioのBlueprintコンパイル実行実績は未確認。

3. **両ページの平板な横長5段**：視覚重量と読む順番を設計し、変化のあるコマ割りへ変更。
