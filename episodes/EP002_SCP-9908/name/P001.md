# EP002 / P001 — 文章ネーム「異常な巻紙」

**作品：** SCPと一服／SCP-9908「喫煙。」  
**読み順：** 右上→左下（日本式RTL）／吹き出しは原則縦書き  
**状態：** 改訂文章ネーム／画像候補はGitHub `images/drafts/` に保管済み（正式採用未確認）

## ページの狙い
普通の押収資料に見える巻紙から、あらゆる固形物をタバコへ変える能力と素材ごとの予測不能な作用へ話を展開する。ゴールディは単なるボケ役にせず、真剣に解析し、最後に七星が含みを持たせて次ページへつなぐ。**本文の話者は七星とゴールディのみ**。

## 改訂版コマ割り（2026-10-12 作画レビュー）

従来の「横長5段・等高」は不採用。日本式右上→左下の読み順を厳守しながら、**人物／モニター／小物と画面占有率を変える**。

- **上段：1コマ（大きめ横長）**：研究室とタイトルを印象付ける。
- **中段：右2コマ（縦長の机崩壊映像）→左3コマ（実験結果コラージュ）**。3コマの情報量に応じて幅と高さを優先。映像の中に細かい日本語を詰め過ぎず、台詞の可読性を確保する。
- **下段：右4コマ（ゴールディの研究者としての目）→左5コマ（七星の含み笑い）**。4→5で表情と明暗差をつけ、次ページへの引きを作る。
- 5コマ目は七星の**「……そうか。なら話が早い」一つの縦書き吹き出し**とする。過去の試作画像で右側に後半「なら話が早い」、左側に前半「そうか」が配置され、読順が逆になった失敗を繰り返さない。
- 2・3・4・5コマは長方形の均等四分割に固定しない。視線誘導・文字量・余白を検討し、幅・高さを非対称に調整する。ただし右2→左3→右4→左5の順序を崩さない。

### 1コマ目 — 上段横長・導入／タイトル入り
データ解析研究室。七星がモニターに資料を表示し、小柄なゴールディが横から覗き込む。喫煙はしていない。二人の身長・体格差は自然に見せる。

- **画面内題字：** 「SCPと一服」
- **画面内サブタイトル：** 「SCP-9908『喫煙。』」
- **七星：**「今回の解析対象はこれだ」
- **ゴールディ：**「……巻紙？」
- **七星：**「異常な巻紙だ」

### 2コマ目 — 中段右／異常性の提示・手元中心
モニター内の既存実験映像。巻紙を折りたたみ机へ接触させると、接触部分がぽろぽろ崩れて紙へ入る。実物が研究室にあるようには描かない。

- **ゴールディ：**「うわ、机が……」
- **七星：**「どんな固形物でも、これで巻けばタバコにできる」
- **ゴールディ：**「『何でも吸える』ってことですか」

### 3コマ目 — 中段左／試験結果の列挙・映像コラージュ
異常な巻紙でタバコにした材料の試験記録を、モニター上の小さな3つの映像／資料で見せる。**バナナ／炭酸飲料の缶／野球ボール**の視覚を明確に区別する。

- **七星：**「素材ごとに作用が変わる」
- **七星：**「だが、法則性はまだ見えていない」
- **ゴールディ：**「バナナでめまい、缶で幻覚、野球ボールで多幸感……」
- **ゴールディ：**「意味分かんないですね、これ」

### 4コマ目 — 下段右／ゴールディの研究者としての関心
ゴールディがモニターへ身を乗り出す。気だるい平常時とは違い、目が鋭くなっている。

- **ゴールディ：**「でも、ちょっと面白いな……」
- **七星：**「ほう？」
- **ゴールディ：**「吸う物が変わるだけで、体感がそこまで変わるなら」
- **ゴールディ：**「データとしてかなり興味あります」

### 5コマ目 — 下段左／ページ終端・引き・七星の表情
七星が資料の上から視線を上げる。眠そうだった目と口元に、少しだけ含みのある表情。

- **七星：**「……そうか。なら話が早い」
- **組版：** 一つの縦書き吹き出しにまとめ、上から下へ正しく読ませる。別々の吹き出しに分割しない。

## P001連続性・作画注意
- 人物：ゴールディ（小柄な成人女性、金髪ミディアム／ハーフアップ、深紅の瞳、オーバーサイズ白衣・黒ネクタイ）／七星（約190cm・100kg、40代の大柄な男性、眼鏡・無精髭・白衣・緩いネクタイ）。
- 一度に大きく見せる焦点を変える：研究室全体 → 巻紙と机の接触 → 記録の3分割 → 新人の目 → 主任の含み笑い。
- 原作での巻紙の作用は**対象物へ紙を当てることで、その一部が紙に崩れ込む**。机全体が消失する描写にしない。
