## 内容

1. ゴールディが喫煙室へ駆け込み「主任！」。七星は「なんだ？」。
2. 藤崎の記録に「医務室にタバコを持ち込むことは推奨しません。」とあることを指摘。
3. 七星「知ってる」→ゴールディ「言ってくださいよ！」。
4. 七星「お前は身をもって体験しないと覚えないタイプだ」。無枠の「師範の勘だ」。
5. 元人型SCPを実際に見せる教育上の意図を、七星が得意げに説明。ゴールディは「反論できない……」と心でつぶやき、一服。

読順は日本式右→左、縦書き。実画像は**6個の物理的コマ枠**（5つの物語ビートのうち「知ってる」「言ってくださいよ！」が分割）で構成される。
