# EP006 幕間「師範の勘」P001 — 公開画像の読解

> [採用完成画像](../images/final/P001.png)を観測した記録。**制作時の5ビートを6物理コマへ組み替えた最終画面**として記載する。pixiv配信JPEGとの画素完全照合は未実施。

- 縦長1P、1024×1536px、低彩度アニメ・漫画調、人物二人、喫煙室のみ。
- ページ最上部のタイトル「SCPと一服」、サブタイトル「SCP-3491-JP 幕間 師範の勘」。
- 日本式の右→左・上→下。物理コマ枠は**上段全幅1 + 中段右縦長1 + 中段左の上下2 + 下段横長1 + 最下段横長1 = 計6**。

## 実際に観測できる6コマ

1. **上段横長**：右のゴールディが勢いよく喫煙室へ入り「主任！」。左の七星は喫煙しつつ「なんだ？」。尻尾は七星へ向く。
2. **中段右・大きめ**：ゴールディがタブレットを差し出し「藤崎さんの記録見てたら、そもそも『医務室にタバコを持ち込むことは推奨しません。』って書かれてるじゃないですか！」。タブレットにも該当注意事項を表示。
3. **中段左・上**：七星の顔アップ。「知ってる」。
4. **中段左・下**：怒るゴールディ。「言ってくださいよ！」。
5. **下段横長**：七星「お前は身をもって体験しないと覚えないタイプだ」。**無枠直書き**「師範の勘だ」。
6. **最下段横長**：右の七星が得意げに「実際に元人型SCPを見て貰う意味もあった。」「今はもう異常性のない人間だが人もSCPになるということをな」。左のゴールディは火のついたタバコを口元に持ち、やりこめられた表情で心内語「反論できない……」。**「（心の声）」などの文字ラベルは無し**。

## 採用版で確認した差分

- 制作時に一つのビートだった「知ってる」→「言ってくださいよ！」を別々のコマへ分割。
- 題字とサブタイトル追加、1コマ目の人物配置と尻尾の修正。
- 文字がページ端で切れない構図へ再生成。
- 誤字「しまれん」→「しません」、重複「をを」→「を」。
- ゴールディの末尾表情を弱く困り顔へ、タバコを吸う描写を追加。心内の表示から「（心の声）」の注記を削除。

この読解は**当該GitHub完成PNG**をもとに作成した。pixiv側JPEGには再圧縮・差し替え等の可能性があるため、ビット単位の同一性は主張しない。
