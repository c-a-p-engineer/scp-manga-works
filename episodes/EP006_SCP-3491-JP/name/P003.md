# EP006 / P003 — すくえない男

**状態：文章ネーム・改訂版（2026-10-16、原典・読順・回想の年齢差・背景密度・ラスト台詞を反映）。画像候補は会話内で作成済み・未採用。**

- 日本式右→左、上→下。**5コマ**：上段右1 → 上段左2 → 中段右3 → 中段左4 → 下段横長5。縦書き。
- ページの主眼：人間型SCPの説明 → 元外科医の後悔 → 能力を人命救助に使った出来事 → 静かな一服。
- 背景密度：**1=C（質問・回答を最優先）、2=A（過去のスリを説明）、3=C（医師の後悔・余白）、4=A（重要な救命現場。ただし焦点のみ）、5=C（余韻・白場）**。Aは「情報が必要な被写体だけ精密」であり、群衆や設備を高精細にする意味ではない。

## 1コマ目（上段右・喫煙室／背景C、話者・読順優先）

喫煙室。ゴールディが驚いて七星に顔を向ける。二人の位置は前ページからの連続性が伝わる範囲で**カメラを切り返すなどして調整可**。会話の読順を優先する。

- **吹き出し第1／コマ右上**：ゴールディ「てか、あの人SCPだったんですか！？」（尻尾＝ゴールディ）
- **吹き出し第2／コマ左側、1より後に読む位置**：七星「SCP-3491-JP。かつて『箱師のマサ』と呼ばれたスリ師だ」（尻尾＝七星）

**最重要**：生成版で繰り返された「右の七星の回答→左のゴールディの質問」という逆順を禁止。人物の左右を固定するより、質問→回答とそれぞれの尻尾の対応を優先する。背景は無地または微かな喫煙室アンカー。

## 2コマ目（上段左・過去のスリ／背景A）

回想と分かるトーン。若くはあるが**外科医時代より年を取った藤崎（中年）**が、人混みで他人の財布から紙幣を抜く。人物は七星に似せない。両手首から先と保持物が物体を透過する描写を中心に。モブはシルエット数名、街並みのネオンや人物群の描き込みを避ける。

- 七星（説明）「手や、手に持った物を透過させる能力でな。40年もスリをやってた」

**透過表現は過去のみ**。現在の医療アドバイザー藤崎の能力が復活した印象を与えない。

## 3コマ目（中段右・元外科医の後悔／背景C）

2コマ目より**さらに若い藤崎（外科医時代）**。手術着で、メスを握れなくなった手を見つめる。顔と手元を大きく、手術室設備は手術灯の一部・淡いトーンだけ。患者の生々しい描写や大きな血痕は不要。「優秀な医師だったが患者を救えず、後悔によってメスにも人体にも触れられなくなった」を視覚化する。

- 七星（説明）「だが元は外科医だ。救えなかった患者がいてな」
- 七星（説明）「それから、メスも人も触れなくなった」

※原典では小児がん患者を救えなかった後の出来事。手に触れられなくなったのは**比喩ではなく異常性による透過**。

## 4コマ目（中段左・過去の収容違反時の救命／背景A、視覚的核心）

**財団施設内**の収容違反の最中。高齢の藤崎が銃創を負った警備員を応急処置し、かつて医師だった手で**異常性を使い、体内から弾丸を取り出す瞬間**へ画面の焦点を絞る。薄く透過する指先と摘み出された弾丸の小さな形で能力を示す。背景は足元、無地の床・警報灯をわずかに描く程度。モブと過剰な血液・軍装・照明・壁面情報は削る。

**原典ライターの扱い**：原作ではライターの炎で大型ナイフを炙る。今回は画面を単純化するため**ライター本体は描かず、必要なら画面端の小さな炎と刃の熱だけを記号的に示す**。主要な視覚情報は「藤崎の透過する指＋弾丸＋警備員」で、火器の形状・炎の演出を競わせない。

- 七星（説明）「収容中の事故で警備員を救った。その後、異常性が消えたんだ」
- 七星（説明）「今は財団の医療アドバイザーだよ」

※救命と能力喪失には時間的な前後関係があるが、**喪失した原因は原典で不明**。因果を断定した絵・効果文字は描かない。

## 5コマ目（下段横長・喫煙室／背景C、静かな締め）

七星とゴールディが横並びで一服。**ゴールディは七星から一本分けてもらったタバコを吸っている**。受け渡しの動作を無理に描く必要はない。タバコ箱やライターは描かず、煙と近い二人の表情で示す。前ページの「Booo!!」から一転して落ち着いた空気。背景は白場と薄いトーン、ソファ輪郭程度。

- **吹き出し第1／コマ右上**：ゴールディ「へぇー……オブジェクトって、物のことだと思ってました」（尻尾＝ゴールディ）
- **吹き出し第2／コマ左側・第1より後**：七星「人間だってSCPになるさ」（尻尾＝七星）
- **七星の小声・文字のみ**：「**俺のをやるから許せ**」。吹き出し枠なし、四角い地の文枠なし、吹き出し尻尾なし、白い背景板なし。**七星の顔／肩の近くの空白に、本人の発話だと一目で分かる形で配置**。文字は小さめだがスマホで判読可能とする。主要会話の読順を割り込ませない位置に置く。

**最重要**：右の七星の答えが左のゴールディの感想より先に読まれる旧版の配置を禁止。セリフを動かすために人物位置・カメラ側を調整してよい。

## 原典・連続性・作画固定

- SCP-3491-JPは異常性喪失後に**Neutralized**。過去の手の透過と現在の通常のスリを混同しない。
- 若い医師時代 → 中年期の長いスリ歴 → 高齢期の救命 → 現在の医療アドバイザー、の時系列を**顔と服装で明確に描き分ける**。
- 収容違反と救命は原典では施設内で発生。漫画では**サイト番号と七星たちの所属先を特定しない**。
- P003にタバコ箱を描かない。ライター本体は原則描かず、原典に必要な炎は小さく暗示するだけ。
- 回想モブ、ネオン、高精細な医療装置を過剰生成しない。描くべきものは藤崎の**手・表情・弾丸**。
