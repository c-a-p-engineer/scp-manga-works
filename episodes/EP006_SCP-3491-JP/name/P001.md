# EP006 / P001 — お届け物です！

**状態：文章ネーム・最新改訂版（2026-10-16、藤崎の「君もね」・無枠の補足・吹き出し設計を反映）。会話内の生成画像は未採用。**

- 作品：『SCPと一服』／SCP-3491-JP「すくえない男」
- 日本式右→左、上→下。**4コマ**：上段右1 → 上段左2 → 下段右3 → 下段左4。縦書き。
- ページの主眼：喫煙室からの使い → 医務室で藤崎に出会う → スリの機会を隠しておく。
- 背景密度：**1=A（場所の提示）、2=A（医務室の提示）、3=C（接近と受け渡しに集中）、4=C（表情と会話に集中）**。A＝場面識別に必要な背景、C＝白場・薄いトーン・必要な線のみ。
- **文字設計**：会話は縦書きの通常の丸吹き出し（楕円）＋**1吹き出しにつき話者へ短い尻尾1本**。無枠文字は吹き出しでも心の声でもない補足で、**尻尾なし**。吹き出し本体が別の話者の頭上に乗らないようにする。

## 1コマ目（上段右・喫煙室／背景A）

喫煙室。右に七星、左にゴールディ。七星が**薄い灰色の紙製書類ファイル**を差し出し、ゴールディが**火のついたタバコを吸いながら**片手で受け取る。七星も喫煙中。喫煙室の看板や椅子など最低限の室内アンカーだけ描く。机の大理石反射・ガラスの映り込み・植物の細部は不要。

- タイトル：「SCPと一服」
- サブタイトル：「SCP-3491-JP すくえない男」
- **吹き出し①／右上・丸・尻尾→七星**「ちょっとこれ、医務室に持ってってくれ」
- **吹き出し②／①より左下・丸・尻尾→ゴールディ**「はーい！」

**読順**：七星の依頼 → ゴールディの返事。タバコを吸うゴールディの口やファイルを、吹き出しと尻尾で隠さない。

**連続性**：場面転換中にゴールディはタバコを吸い終えて消しており、医務室では喫煙しない。ゴールディが持つタバコの在庫とライターは画面外の私物ポケット内にある設定。**タバコ箱とライター本体は描かない**。

## 2コマ目（上段左・医務室／背景A）

医務室のドアと「医務室」の表示で場面を提示する。ゴールディは同じ灰色の**紙ファイル**を抱えて入り、藤崎勝政（穏やかな高齢の男性医療アドバイザー）が迎える。医務室と分かれば棚の背表紙、机上の器具、反射、細かな設備は省く。

- **吹き出し①／右上・丸・尻尾→ゴールディ**「お届け物です！」
- **吹き出し②／①より左下・丸・尻尾→藤崎**「おや、ありがとう」

**読順**：訪問者の声 → 藤崎の応答。入口・人物の相対位置はこの順を満たすように決める。

## 3コマ目（下段右・受け渡し／背景C）

藤崎が立ち上がるか少し身を寄せ、ファイルをゴールディから受け取って読む。**スリが可能なほど距離は近いが、盗む手の動きは写さない**。顔、手、書類ファイルのみを主な情報にする。ファイルをタブレット／金属プレート／端末として描かない。

- **吹き出し①／右上・丸・尻尾→藤崎**「ふむ……主任は？」
- **吹き出し②／①より左下・丸・尻尾→ゴールディ**「喫煙室です！」

吹き出しの位置だけでなく**藤崎の質問→ゴールディの返答**の順が右→左・上→下で読めることを必須とする。

**見えない出来事**：藤崎は能力を失った後の通常のスリ技術で、ゴールディのタバコとライターを画面外で盗む。手品・異常性・透明化等を新たに描かない。

## 4コマ目（下段左・注意／背景C）

藤崎の優しい微笑みを大きく。背景は白場か薄いトーン。ゴールディは盗難にまだ気付いていない。

- **吹き出し①／コマ右上・丸・尻尾→藤崎**「主任に、タバコはほどほどにと言っといてくれ。**君もね**」
- **無枠の補足文字／藤崎の顔や肩の近く、①の後に目に入る余白**「**匂いでわかる**」
  - **地の文・補足**として扱う。**吹き出し枠なし／四角い説明枠なし／背景板なし／尻尾なし**。藤崎が発声するセリフとして誤認されるような尻尾や括弧を付けない。
  - ゴールディの喫煙が衣服などに残した匂いで、藤崎に見抜かれたことを読者へ示す。超常的な嗅覚がある描写にしない。
- **吹き出し②／左下・丸・尻尾→ゴールディ**「はーい」

**読順**：①主任への注意 → ①内の「君もね」 → 無枠の「匂いでわかる」 → ②ゴールディの返事。①が長文で人物を覆うなら**コマ面積や余白を調整**し、極小文字化しない。

## ページ間・作画固定

- **国内の財団施設**以外の所在地とサイト番号を本編に表示しない。
- 七星／ゴールディ／藤崎は人物設定と採用済み画像を参照。藤崎と七星を混同しない。
- タバコ箱の形やブランド印字は**描画しない**。ライターも全編原則非表示。描く喫煙小物は紙巻きタバコそのもの、必要なら灰皿と煙だけ。
- 紙ファイルは**P001-1で七星→ゴールディ、P001-3でゴールディ→藤崎**と移動し、P001-4以降は藤崎所持。P002ではゴールディは手ぶら。
- 背景は全コマ高精細にしない。人物と吹き出しの面積を優先する。
- 原作設定では藤崎は既にNeutralized。現代のスリに異常能力を使わせない。
- 「君もね」と「匂いでわかる」は本エピソード独自の表現。藤崎の嗅覚・盗みの手口へ新しい異常性を追加しない。
