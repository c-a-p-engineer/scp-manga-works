# EP006 / P002 — いつの間に！？

**状態：文章ネーム・最新改訂版（2026-10-16、発話順・吹き出し本体と尻尾の割当てを明示）。会話内の生成画像は未採用。**

- 日本式右→左、上→下。**5コマ**：上段右1 → 上段左2 → 中段右3 → 中段左4 → 下段横長5。縦書き。
- ページの主眼：ゴールディ帰還 → 私物消失に気付く → 七星の確信犯ぶりで笑う。
- 背景密度：**1=A（喫煙室の再提示）、2=C、3=C、4=C、5=B（喫煙室を最低限だけ残す）**。A＝場所の識別、B＝椅子・看板の一部などのアンカー、C＝白場／淡いトーン／必要な集中線。5は感情と表情を最優先し、豪華な室内描写はしない。
- **文字設計**：通常の発話は丸吹き出し。大きい抗議「Booo!!」のみギャグ用のギザギザ吹き出し。**本体を発話者に寄せ、尻尾は1人に1本**。無枠の地の文はこのページにはない。

## 1コマ目（上段右・喫煙室への帰還／背景A）

ゴールディが医務室から戻る。**書類ファイルは藤崎に渡しており、ゴールディは完全に手ぶら**。七星は自分のタバコを吸って寛いでいる。喫煙室の椅子・看板の一部だけ背景に残す。

- **吹き出し①／コマ右上・丸・尻尾→ゴールディ**「……って言われましたよ」
- **吹き出し②／①より左下・丸・尻尾→七星**「ふーん」

読み順と尾が矛盾するなら、人物の左右位置・吹き出しの高さを微調整する。**尻尾が2本、人物違いへ刺さる、見切れた顔から発話する**を避ける。

## 2コマ目（上段左・ポケットを探る／背景C）

ゴールディがいつも持っているはずの私物を求めてポケットを探る。表情は小さな違和感。背景は白場中心で手元と顔に注目。

- **吹き出し①／上側・小さい丸・尻尾→ゴールディ**「あれ？」

## 3コマ目（中段右・盗難発覚／背景C＋集中線）

空のポケットを確認したゴールディのリアクションを強調。**盗まれたタバコ箱・ライター本体は描かない**。誤った数の指、ポケットの布と手のねじれを避ける。

- **吹き出し①／右上・驚きの輪郭・尻尾→ゴールディ**「タバコとライターがない！？」

## 4コマ目（中段左・七星の薄笑い／背景C）

七星の顔アップ。タバコは口元／片手のどちらか一方に保持し、勝手に本数を増やさない。周辺の喫煙室設備はほぼ描かない。

- **吹き出し①／右上・丸・尻尾→七星**「フッ……爺さんに盗られたな」
- **吹き出し②／左側・驚きの輪郭・尻尾→画面外のゴールディ方向**「いつの間に！？」

画面外のゴールディの声は**コマの左側から来る吹き出し／尾**で明確化し、七星に誤接続しない。

## 5コマ目（下段横長・オチ／背景B）

右に七星、左にゴールディ。七星は悪びれずに一服。ゴールディは頬を膨らませて腕組み／不満顔。**「Booo!!」がこのページで最も強い文字表現**。喫煙室背景は椅子の輪郭・標識程度に抑える。

- **吹き出し①／右上・丸・尻尾→七星**「俺も会うたびにスられるんだ。だからお前に行かせた」
- **吹き出し②／左側・大きなギザギザ・尻尾→ゴールディ**「**Booo!!**」（英字そのまま、ギャグ的な抗議）
