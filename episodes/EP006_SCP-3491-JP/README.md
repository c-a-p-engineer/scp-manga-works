# EP006 — SCP-3491-JP「すくえない男」

- シリーズ：**SCPと一服**
- 話数：**EP006**（今回ネーム用に採番。公開・完成扱いはしない）
- 原作：[SCP-3491-JP「すくえない男」](https://scp-jp.wikidot.com/scp-3491-jp) ／ 著者 mojamoja

- ジャンル：愛煙家の職場コメディ＋人間型SCP紹介＋短い人情の余韻

## ネーム

1. [P001 — お届け物です！](name/P001.md)：**喫煙室から開始**。七星が書類を託し、ゴールディが医務室で藤崎に会う。「主任は？」「喫煙室です！」でやり取り。
2. [P002 — いつの間に！？](name/P002.md)：喫煙室に戻ってタバコとライターの盗難に気付く。七星は知っていて使いに出した。
3. [P003 — すくえない男](name/P003.md)：藤崎の異常性・元外科医の過去・Neutralized後の医療アドバイザーとしての現在、人間型SCPへの理解。

## 制作上のロック

- 原案の会話とギャグ（藤崎がタバコをスる／七星の確信犯／ゴールディ「ぶー」）を保持。
- P001修正：サイト番号を消し、最初も喫煙室、藤崎「主任は？」→ゴールディ「喫煙室です！」。
- ゴールディがタバコと100円ライターを携帯→P001の受け渡し前後に藤崎がスる（**動作は見せない**）→P002で気付く。
- 藤崎はすでに能力喪失済み。漫画内のスリは長年の経験による通常技術。
- **原典設定**：元外科医、両手首から先と保持物を透過、約40年間スリ、警備員を救命した事案の後に異常性喪失、喪失原因は不明、現在は医療アドバイザー。タバコを盗んで健康を注意する。
- **漫画独自**：七星がゴールディを使いに出し、藤崎がその私物を盗む場面。元記事の記録に存在する遭遇と混同しない。
- 七人ではなく、今回の主要登場人物は**3人**。背景モブを増やさない。
- キャラクター参照は [ゴールディ](../../characters/CHAR-001_BAT.md) と [七星](../../characters/CHAR-002_SETTER.md) の承認済み正本を優先。
