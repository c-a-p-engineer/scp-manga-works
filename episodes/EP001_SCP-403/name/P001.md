# EP001 / P001 — 文章ネーム（草稿）

**作品**：SCP財団 ヤニカス研究室 ― SCPと一服 ―  
**話名**：第1話「新人歓迎」／題材：SCP-403  
**ページ**：P001／全2P／4コマ構成（暫定）  
**読み**：日本式・右上→左下（右→左）、日本語縦書き  
**登場**：ゴールディ（バット）、七星（セッター）  
**役割**：新人の初登場と、七星の怪しい歓迎。P001の終点ではSCP-403を明かさない。

## 重要な演出ロック

- **1コマ目はゴールディの全身を見せる「ブチ抜き」**。人物の頭・足先まで認識でき、縦方向にコマ枠をまたぐ。人物と他コマのセリフは重ねず、読順を妨げない。
- **研究所の外観・地理は見せない**。どこにあるのか分からない研究所「内部」の無機質な通路・耐火区画への扉で舞台を示す。
- 身長差は **ゴールディ約150cm／七星約190cm**。人物・衣装は [CHAR-001](../../../characters/CHAR-001_BAT.md) と [CHAR-002](../../../characters/CHAR-002_SETTER.md) の承認済み基準PNGを優先する。
- **手渡すライターはSCP-403**。見た目は普通のナフサ燃料用ライター。ゴールディの私物の安価な使い捨てライター、七星私物のZippoとは別個の一意な小物。
- 研究室内や通路では喫煙しない。使用場所は専用の**耐火試験区画**。研究室に大型の試験施設があるという設定にはせず、保管中のSCPがある別区画に一時訪れている。

## コマ別ネーム（右上から読ませる）

### 1コマ目 — 右上を起点／縦長・全身ブチ抜き

**画**：研究所内部の無機質な長い通路。無地の隔壁、照明、セキュリティ扉。位置の手掛かりとなる外景やSite名は描かない。小柄なゴールディが軽い荷物を持ち、気だるげに周囲を見る。**立ち姿が縦方向に大きく伸び、コマ枠とコマ間を越えるブチ抜き**。頭から靴まで全身が読めるようにし、金髪ハーフアップ・赤いジト目・だぶついた白衣・黒ネクタイ・スラックスを見せる。

**ゴールディ（普通・ぼやき）**「初日からこんな辺鄙なところ？」

**ビート**：施設の見知らぬ閉鎖感と、ゴールディの小柄な全身ビジュアルを同時に紹介する。

### 2コマ目 — 上段左／対面、軽いあおり

**画**：通路の奥から七星が現れる。白衣姿、眼鏡、無精髭、熊のように大柄。ゴールディと対面した構図で約40cmの身長差を見せる。七星はくたびれた表情だが気安い。

**七星（低い通常声）**「俺が研究室の主任研究員、七星だ」

**ビート**：主任の登場、見た目の迫力と穏やかな第一印象。

### 3コマ目 — 下段右／ライターと手元に視線集中

**画**：七星が古びた金属製ライターを差し出す。SCP-403を識別できるラベルはこの時点では見せない。背後には一般の喫煙室ではなく耐火試験区画へ続く扉。ゴールディがライターを受け取ろうと手を伸ばす。余白を残して会話を読みやすく。

**七星（穏やかな歓迎）**「よく来たな。新人歓迎だと思ってな」

**七星**「これでタバコをあそこで吸ってきな」

**ビート**：歓迎の裏に別の狙いがあることを、絵だけで薄く匂わせる。

### 4コマ目 — 下段左／ゴールディ表情の寄り、大きめ

**画**：いつものジト目が一転して目を輝かせるゴールディ。SCP-403を受け取って満面の笑み。背後で七星がごくわずかに悪い笑みを浮かべる。ライターはゴールディの手中（受け渡し完了）。

**ゴールディ（嬉々として）**「タバコを吸うのが仕事！？」

**ゴールディ（勢いよく）**「最高ですね！」

**ページ終端**：喜ぶ新人と、怪しく笑う主任。次ページで意味が反転する。

## P002への継続状態

- 場所は同じ施設の耐火試験区画へ移る。研究室そのものではない。
- ゴールディは**SCP-403を受け取って所持**。まだ着火していない。
- 七星はゴールディが最初は喜ぶと知っている。異常性をゴールディに説明していない。
- 峰は第1話には登場させない。
- 本ページにはSCPの原理やナンバーの説明文を載せない。
