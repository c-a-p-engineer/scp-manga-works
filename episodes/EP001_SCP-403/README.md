## 制作方針と裏設定

- **場所の分からない研究所内部**を描く。施設外観・Site番号・所在を明示しない。
- ゴールディは配属先の研究室へ直行したのではなく、**保管されているSCP-403の使用のため先に別施設へ招かれている**（読者には明かさない）。
- SCP-403は渡された**単一のライター**。私物の100円ライター／Zippoとは区別。
- 試験区画でのみ喫煙・着火を描く。分析研究室や通路と区画を混同しない。
- **原作の収容・追加実験中止条件と異なる新人歓迎での使用**は本シリーズの脚色。確定稿で整合性説明の要否を再評価する。
