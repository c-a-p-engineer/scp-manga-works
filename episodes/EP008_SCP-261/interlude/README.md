## 内容
実験記録にあった「青いタバコ21本（青い煙）」「ガムシガレット5本（噛むガム）」「潰したタバコ3本を投入して出た鍵開け道具入りキャラメル」を紹介。最後はゴールディがタバコで買える点に驚き、七星が突っ込む。

- 全1P・5コマ、右から左読み。中段右：青いタバコ／左：ガムシガレット。下段右：キャラメル／左：オチ。
- タブレット1台の画面に表示された**独立した3件の過去記録**。ガムシガレットはタバコそのものではない。
- キャラメルは**1個**。包装された状態と割った断面は同じ商品の説明図として描く。
- 実験内容は[英語版追加実験記録](https://scp-wiki.wikidot.com/experiment-log-261-ad-de)を直接の出典とする。
