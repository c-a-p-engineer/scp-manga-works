## 内容
青い煙が出るタバコ21本、ガムシガレット5本、潰したタバコ3本を投入すると出てきた鍵開け道具入りキャラメル。過去の別々の実験記録3件を紹介し、ゴールディが「タバコで支払える」点に驚くオチ。

- 1P・5コマ、右から左読み。中段右：青いタバコ／中段左：ガム／下段右：キャラメル／下段左：オチ。
- 実験記録はタブレット内の過去資料。ガムシガレットは本物のタバコではなくガム。
- キャラメルはひとつの出現品の包装状態と断面を示した記録表現。
