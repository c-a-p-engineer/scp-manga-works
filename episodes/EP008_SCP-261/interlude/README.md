# EP008 / SCP-261 幕間「タバコと自販機」

**状態：文章ネームv1草稿保存済み／画像未生成／未公開（2026-10-17）**

[EP008本編「異次元自販機」](../README.md)から派生した**独立した1ページの幕間**。本編（3ページ／v1.3改訂草稿）の一部には数えず、EP009にも採番しない。

## 収録するSCP-261の追加実験記録
1. 500円 → 青いタバコ21本。ブルーベリー味、青い煙。
2. 500円 → ガムシガレット5本。火・煙なし、5分噛むと軽いニコチン感。
3. 大阪の矯正施設で通貨として使われた潰したタバコ3本 → 鍵開け道具入りキャラメル。

**編集方針**：自販機に投入した物・出た物・効果を一目で理解できる5コマ。ゴールディが「タバコでも払える」点に食いつき、七星が「中身は脱獄道具だぞ」と突っ込む。
