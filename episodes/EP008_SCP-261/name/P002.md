# EP008 / P002 — 文章ネーム v1.3（ケーキの実験記録①）

**作品**：SCPと一服／EP008「異次元自販機」／SCP-261  
**状態**：改訂草稿・作者未採用／2026-10-17  
**ページの目的**：1つの過去実験の因果を、**投入→出現→Dクラス試食→発症→死亡**の順に見せる。  
**構成**：5コマ。日本式右上→左下。台詞縦書き、記録枠は横書き。

## 読順と物理配置

```text
┌────────────────────────┐
│ ① 上段横長：300円投入→ケーキが出る       │
├────────────┬───────────┤
│ ③ 中段左：発症     │ ② 中段右：試食     │
├────────────┼───────────┤
│ ⑤ 下段左：死亡記録 │ ④ 下段右：倒れる   │
└────────────┴───────────┘
読順 ①→②（右）→③（左）→④（右下）→⑤（左下）
```

### ① 上段横長｜実験記録①・何が出た？
- **画**：再現イメージ。SCP-261の取出口から、白いケーキ一切れが入った**透明なプラスチック箱**が出てくる。装置そのものは描きすぎず、**取出口と商品**の連結を明確に。
- **資料文字（四角い実験記録ラベル）**：「実験記録①」「投入金額：300円」「出現品：『食べてみて』」
- **台詞なし**。「300円がケーキの価格」と見せない。ケーキ容器の外側に「食べてみて」以外の成分表示を創作しない。

### ② 中段右｜誰が食べる？
- **画**：過去の簡素な実験室。識別できる**Dクラス職員1人**がケーキをフォークで一口食べる。実験担当者は画面外、モブ研究員を描かない。ゴールディと七星は映像記録の閲覧者であり実験室にいない。
- **資料文字（簡素なラベル）**：「被験者：Dクラス」「試食」
- **効果音**：「ぱく」。Dクラスのセリフは不要。

### ③ 中段左｜直後
- **画**：同じDクラスが**食べてすぐ痙攣する**。口元に手をやり、椅子が傾く。症状は身体の動きで示す。異常に膨らんだ頭部・飛び散る血など、原作にない視覚演出を加えない。
- **資料文字（小さな実験記録ラベル）**：「直後、痙攣」
- **台詞なし**。②と**同じ人物・服・ケーキの配置**を維持する。

### ④ 下段右｜倒れる
- **画**：同じDクラスが床へ崩れ落ちる。机と椅子は最小限。視線が**倒れた身体→次コマの記録**へ自然に移るよう配置。
- **台詞なし**。誇張されたグロテスク演出や、新しいDクラスを追加しない。

### ⑤ 下段左｜実験結果
- **画**：再現映像が止まり、タブレットの**結果欄**へ切り替わる。喫煙室のゴールディの驚いた小さな顔を端に入れる。端末画面に商品名や金額を**再掲せず**結果だけ大きく見せる。
- **資料文字（端末横書き）**：「結果：死亡」「死因：脳の膨張」
- **ゴールディ**「……ケーキで？」
- **組版**：尻尾はゴールディへ1本。結果文字は大きく、記録枠に尻尾を付けない。
- **出口**：軽食を食べただけなのに死亡したと理解したまま、次の実験記録へめくる。

## 事実と演出の境界
- 原作：300円投入、透明容器の白いケーキ、Dクラスによる試食、即座の痙攣、死亡、死因は脳の膨張。
- 監視カメラ風の構図と被験者のポーズは漫画の再現演出。原典が記していない被験者番号や実際の映像撮影方法は断定しない。
- **コーン缶の記録はこの版から削除**。別実験を1ページへ押し込み、因果を曖昧にする問題を解消する。
