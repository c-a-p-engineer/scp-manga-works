# EP008 / P002 — 文章ネーム v1.4（ケーキ実験を因果で描く）

**作品**：SCPと一服／EP008「異次元自販機」／SCP-261  
**状態**：品質改善草稿・作者確認前（2026-10-17）  
**ページ目的**：「投入300円→ケーキ出現→Dクラス試食→即時痙攣→死亡」を**同じDクラス職員**の行動で理解させる。  
**構成**：5コマ、右上→左下。原作照合は [原文追加ログ](https://scp-wiki.wikidot.com/experiment-log-261-ad-de)・[日本語訳](https://scp-jp.wikidot.com/experiment-log-261-ad-de)。

## 物理コマ割り
```text
┌────────────────────────────┐
│ ① 上段全幅（約24%）｜投入とケーキ          │
├──────────────┬─────────────┤
│ ③ 中段左：痙攣   │ ② 中段右：試食   │
├──────────────┼─────────────┤
│ ⑤ 下段左：記録   │ ④ 下段右：倒れる │
└──────────────┴─────────────┘
読順：①→②右→③左→④右→⑤左
```

### ① 上段全幅｜何が出た？
- **画**：過去の実験再現。紙面右側に自販機の硬貨口を小さく、紙面左側に取出口から現れた**透明プラスチック箱の白いケーキ1切れ**を大きく描く。因果の方向は右「投入」→左「出現」。SCP自販機の全面・研究室背景を過剰に描き込まない。
- **記録文字（横書き・枠あり）**：「投入：300円」「出現：『食べてみて』」
- **台詞なし**。商品に架空の成分表を増やさない。「300円」は金額を入力した記録であり値札ではない。

### ② 中段右｜誰が食べた？
- **画**：**オレンジ色の一体型つなぎ**を着たDクラス職員（実験①は匿名成人男性、短い黒髪・無精髭なしで簡略化）。白衣でも灰色の服でもない。実験室の簡素な椅子に座り、ケーキをフォークで一口口へ運ぶ。フォークを持つ片手と、机のケーキの位置を次コマへ引き継ぐ。
- **ラベル（小さい四角）**：「被験者：Dクラス」
- **効果音**：「ぱく」
- **台詞なし**。背景・研究員モブは不要。

### ③ 中段左｜直後に痙攣
- **画**：②と**同じ髪・顔・オレンジつなぎのDクラス**。食べた直後に身体が激しく痙攣し、持っていたフォークが手から離れる。椅子が傾く。身体の異常は動きで見せ、頭が破裂するなど非原作の描写は禁止。
- **ラベル（小さい四角）**：「直後、痙攣」
- **台詞なし**。読者には②の直後だと分かるよう、同じ側の机と椅子の配置を維持。

### ④ 下段右｜死亡
- **画**：Dクラス職員が床に崩れ落ちる。**つなぎのオレンジ色を連続**させて、別人に見せない。大きく異なるカメラ視点は避け、直前の傾いた椅子が近くに残る。グロテスクな血液や人体の変形は描かない。
- **台詞・ラベルなし**。意図的に無音にする。

### ⑤ 下段左｜結果が事務的
- **画**：喫煙室に戻り、タブレットに**結果の2行だけ**。その横に驚いているゴールディの小さな顔。七星の顔や喫煙室背景は省略可。P001からの一本目のタバコをゴールディは指に持ったまま。
- **結果文字（端末横書き）**：「死亡」「死因：脳の膨張」
- **ゴールディ**「……ケーキで？」
- **組版**：右側にタブレット表示、左側にゴールディの反応（ゴールディの本人位置に引きつける）、吹き出しの尻尾→ゴールディ1本。文字は死因が十分読める大きさ。
- **ページ出口**：タブレットの記録が切り替わるところで止める。次の実験は「何が出た→どうなった」が読める順で始める。

## 原作と演出の境界
- **原作**：300円の投入で「TASTE ME」、透明の箱に白いケーキ1切れ。Dクラスが試食して即座に痙攣、ほどなく死亡。脳が膨張したことが死因。身長＋7インチ、体重＋13.6%という検死所見もあるが、本漫画では**情報量削減のため印字せず**、逆に嘘の所見を創作しない。
- **創作演出**：被験者の年齢・髪型・性別、実験室の撮影構図は漫画上の演出。実験①ではオレンジつなぎの同じ男性1人に固定して識別しやすくする。
- 別件の試食記録をこのページへ戻さない。複数ログを1ページへ詰めて読者が取り違える再発を防ぐ。
- SCP-261の硬貨投入と商品生成の間に、原作にない数字・詳細UI・顔のないモブを追加しない。
