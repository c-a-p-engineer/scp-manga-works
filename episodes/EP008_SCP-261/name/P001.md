# EP008 / P001 — 文章ネーム v1.2

**版**：v1.2／文章ネーム草稿（2026-10-17、作者未採用）  
**作品**：SCPと一服／EP008「異次元自販機」／SCP-261  
**方向**：日本式RTL（上から下、同じ段は右→左）／台詞は縦書き  
**舞台**：専用喫煙室で過去の実験記録を読む。実験コマは**原作の記録をもとにした再現イメージ**であり、現在この研究室が実験しているわけではない。  

## 共通の固定条件
- 喫煙室の2人は原則**画面右にゴールディ、左に七星**。ふたりの承認済み基準画像を人物同一性の正本とする。
- ゴールディは小柄で華奢、金髪ラフなハーフアップ、深紅のジト目。七星は大柄、黒髪、黒縁眼鏡、無精髭、白衣、緩い濃紺ネクタイ。
- タブレットは**卓上の1台のみ**。七星は右手でタバコを保持、操作は左手。ゴールディはP001で喫煙中、P003③で一本目を消してP003④で**次のタバコに点火する**。点火動作を描くのはP003④のみ。タバコ・灰皿・ライターの出現と消失を追跡する。
- 喫煙室の室内描写はP001冒頭のみ。会話は白・薄トーンを中心に、記録の異常性とゴールディの反応へ情報予算を使う。
- 実験記録中に現れるDクラスはそれぞれ**別の被験者**。必要以上にモブの細部を描きこまず、死の瞬間は倒れ込むシルエット・無音・記録文字で表す。
- 漫画に出す文字は指定された台詞・資料文字・効果音のみ。吹き出しは1発話1話者で尻尾は原則1本。画面外の事実説明は**無尻尾の四角い実験記録枠**。
- P001だけ作品名「SCPと一服」、題材「SCP-261」、サブタイトル「異次元自販機」を表示。P002/P003にタイトル、サブタイトル、制作番号・コマ番号を描かない。
- 原作記録の再構成箇所：ケーキ（300円・脳の膨張による死亡）、コーン缶（500円・試食後に急死）、プラングルス（1000円・1人目終了処分後も摂食、2人目で実験中）。それぞれ別の過去実験記録であり、同日の連続試食だと断定しない。

**ページの役割**：七星が提示したDクラス実験ログからSCP-261の説明へ進み、「試食なら楽そう」という期待を作る。

**4コマ**：①上段横長 → ②中段右 → ③中段左 → ④下段横長。

```text
┌───────────────────────┐
│ ① 上段横長／「これ見ろ」                    │
├───────────┬───────────┤
│ ③ 中段左／疑問     │ ② 中段右／Dクラス実験ログ   │
├───────────┴───────────┤
│ ④ 下段横長／期待                        │
└───────────────────────┘
読順 ①→②→③→④
```

### ① 上段横長｜これ見ろ
**画**：喫煙室の2人。右にゴールディ、左に七星。卓上にタブレット1台と灰皿。二人は喫煙中。七星は右手に点火済みのタバコを持ち、左手でタブレットをゴールディへ示す。作品名・題材・サブタイトルはこのコマの余白のみ。

**発話① 七星**「これ見ろ」  
**吹き出し**：七星に尻尾1本。短く強めの視線誘導で次の画面アップへ。

### ② 中段右｜Dクラス実験ログ
**画**：タブレットのアップ。「SCP-261」とDクラス職員を使った実験ログの一覧が表示される。自販機のサムネイルを小さく添え、ログを見せられたことが分かる構図。画面に出す資料本文は最小限。

**資料文字（横書き／無尻尾）**：「SCP-261」「Dクラス職員を用いた実験ログ」  
**発話 ゴールディ（画面外）**「Dクラス職員を使った実験ログ？」  
**吹き出し**：画面外のゴールディへ尻尾1本。画面端に本人の手または袖を見せ、話者を確定する。

### ③ 中段左｜SCP-261の説明
**画**：タブレット内のSCP-261の写真を大きめに表示。黒い自販機とキーパッドが分かる。ゴールディの小さな横顔を端に置いて「説明を聞いている」関係を維持。自販機の実物が喫煙室に出現したようには描かない。

**資料文字（端末内・横書き）**：「SCP-261」「Safe」  
**発話① 七星**「異常な自販機だ」  
**発話② 七星**「金と3桁の数字を入れると、妙な食い物が出てくる」  
**吹き出し**：①右寄り→②左寄り、七星に各尻尾1本。端末内の資料文字に尻尾をつけない。

### ④ 下段横長｜試食実験
**画**：二人のミドル。右ゴールディは少し気楽な顔。左七星は左手でタブレットをスクロールし、右手のタバコを持ったまま。背景は白または薄いトーン。実験ログの先頭へ進む動きでP002へ繋ぐ。

**発話① ゴールディ**「へえ、試食実験ってことですか」  
**発話② 七星**「まあな」  
**発話③ 七星**「で、そのログがこれだ」  
**吹き出し**：右上①ゴールディ→左寄り②七星→下寄り③七星。各尻尾1本、ページ出口を妨げない。

**次ページへの出口**：記録が切り替わり、P002のケーキ実験へ。
