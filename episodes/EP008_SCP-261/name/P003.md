# EP008 / P003 — 文章ネーム v1.4（プラングルスと財団の余韻）

**作品**：SCPと一服／EP008「異次元自販機」／SCP-261  
**状態**：品質改善草稿・作者確認前（2026-10-17）  
**ページ目的**：ケーキより異様な「やめられない試食→終了処分後も摂食→2人目に続行」を絵で理解させ、ゴールディの反応と七星の立場で締める。  
**構成**：4コマ、右上→左下。最終コマにページの約55%を配分する。

## 物理コマ割り
```text
┌──────────────┬─────────────┐
│ ② 左上：止まらず │ ① 右上：商品 │
├──────────────┴─────────────┤
│ ③ 中段全幅：1人目の結末→2人目（約25%）  │
├────────────────────────────┤
│ ④ 最下段最大：財団と次の一本（約55%）   │
└────────────────────────────┘
読順：①右上→②左上→③内側も右から左→④
```

### ① 上段右｜実験記録②・出現品
- **画**：過去の別の実験。SCP-261の取出口から出てきた筒型ポテトチップス。サワークリームオニオン味のプリングルスに似るが、容器のマスコットの**肌は赤く、悪魔めいた顔**。ロゴの細部は簡略化。資料の見せ場は投入額と異常な容器。
- **資料文字（横書き／記録ラベル）**：「投入：1000円」「出現：プラングルス」
- **台詞なし**。1000円は商品の値札でなく実験時の投入金額。

### ② 上段左｜開けた瞬間
- **画**：**オレンジ色の一体型つなぎ**を着た女性Dクラス職員（この実験の1人目）。耳にかかる短い髪。筒を開けて「ポン」と音がすると、そのまま一心不乱に食べ続ける。指→チップス→口の経路を一目で分かるよう描き、残像は**食べる手にのみ**限定する。背景は白、モブは描かない。筒の形状・赤いマスコットは①と一致。
- **効果音**：「ポン」「もぐ　もぐ　もぐ」
- **資料文字（小ラベル）**：「開封後、食べる手が止まらない」
- **台詞なし**。単なる大食いギャグにはしない。

### ③ 中段全幅｜一人目の後にも二人目
- **画の全体**：喫煙室で二人が見ている**タブレット1台の画面**をコマ中心に据える。画面内に過去記録の**小さい静止画2点を右→左**へ。どちらもオレンジつなぎの**別人**だと分かる。
- **画面右・1人目**：②と同じ髪の**女性Dクラス**。終了処分後も筒を握ってチップスを食べようとする異様な手元。画面外の職員の**手だけ**が筒を引き離している。射撃・注射など、原作に明示されない具体的な処分方法は描かない。表情や身体の状態はシルエットで整理し、異様さだけ伝える。
- **画面左・2人目**：髪型の違うオレンジつなぎのDクラス。プラングルスを持ち、試験が続いている。1人目を突然服だけ変えた絵にしない。
- **端末資料文字（右の画）**：「1人目：終了処分後も食べ続けた」「筒を強制回収」
- **端末資料文字（左の画）**：「2人目：実験継続中」
- **発話 ゴールディ**「……二人目？」
- **組版**：ゴールディの小顔を手前右端に置いて吹き出し尻尾→本人へ1本。端末資料には尻尾を付けない。右から左へ1人目→2人目の順に読めることを優先。
- **喫煙動作**：ゴールディは**一本目のタバコを灰皿で消す**。手と灰皿を画面端に小さく描き、次のコマの着火への前提を作る。

### ④ 下段大ゴマ｜財団
- **画**：静かな専用喫煙室。**右に小柄なゴールディ、左に大柄な七星**。背景は白地とごく薄い影に抑え、巨大な最終コマにセリフの余白を先に確保する。ゴールディは**次の2本目のタバコ**を口元に運び、安価な使い捨てライターで火をつける。片手はライター、もう片手はタバコの補助。火があるのはライターの先端だけ。七星は自分の右手のタバコを持って落ち着いている。タブレットは同じ1台をテーブル上に置く。
- **発話① ゴールディ（作者指定、改変禁止）**「SCPって薄々感づいてましたけど……死ぬんですねー　財団も酷い」
- **発話② 七星（作者指定、改変禁止）**「だがSCPなんて、危険物を野放しにもできんからな」
- **発話③ 七星の補足（作者指定、改変禁止）**「Dクラスは死刑囚とかが使われてるから気に病むな」
- **文字順と領域（必須）**：
  - ①右上に大きめの縦書き吹き出し。尻尾は**ゴールディ1本**。
  - ②左上に大きめの縦書き吹き出し。尻尾は**七星1本**。
  - ③最後に読む**左下の素の縦書き文字**。**枠なし・背景なし・吹き出しなし・尻尾なし**。②の七星からの言葉であることが自然に分かる近接位置。作者ナレーションの独立説明枠にはしない。
  - 台詞を小さくして入れるのは禁止。顔・着火中の手を小さくするか、背景を削って文字スペースを確保。③の後に新しいツッコミや解説は足さない。
- **余韻**：炎と二人の表情で結び、文字が見切れない余白を四辺に確保する。

## 事実・創作の境界
- 原作のプラングルスはサワークリームオニオンの類似商品だが、**赤く悪魔めいた顔のマスコット**を持つ。女性Dクラスが開封した途端、食べることを止められなくなる。筒は底なしのようである。
- **英語原文では最初の被験者は終了処分後も食べ続け、筒を強制的に取り上げられた**。日本語訳の「解雇」は通常の退職の意味に取らず、原文の `termination` を採る。原作にない処分方法を創作しない。
- 現在の実験記録は二人目。漫画では2人目も**オレンジつなぎ**、ただし別人だと分かる髪型にする。本シリーズの標準的Dクラス衣装はオレンジの上下つながったつなぎ。
- 七星の最後の無枠補足は**登場人物自身の価値判断**であり、全てのDクラスが死刑囚だという普遍的な断定にはしない。
