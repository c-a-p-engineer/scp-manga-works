# EP008 / P003 — 文章ネーム v1.3（プラングルスの実験記録②と結語）

**作品**：SCPと一服／EP008「異次元自販機」／SCP-261  
**状態**：改訂草稿・作者未採用／2026-10-17  
**ページの目的**：1人目が処分後も食べ、2人目へ実験が続く異様さを読み取らせ、財団へのゴールディの評価と七星の認識の違いで締める。  
**構成**：4コマ。日本式右上→左下。**最終④をページの約半分**にして、長い指定台詞と地の文を可読化する。

## 読順と物理配置

```text
┌────────────┬───────────┐
│ ② 上段左：止まらず │ ① 上段右：1000円   │
├────────────┴───────────┤
│ ③ 中段横長：処分後も／2人目へ             │
├────────────────────────┤
│ ④ 下段大ゴマ：次のタバコに点火・財団論      │
└────────────────────────┘
読順 ①（右上）→②（左上）→③→④
```

### ① 上段右｜実験記録②・次に出た物
- **画**：別の過去実験の再現。SCP-261の取出口から筒型ポテトチップスが出た直後。商品はサワークリームオニオン味の有名商品に似ているが、マスコットだけ赤い悪魔のような顔。
- **資料文字（四角い実験記録ラベル）**：「実験記録②」「投入金額：1000円」「出現品：プラングルス」
- **台詞なし**。P002のケーキとは**別件**。同じDクラス・同じ購入日と断定しない。

### ② 上段左｜開けた途端
- **画**：別のDクラス職員が筒の蓋を開ける。「ポン」の直後、手が止まらずチップスを食べ続けている。短い残像や連続する「もぐ」で時間経過を表し、筒が**底なしらしい**ことを見せる。
- **効果音**：「ポン」「もぐ もぐ もぐ」
- **資料文字（簡素な実験記録ラベル）**：「開封後、摂食が止まらない」
- **台詞なし**。手・口・筒の関係は明確にし、モブを増やさない。

### ③ 中段横長｜処分しても、二人目
- **画**：喫煙室へ戻る。**右にゴールディ、左に七星**。タブレットに2行だけの実験記録が大きく表示される。背景は白または薄いトーンにし、**記録文字そのものが見せ場**。ゴールディは一本目のタバコを灰皿で消す。
- **資料文字（端末横書き）**：
  - 「1人目：終了処分後も食べ続けた」
  - 「2人目：実験継続中」
- **ゴールディ**「……二人目？」
- **組版**：右上の小さな吹き出し、尻尾→ゴールディ。七星は無言。1人目・2人目が**同じ筒の別の被験者**であると伝える。**終了処分後も食べ続けた**点を省略しない。
- **状態変化**：ゴールディの一本目が消える。次のコマだけで新しいタバコを点火する。

### ④ 下段大ゴマ｜財団
- **画**：大きな余白のある静かな喫煙室。**右にゴールディ、左に七星**。ゴールディは**次のタバコ**を口元に運び、使い捨てライターで着火。ライターを持つ手とタバコに添える手は別、指・火・煙の状態を確実に区別する。七星はタバコを吸いながら、特に怒るでも笑うでもない疲れた表情。背景は可能な限り省き、文字の可読性を最優先。
- **発話① ゴールディ（指定台詞・改変禁止）**「SCPって薄々感づいてましたけど……死ぬんですねー　財団も酷い」
- **発話② 七星（指定台詞・改変禁止）**「だがSCPなんて、危険物を野放しにもできんからな」
- **七星の補足（指定文言・改変禁止／地の文扱い・枠なし・背景なし・吹き出しなし・尻尾なし）**「Dクラスは死刑囚とかが使われてるから気に病むな」
- **組版**：①右上（ゴールディへ尻尾1本）→②左上（七星へ尻尾1本）→③左側下方またはコマ最下部に**素の縦書き文字**。③を吹き出し・説明枠へ戻さない。③は七星の発言を地の文風に見せるものであり、無人格の作者ナレーションではない。
- **ラスト**：最後の台詞の後に新たなツッコミや説明は足さない。ゴールディの着火動作と沈黙で締める。

## 事実と演出の境界
- 原作：1000円投入の「プラングルス」、開封後に抑えられない摂食、底なしに見える筒、1人目が**termination（終了処分）後も食べ続け**、現在2人目で試験中。
- 「死亡してすぐ別の人へ切り替えた」という具体的な時系列・処分方法は原典から断定しない。
- Dクラスに死刑囚が使われるという七星の補足は財団設定に基づくが、**全員が死刑囚という意味にはしない**。
