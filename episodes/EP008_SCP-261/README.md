# EP008 — SCP-261「Dクラス職員」

**状態：文章ネームv1草稿／画像未生成／未公開**

- 主題：危険な試食に投入されるDクラスと、犠牲者を出しても実験を継続する財団の事務的な冷酷さ

## 留意点
- 漫画化する各実験記録は別件。連続して同じ被験者を投入した設定にはしない。
- 「プラングルス」の日本語訳にある「解雇」は、原文の `termination` を参照し、ネームでは「終了処分」として意味を整理。
