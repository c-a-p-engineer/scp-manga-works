# EP008 — SCP-261「異次元自販機」

**状態：文章ネームv1.2改訂稿／画像未生成／未公開**

- ページ：P001〜P003（計3ページ、13コマ予定）
- 正式シリーズ：SCPと一服
- 主題：危険な試食に投入されるDクラスと、犠牲者を出しても実験を継続する財団の事務的な冷酷さ
- 登場：ゴールディ、七星。実験記録中の匿名Dクラス職員（再現イメージ）
- 舞台：研究室隣接の専用喫煙室。実験記録はタブレットで閲覧する過去資料。
- 原作：[SCP-261](https://scp-jp.wikidot.com/scp-261)／[実験記録261-Ad-De](https://scp-jp.wikidot.com/experiment-log-261-ad-de)

## 留意点
- 漫画化する各実験記録は別件。連続して同じ被験者を投入した設定にはしない。
- 「プラングルス」の日本語訳にある「解雇」は、原文の `termination` を参照し、ネームでは「終了処分」として意味を整理。
- すべて既存実験資料の**再現イメージ**であり、この研究室が直接実験した事実は創作しない。
- 作者の指定台詞とP003④の無枠地の文を反映した改訂稿。画像はまだ完成扱いしない。
