## 留意点
- ケーキとプラングルスは**別件**。プラングルス内の1人目と2人目は同じ商品を試した別被験者。
- 「プラングルス」の日本語訳にある「解雇」は、原文の `termination` を参照し、ネームでは「終了処分」とする。処分**後も食べ続けた**点を省略しない。
- すべて既存実験資料の**再現イメージ**。研究室が実験した事実は創作しない。投入金額は商品価格ではない。原典にない入力番号・Dクラス番号・実施日を補わない。
- v1.2で扱った**コーン缶の別実験はv1.3では削除**。英語原文は腹痛後の終了処分・解剖という流れであり、商品の影響で即死したと描かない。
- 作者の指定台詞とP003④の無枠地の文は保持。v1.2に基づく会話内生成画像は**旧案の候補**であり、v1.3準拠の完成画像としては扱わない。
