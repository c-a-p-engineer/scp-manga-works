## 原作と共通方針
- [SCP-261](https://scp-jp.wikidot.com/scp-261) ／ [Experiment Log 261 Ad De](https://scp-wiki.wikidot.com/experiment-log-261-ad-de) ／ [出典・ライセンス](CREDITS.md)

- SCP-261は投入金額と3桁入力で予測できない食品が出る。金額は商品の値札ではない。
- 漫画の現在時制では喫煙室で過去の実験ログを読んでいる。原作と創作演出を混同しない。
