## 同一性・来歴
- 元画像はチャット内の漫画画像生成結果として存在し、ユーザーがルート直下にアップロードしたもの。ローカル生成ファイルのGit blobアルゴリズム（`SHA1("blob "+size+"\\0"+bytes)`）による照合でも、GitHubの4ファイルのSHAにすべて一致。
- 画像の移動に際して再生成・画像補正・再エンコードはしていない。移動したコミット：[44a0a60](https://github.com/c-a-p-engineer/scp-manga-works/commit/44a0a601c54b60c1ab7673552a55103de48a7734)。
- 旧ファイルは現在のmasterルートから取り除いた。履歴のGit Blobは保たれる。
- ユーザーが公開した後は、作品名・説明・ページ数・タグ・AI作品分類・公開日時について**pixiv実投稿**が優先。ネームは制作意図の履歴。

## 目視メモ・既知差分
- P002冒頭の2発話は七星であり、最終画像でも七星側の吹き出しにまとめられている。
- P003の財団の例外に関する会話では、背後にSCP-682を想起させる巨大な爬虫類のイメージがある。
- P004の**ページ最上部のシリーズタイトルは削除済み**で、中段の資料見出しは「日本の要注意団体」。
- **P004の左下の団体名称が正規表記「酩酊街」ではなく「酪町街」に見える**（生成画像内の文字誤り）。公開済み画像を無断修正せず、問題点として記録する。
- 団体ロゴ／紋章はAI生成候補であり、公式マークとの一致・素材ライセンスは未確認。原典の公式ロゴを収録したと断定しない。
