# EP004 — 「財団と要注意団体」

**作品：SCPと一服／本編EP004／全4P・2026-10-14 pixiv公開済み・採用完成PNG4枚をGitHub保存済み**

- 形式：組織紹介編。単一SCP番号ではなく、SCP財団および要注意団体（GoI）を題材とする。
- 舞台：日本の小規模データ解析研究室に隣接する専用喫煙室。
- 登場：七星（セッター）、ゴールディ（バット）。
- 読み順：日本式右上→左下／台詞は縦書き基本。
- 演出：キャラクターの掛け合いと、団体ロゴ・短い解説を示す作中資料コマを組み合わせる。
- 公開先：**[pixiv作品 150837706](https://www.pixiv.net/artworks/150837706)**（2026-10-14 13:21 JST公開）。公開タイトル「財団と要注意団体｜SCPと一服」。
- 作品紹介・公開日時・タグ・クレジットの正本は[PUBLICATION.md](PUBLICATION.md)。完成PNGは[画像管理](images/README.md)。

## 人間の演出指定・保持する条件
- マスターが決めた全4P構成、会話の軸と話者、海外・国内の各団体の選択を保持。
- P003、七星「もちろん、財団にも例外はあるがな。」の背景に、**SCP-682を連想させる巨大なトカゲの薄いシルエット**。喫煙室にSCP-682が実在する描写ではない。番号を吹き出しで明かさない。
- 闇寿司は紹介から除外。資料パートを4Pの内側で圧縮し、P003の会話と感情の間を優先。
- 画風、人物同一性、喫煙区域の設定は既存の series/ と characters/ の正規設定に従う。
- 資料コマには団体のロゴ・名称・短い説明を使用。ただし、実際に使うロゴファイルの出典・ライセンス・利用可否は作画前に個別確認する。
- 右上から左下の読順と吹き出し話者対応を最優先。**通常の日本式ページ漫画**でありWebtoon型の全面幅横帯積みではない。P001〜P003も左右分割を利用するv3レイアウト指示へ改訂。P004最下段は右の会話→左のオチの順で読む。各ページのコマ数は文章ネーム段階の構成であり、Blueprint実行済みではない。
