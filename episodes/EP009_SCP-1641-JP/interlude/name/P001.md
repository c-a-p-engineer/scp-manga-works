## 幕間 P001｜誰が作ったコーヒーメーカー？（フロー図版・改訂）

作画形式: 縦長1ページ。右上→左上→中央大コマ→下段右→下段左→最下段の小さな独立コマ。台詞は縦書き。登場人物は参考画像の七星（黒髪・眼鏡・無精ひげ・白衣）とゴールディ（金髪・赤目・華奢・白シャツ）。資料表示面のみ横書き可。全コマに説明を増やさず、図と表情へ情報を分担する。

1. **上段右・導入／2人の中景**。喫煙室。ゴールディが机上タブレットの製造元欄を見る。七星はタバコを持つ。ゴールディ「ところで、これって誰が作ったんです？」／七星「そこが少しややこしい」。ふたりの顔と手元を明瞭に。
2. **上段左・価格の驚き／タブレットの拡大**。超工家電の販売画面、コーヒーメーカーの写真と「999,980円（税込）」が主役。七星（画面外）「販売は超工家電だ」／ゴールディ「約100万円！？」。小さな顔のリアクションを添えてもよい。
3. **中央・ページ最大の全幅コマ／タブレット上の4団体のフロー図**。七星（右端、小さく）「関係はこうだ」／ゴールディ（左端、小さく）「いろいろ絡んでますね……」。図の内容をセリフで復唱しない。表記を以下に限定し、情報の重複や装飾的な架空ロゴを避ける。
   - ノード「夏鳥思想連盟」「超工家電」「東弊重工」「如月工務店」「SCP-1641-JP」。ノード表記は正確に。
   - **確認できる実線**: 夏鳥思想連盟 → 超工家電［製造依頼］、超工家電 → SCP-1641-JP［製造］、**如月工務店 → 夏鳥思想連盟［超工家電を紹介］**。特に「紹介」矢印は如月工務店→超工家電へ誤接続しない。
   - **推定・主張を示す破線**: 東弊重工 → 超工家電［技術の盗用・流出／東弊主張・財団推定］、如月工務店 → 超工家電［流出仲介の疑い］。
   - ※東弊重工が夏鳥思想連盟へ「使用中止の警告」を送ったことは後段で扱う。超工家電 → 夏鳥思想連盟へ「開発依頼」を向けたり、SCP-1641-JP → 超工家電へ「製造」を向けたりしない。
   - 図内は5ノード・4〜5本の矢印・短いラベルだけ。文字が読めなくなるほど詰め込まない。実線・破線の凡例を小さく1か所。
4. **下段右・警告状アップ**。東弊重工から夏鳥思想連盟への書類を見せる。大きく「使用中止のお願い」、ほかの本文は最小限。七星（画面外）「東弊重工は使用中止を警告した」／ゴールディ「じゃあ、やめたんですか？」。レターは作中資料の要約であり原文の逐語再現ではない。
5. **下段左・七星の返答／少し大きめ**。喫煙室。七星がタブレットを閉じた後、一服する（片手でタバコを保持、眼鏡と顔を隠さない）。七星「いや、使い続けてる」。**七星の「その程度で辞めるなら要注意団体やってないわ」の吹き出しは削除。** 追加の台詞や吹き出しを置かず、気だるい表情とタバコの煙を残す。
6. **最下段・細い横長の独立コマ／余韻**。左側にゴールディのみ、半目で納得する顔のアップ。右側は机の縁とごく控えめな灰色の喫煙室背景で自然につなぎ、不要なタバコ箱・灰皿・カップを増殖させない。ゴールディ「確かにその程度で辞めるなら要注意団体にならないか…」。**この一言だけがオチ。** 縦書き、スマートフォンで読める文字サイズ。5コマ目からの読順を守り、空白だけの未完成領域を作らない。
