# EP018 — SCP-3295「ご喫煙ありがとうございます」

**ステータス：文章ネームv2保存済み／画像未生成／未公開（2026-11-03）**

- **作品**：『SCPと一服』本編候補 EP018。
- **題材**：[SCP-3295](https://scp-jp.wikidot.com/scp-3295) — 原作 ObserverSeptember。
- **仮タイトル**：「ご喫煙ありがとうございます」。
- **形式**：カラー縦長2ページ、計7コマ。P001＝3コマ、P002＝4コマ。
- **読順**：右→左、上→下。全会話縦書き。七星＝白吹き出し、ゴールディ＝薄赤。
- **出演**：七星・ゴールディ。財団のSCP-3295喫煙室に入室し、天井のワームホールを発見する。
- **大筋**：入室 → ゴールディ「主任見てください！竜の巣だ！」 → 七星「SCP-3295だ」 → 異常性の紹介 → 電子タバコ対応 → ゴールディの利用普及提案。

- **位置づけ**：既存の[EP017幕間「先駆者」](../EP017_O5/interlude/README.md)は同じSCPのO5-6の契約・除名に焦点。本作は**喫煙室の異常な構造と電子タバコ対応**を中心に描き、幕間とは独立した本編とする。

## 留保・確認点
- 今回の舞台はSCP-3295の一室。常用の研究室隣接喫煙室が恒常的にSCP-3295であるとは確定しない。
- 原典では全財団サイトにSCP-3295が既に存在する。最後の「普及」は**利用促進**として解釈。
- 電子タバコの蒸気吸収開始は2010年1月1日。「最近では」は作者指定台詞として維持。
- 画面へのキャラクター名・コマ番号の印字なし。基準キャラクター画像の同一性を作画時に照合する。
- 文章ネームの固定台詞をユーザー承認なく書き換えない。
- 画像・pixiv公開・作者による作画採用は未実施。文章ネームの保存を完成漫画と混同しない。
