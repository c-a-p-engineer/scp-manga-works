# EP007 / P003 — 文章ネーム（確定稿）

**作品**：SCPと一服  
**話名**：EP007「オブジェクトクラス」  
**ページ**：P003／全3P／4コマ構成  
**読み**：日本式・右上→左下（右→左）、日本語縦書き  
**登場**：ゴールディ（バット）、七星（セッター）  
**場所**：研究室隣接の喫煙室  
**役割**：収容難易度という理解を定着させ、収容方法の改善や異常性の消失でクラスが変わることを示して締める。

## 重要な演出ロック

- P003は**理解の整理ページ**。P002ほど派手にせず、会話を読みやすくする。
- **Neutralized** は「異常性が消失・無力化された状態」として簡潔に紹介する。深掘りしすぎない。
- 最終コマは、解説オチではなく**研究者としての二人の仕事**へ着地する。
- 幕間で扱う「主任を分類するネタ」「財団神拳」はこの本編には入れない。

## コマ別ネーム（右上から読ませる）

### 1コマ目 — 上段右／理解の確認

**画**：喫煙室の二人。ゴールディがタブレットの図を見ながら整理する。七星は落ち着いて聞いている。

**ゴールディ**「つまり、危険度じゃなくて」

**ゴールディ**「どれだけ収容しやすいか、なんですね」

**ビート**：ここで読者にも理解を言語化させる。

### 2コマ目 — 上段左／七星の補足

**画**：七星が頷く。タブレットにはSafe・Euclid・Keterの簡単な比較表示。

**七星**「そうだ」

**七星**「収容方法が改善されれば、クラスが見直されることもある」

**ビート**：解析や研究の意義へつなげる。

### 3コマ目 — 下段右／Neutralizedを問う

**画**：ゴールディがさらに興味を持って尋ねる。タブレットには新たな表示に切り替わる途中の手元。

**ゴールディ**「じゃあ、異常性そのものが消えたら？」

**七星**「その場合はNeutralized」

**七星**「無力化済みだ」

**ビート**：異常性の消失という別軸を短く追加し、話に広がりを持たせる。

### 4コマ目 — 下段左／締め

**画**：ゴールディが納得した顔で一服する。七星もいつもの調子で煙草を吸っている。喫煙室の日常へ自然に戻る。

**ゴールディ**「なるほど」

**ゴールディ**「私たちの解析で、収容を楽にできることもあるんですね」

**七星**「ああ。それも俺たちの仕事だ」

**終端**：オブジェクトクラスの理解と、研究室の役割をきれいに接続して終える。
