## 全ページ共通の固定指示

- **キャラクター同一性**：提供されたゴールディ／七星のキャラクターリファレンスを優先。ゴールディは小柄・華奢、金髪のラフなハーフアップ、深紅のジト目。七星は黒髪、黒縁眼鏡、無精髭、大柄な体格。ともに白衣とネクタイ。リファレンスのポーズを丸写ししない。
- **舞台・位置**：喫煙室。基本は画面右にゴールディ、画面左に七星。卓上に**同一のタブレット1台**と灰皿。手・煙草・視線・タブレットの操作状態を繋げる。タバコを持つ手で同時に別の物を操作しない。
- **背景予算**：喫煙室の全景を見せるのはP001の最初だけ。その他のコマは**無地／白／控えめなトーン／簡素な室内線**を積極的に使用。美麗なガラスの反射、装飾植物、夜景、金属光沢、過剰な煙や髪の細密描画で主眼を奪わない。作画の質は落とさず漫画の情報密度を最適化。
- **資料と吹き出しの表記分離**：会話の吹き出しは原則「セーフ」「ユークリッド」「ケテル」「ニュートラライズド」の日本語読み。タブレットの公式クラス表記は **Safe / Euclid / Keter / Neutralized**（端末内は横書き）。吹き出しへ英単語をどうしても残す場合は**単語全体を横倒し**、1英字は正位、2英字は縦中横を候補にして可読性で選ぶ。縦の一文字ずつ積み重ねは避ける。
- **吹き出し**：発話は話者に所有され、尻尾は原則1本で該当人物に結ぶ。台詞と吹き出しの位置を右→左の発話順へ対応させる。資料文字は発話ではないので尻尾を付けない。
- **ページ表示**：タイトル「SCPと一服」と副題「オブジェクトクラス」はP001のみ。P002・P003にタイトルやページ番号・コマ番号を描かない。
- **図解**：ボタン、猫、箱、異常性消失は七星がタブレットで見せる**仮想イメージ**であり、喫煙室に実物が出現した設定にしない。SCP-403のライターをEuclid→Safeの再分類事例として誤用しない。
- **本編と幕間の区別**：本編のオチは世界破滅ボタンと情報秘匿。別案「財団神拳で主任を収容する」は本編には入れず1P幕間用に維持。

**役割**：危険度と収容難易度の違いを理解→Euclid紹介→収容方法改善→Neutralized紹介→世界破滅ボタンの情報秘匿オチ。  
**構成**：5コマ（①上段右 → ②上段左 → ③中段横長 → ④下段右 → ⑤下段左）。

### ① 上段右｜理解
**画**：喫煙室の二人へ戻る。ゴールディは落ち着き、タブレットを見ながら納得の顔。背景なしに近い薄いトーン。

**発話① ゴールディ**「危険度とは別の分類なんですね」  
**吹き出し①**：ゴールディの顔寄り、尻尾→ゴールディ。

### ② 上段左｜Euclidの補足
**画**：七星がタブレット内の「？」付きのシンプルな箱の図を示す。図解以外のUIを増やさない。

**資料ラベル**：「Euclid」（横書き）。

**発話① 七星**「収容が不確かなものはユークリッドだ」  
**吹き出し①**：七星に近接させ、尻尾→七星。

### ③ 中段横長｜収容手順による見直し
**画**：匿名の箱・抽象的な物体で収容手順の改善を模式化（**SCP-403のライターを使用しない**）。画面**右がEuclid**の不安定な状態、**左がSafe**の管理が安定した状態。**右→左に変化**し、「Euclid → Safe」は単なる想定例であることを図として表す。資料の矢印は物理的に右側から左側へ向ける。背景は無し。

**資料ラベル**：右「Euclid」、左「Safe」（横書き）。

**発話① 七星**「収容方法が改善されれば、クラスが変わることもある」  
**吹き出し①**：図を覆わず右上。七星からの発話であると分かる吹き出し尻尾を与える。図だけのコマにする場合は別の説明枠と混同しない。

### ④ 下段右｜Neutralizedの問答
**画**：少し大きめのコマにし、**ゴールディが右、七星が左**。タブレット画面の中に抽象物体の変化を小さく見せる。**右側＝異常な発光中、左側＝光が消えた通常物体**の順（右→左）。Neutralizedは破壊による無力化だけを意味するのでなく、異常性の消失も含む。背景は簡素。

**資料ラベル**：「Neutralized」（タブレット内の横書き）。

**発話① ゴールディ**「じゃあ、異常性そのものが消えたら？」  
**発話② 七星**「その場合はニュートラライズド。無力化済みだ」  
**吹き出し**：①右上・ゴールディへ尻尾1本 → ②左上・七星へ尻尾1本。②が読めるよう図を小さく留め、長文を極小化しない。

### ⑤ 下段左｜オチ
**画**：先ほどの世界破滅ボタンを思い出したゴールディが、率直に質問する。七星は「教えてやらない」とばかりに**口元を歪めた、含みのあるニチャッとした笑顔**。笑いの強さは顔つきと間で出す。背景は**白またはごく淡いトーン**で、顔と吹き出し以外を削ぎ落とす。P003最終コマなので台詞が上下に見切れない余白を確保する。

**発話① ゴールディ**「で、その世界破滅ボタンはあるんですか？」  
**発話② 七星**「お前のクリアランスレベルではまだ教えられないな」

**吹き出し**：①はコマの右上に置き尻尾→ゴールディ、②を左寄りに置き尻尾→七星。人物の顔位置と吹き出し読順を噛み合わせる。**(ﾆﾁｬｧ)という文字は描かず表情で示す**。台詞の改変・後続の説明ツッコミは禁止。

**本編終端**：情報統制のギャグで締める。主任自身のオブジェクトクラスは別の幕間で扱う。

## 設定確認（漫画へ印字しない）
- Safeは安全・無害という意味ではない。
- Euclidは収容に不確実性や複雑さがある。
- Keterは継続した収容が極めて難しい。
- Neutralizedは異常性の消失や無力化を示し、危険度の次の段階ではない。
- 宇宙滅亡ボタンと猫は説明用の仮想例。ボタンが実在すると七星が証言した事実ではなく、最後の台詞は含みを残すジョーク。
