# EP013 — 原典・ライセンス

『SCPと一服』EP013「記憶処理」はSCP財団の世界観と記憶処理技術の設定を利用した非公式二次創作。

   - 原著者：**qntm**

## 原典と独自演出の区別
- 本編の「ピカッ！」とペンはゴールディの映画的な連想。SCP財団の標準光学式記憶消去装置が存在すると確定した描写ではない。
- 喫煙室での二人の会話、七星の「俺も消されているかもしれない」という一般的可能性、タバコの本数を巡るオチはシリーズ独自の創作。
- 「記憶しただけで死ぬSCP」は恐ろしい情報災害を噛み砕いた登場人物の発言であり、SCP-3125原典の厳密な発動条件の転載ではない。
- 図解・脳画像などの漫画内図は演出であり、原典の画像を転載していない。
