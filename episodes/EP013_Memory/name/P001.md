# EP013 P001 — 秘密組織のアレ

**文章ネーム／公開対応版／日本漫画RTL・縦書き／5コマ。**

## 1コマ目：上段右
喫煙室。低い机のタブレットに顔を寄せるゴールディ。気だるいジト目。題字はこのページだけに表示。

- ページ内題字：**SCPと一服**
- 話数と題名：**EP013 記憶処理**
- 小見出し：**秘密組織のアレ**
- ゴールディ「うちって秘密組織じゃないですか？」

## 2コマ目：上段左
ゴールディがペンを携帯式の記憶消去装置に見立てて七星へ向ける。明るい表情。擬音「ピカッ！」は空想演出であり、実際の異常装置ではない。

- ゴールディ「やはりピカッ！って記憶消す装置とかないんですか？」

## 3コマ目：中段横長
大柄な七星を主役に、くわえ煙草と眼鏡、無精髭、気だるい表情。こめかみに少量の白髪。吹き出しとは別に、本人の留保を小さく無枠で置く。

- 七星「……それはない」
- 七星の小さな内語・地の文（**吹き出し・枠・背景なし**）「俺は知らないな」

## 4コマ目：下段右
ゴールディががっかりする。背景は省略。

- ゴールディ「ないんだ……」

## 5コマ目：下段左
七星が煙草を持って説明を始める。ゴールディが意外そうに反応する。

- 七星「だが、記憶を消す方法ならいくつもある」
- ゴールディ「あるんだ！？」

## 演出・固定
- 一貫した専用喫煙室。撮影方向によって左右が変わっても吹き出し尻尾は話者に接続する。
- 「ピカッ！」の光学消去装置を財団の実在する標準装置として確定しない。
- 完成画像の字面がこの制作台詞と微差がある場合、公開画像を正本とする。
