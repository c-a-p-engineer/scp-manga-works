# EP013 P002 — 財団の記憶処理

**文章ネーム／公開対応版／日本漫画RTL・縦書き／5コマ。**

## 1コマ目：上段横長
喫煙室。七星がタブレット上の「記憶処理薬」の資料をゴールディに示す。研究室の大型装置を喫煙室内に設置したわけではない。

- 七星「一般的なのは記憶処理薬だ」

## 2コマ目：中段横長・解説帯
経口投与を示す飲み薬、水、注射器、薬瓶、吸入マスクの3分割イメージ。短く、視認性の高いラベル「飲み薬」「注射」「吸入」。

- 七星「飲み薬、注射、吸入。投与方法も様々だ」

## 3コマ目：中段下・大きめ
記憶処理薬と神経刺激用装置を併用する状況の資料映像。記憶領域を示す脳の模式図、ベッド上の被験者、説明中の七星。医学風の演出は漫画用イメージで、実物の財団装置の図面ではない。

- 七星「薬剤と装置を組み合わせ、特定の記憶を狙う方法もある」

## 4コマ目：下段右
ゴールディが通常のジト目を少し開いて問いかける。

- ゴールディ「そこまでして記憶を消す必要があるんですか？」

## 5コマ目：下段左
七星。説明の温度が少し下がり、P003の不穏な雰囲気への伏線を張る。

- 七星「異常を目撃した一般人を守るためだ」
- 七星「もっとも、記憶処理されるのは一般人だけじゃない」

## 演出・固定
- 詳細なクラス分類には踏み込まず、投与経路と特定記憶への処理を絵で示す。
- キャラの顔と吹き出しを優先。資料画像は補助に留め、密度を上げすぎない。
- 参照：Updated Amnestics Guide（DrChandra）。SCP世界のすべてのカノンに同一の方式が存在すると断定しない。
