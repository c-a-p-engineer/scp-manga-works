# EP013 — 公開原稿に対応したネーム記録

## 証拠の優先順位
1. 2026-10-23に作者が[公開報告](https://www.pixiv.net/artworks/151167242)した作品と併せてmaster直下へアップロードした3枚の画像を採用対象とする。
2. `images/final/P001.png`〜`P003.png` の完成画像の文字・構図が視覚的正本。
3. `name/P001.md`〜`P003.md` は作者との共同制作で確定した台詞・演出意図を記録する。画像に差異がある場合は自動修正して整合したと主張しない。
4. pixiv配信ファイルとのバイナリ同一性は未確認。

## ページ別確定事項
- P001：`SCPと一服`、`EP013 記憶処理`、小見出し`秘密組織のアレ`を1Pにだけ入れる。「……それはない」の後に無枠・無背景で「俺は知らないな」。
- P002：記憶処理薬の飲み薬・注射・吸入、装置併用の模式図。装置そのものをSCP正史の普遍技術として断定しない。
- P003：第3コマをシリアス最大コマへ拡大。「記憶しただけで死ぬSCPも**あるかも知れん**」、「あとなタバコの本数くらいは**記憶しろ**」。最後はゴールディが無言で箱をジト目で覗き込む。灰皿とテーブルを消し、背景を極限まで簡略化。

## 差分・注意
- P003大ゴマは制作途中でセリフを何度も修正。古い草稿の表記へ回帰させない。
- 作者のキャラリファレンスを正本にし、七星の白髪を大きな前髪メッシュとして描かないこと、ゴールディのジト目・長めのラフな金髪ハーフアップを保つことが今後の課題。
- P001の「ピカッ」はゴールディの映画的な想像であり、光学式記憶消去装置の財団共通装備説を主張しない。
- 元PNGのGit Blob SHAの保持はバイナリ同一性の検証。pixiv配信画像の同一性は別問題。
