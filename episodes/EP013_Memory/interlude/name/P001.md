# EP013 幕間「実証」— 文章ネーム（公開版）

**1P、5コマ、RTL、縦書き。** 喫煙室だけで完結。P001の題字は「SCPと一服」「EP013 幕間『実証』」。

## 1コマ目 — 上段右
ゴールディが一服しようとして、手元のタバコ箱を開く。減っていることに気づく。

ゴールディ「ん？ 減ってる……？」

## 2コマ目 — 上段左・小コマ
タバコの箱と残りの本数に寄った手元。背景には七星がその様子を見ている。台詞なし。

## 3コマ目 — 中段・横長大ゴマ
七星が煙草をくわえ、気だるく淡々と告げる。ゴールディは小さく七星を見つめる。

七星「これが記憶処理薬だ」

## 4コマ目 — 下段右
七星が説明する。吹き出しは右から左の読順。

七星「説明後にお前が試したいと言ったから」
七星「数時間分の記憶を消したぞ」

## 5コマ目 — 下段左・オチ
ゴールディがタバコ箱を握り、顔を赤くして過去の自分に本気で怒る。七星は反応に困って沈黙。

ゴールディ「私の喫煙という楽しみを消した私が憎い💢」
七星「……」

## 作画固定条件と差異
- 七星の大柄な体格・眼鏡・無精髭・こめかみの白髪、ゴールディの赤目・ラフな金髪・小柄さを保持。
- 新しいタバコを取り出したり着火したりする状態変化を増やさない。
- 作画上、上段右→左→中段→下段右→左で読ませる。
- 公開版の生成画像では、タイトルと説明・最終台詞は概ね意図に沿う。句読点・改行・絵文字や吹き出しの字面は**原稿画像を正本**として扱う。
- 薬剤を投与する具体的な描写は行わず、七星の告白から逆算する幕間オチ。
