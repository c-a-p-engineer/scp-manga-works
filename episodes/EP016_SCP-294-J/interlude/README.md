概要：コーヒーに生じた文明が別の職員に飲まれた話の直後、七星が「俺たちが吐くタバコの煙にも文明があるかもなぁー」と言う。ゴールディは喫煙自体が研究になると喜ぶ。文明の存在は仮説・冗談であり、実証や収容は行わない。
