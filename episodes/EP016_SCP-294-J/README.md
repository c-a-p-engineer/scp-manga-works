題材は **SCP-294-J**。原作の正式な日本語タイトルは「淹れたての創世記」、本漫画の副題は「一杯の文明」。通常のSCP-294とは混同しない。

## 本編
喫煙室で「コーヒーの中に文明がある」と言い切る七星。ゴールディは自分のカップを持ったまま困惑する。極小の知的生命体と急速な発展を説明した後、別の職員が飲んでしまったという事故を聞き、ゴールディがカップを見つめて嫌がる。

実験・収容室で二人が喫煙したと描かない。文明の描写は原典の顕微鏡観察を踏まえた**視覚的説明イメージ**であり、肉眼でカップ内の巨大都市を見られる設定ではない。
