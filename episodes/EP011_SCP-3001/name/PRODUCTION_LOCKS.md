# EP011 — 文章ネームv4 制作固定表（画像生成前の契約）

**状態**：v4ネームに付属する演出・同一性の契約。画像自体／人物リファレンス実体／装置三面図は未作成・未採用。過去のNG画像を正本にしない。

## 0. 漫画の基本

- 本編はP001〜P006。日本漫画の**右→左、上→下**、縦書き。P001のみにタイトル。各ページの物理コマと発話順は個別Pxxx.mdが正本。
- 台詞種別を3種類に固定する。**現在の会話**＝白い通常楕円吹き出し・正しい人物の口元へ尻尾1本。**ロバートの録音**＝黒地の角型・白字・尻尾なし・必要に応じ「録音」のラベル。**七星らの回想上説明**＝白地の角型・黒字・尻尾なし・必ず「七星／説明」など話者表記をネームで明示。アナ・モブの実際の発話だけ通常吹き出し。
- 回想に現在の七星・ゴールディの全身や顔を合成しない。過去のロバートが現在の二人の説明を話しているような配置を禁止。
- 日本語の内容は各ページの台詞をそのまま使用。画像生成で勝手に補った年号、年齢、生没年、肩書、固有名詞、技術仕様、実験結果、死亡宣告は**不採用**。小さな資料文字は原則省く。

## 2. 固定小物の状態

- **LSS（ラング・スクラントン安定機）本体**：P002サイト-120の大型の実験設備。ブルーライトや崩壊表現は原典既定の公式外観ではない。本体が**2005年に丸ごと戻る描写は不可**。
- **LSSコントロールパネル**：P002で本体側にあった操作用パネルだけが博士とともにSCP-3001へ転移し、P003〜P005の記録を担い、P006で同一のパネルが帰還する。漫画用識別子は「**横長の厚い矩形パネル、左上に小さな赤い録音灯、中央に細い表示窓、右端に物理スイッチ二つ**」。この形、向き、発光点の位置を変更しない。**大きな発電機・木箱・携帯録音機・別種の機械に変化させない**。描画は本案の想像上のデザインであり原典の公式仕様ではない。
- **結婚指輪**：P006帰還した身体の残骸の近く、アナが発見。**パネルの内蔵機構ではない**。指輪の場所はP006②③で連続させる。
- **現代の喫煙**：研究室ではなく**専用喫煙室**。七星＝右手にセブンスター1本、ゴールディ＝右手にゴールデンバット1本。**手に1本ある時は口にもう1本を追加しない**。両者のタバコ・左右手・灰皿・タブレットをコマごとに状態確認。研究室の過去回想にはタバコなし。
- **レッド**：独立のSCP生物や光球ではなく、**上記パネル左上の赤い録音ランプ**。P002の小さな赤い一点→P003に拡大で説明→P005に一点→P006の同一物と、最後のゴールディのタバコ火で視覚モチーフを接続。

## 4. 空間と視覚密度

- SCP-3001は**ほぼ物質のない極低ヒュームの非次元**。床・地平線・宇宙の星・月・銀河・黒い土・廃墟・建物・浮遊瓦礫・扉・SFゲート・粒子の奔流・ワープ通路・CGピクセル禁止。
- 原典では「歩く」感覚やゲルの中を泳ぐ感覚はあるが、**物理的な地面は存在しない**。ロバートの足元は無地の黒に消す。座る姿なら浮遊する人体の主観的略画のみ。
- 博士の顔はP002とP003①で十分に紹介し、P003③〜P005の大ゴマは赤灯・手・音声ログ等の**簡素な絵**中心。小コマの黒ベタを黒い宇宙景観に置換しない。
- 2005年側の廊下・設備・実験室描写は許可。ただしレッド・リアリティ内の背景へ流入させない。
- **P001＝説明→P002＝事故→P003＝孤独→P004＝崩壊→P005＝別れ→P006＝帰還／煙**。各ページで一つの最大コマ。平等4分割の連続を避ける。

## 5. ページ受け入れ条件

1. 現在/過去の人物の見分け、ロバートの顔/服とアナの顔/服、**パネルの外観とランプ位置**が全ページ一致。
2. 日時が表の順で増加。**同一イベントを先後反転した重複なし**。
3. P001の初台詞は七星が発話。P006①の「何かが現れました！」は**スキナー男性**が発話。音声ログと現在の会話を通常の吹き出しで混ぜない。
4. 虚偽の生没年・架空のプロフィール・博士の死亡確定、原典と異なる設定を読める資料テキストへ追加しない。
5. 漫画画像は**1ページ生成→実画像レビュー→局所修正→作者確認**。この文章の保存だけでは画像合格とはしない。
