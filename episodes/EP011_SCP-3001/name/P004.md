# P004 — 底のない探索／崩れる手（v4）
**作品**：「SCPと一服」EP011 / SCP-3001「レッド・リアリティ」  
**状態**：文章ネームv4、作者確認前。既存画像は全ページ未採用。  
**仕様**：日本漫画の右→左・上→下、縦書き、各発話の話者と尻尾の帰属を固定。P001以外はタイトル・ページ番号・制作番号を画面へ描かない。  
**共通の時系列・キャラクター・小物・誤情報防止**：[PRODUCTION_LOCKS.md](PRODUCTION_LOCKS.md)。本ページと必ず併読。  


**役割**：P003の命名以後、時間が一方向に進む。単純な「黒い景色4回」の反復を避け、探索→ログの乱れ→沈黙→肉体の異常で変化をつける。

### ① 右上／6か月10日・戻ってきた探索者
- **画**：赤い表示灯を画面端に置き、そこへ向かってきたロバートのシルエット。**黒一色の背景**。地面に足をつけない。
- **角型日時**「6か月10日」
- **ロバート／録音枠**「ずっと、出口を探していた……」
- **ロバート／録音枠**「だが、果てがない」
- **演出**：「空間は無限」「もう帰れないかもしれない」を静かに。

### ② 左上／1年2か月27日・消えた言葉
- **画**：LSSコントロールパネルの録音時間表示だけを大きく。赤い点滅以外の背景は黒。ロバートの姿なし。
- **角型日時**「1年2か月27日」
- **ロバート／録音枠（文字が歪み、短く）**「あ……」
- **角型地の文**「音声は、しだいに不明瞭になっていった」
- **注**：脳内の記憶が消えた／言葉が出ないと断定せず、録音上の描写として扱う。

### ③ 中段・横長／2年7か月28日以降・沈黙
- **画**：同じパネルの赤灯アップ。**波形UIは表示しない**（音声データは漫画上の角型文字演出）。赤点だけを残し、その周囲を広い黒で囲む。
- **角型日時**「2年7か月28日以降」
- **角型地の文**「やがて、二か月間は何も録音されなかった」
- **演出**：縁なしの黒い長方形だけでもよい。

### ④ 下段・最大／その後・手
- **画**：**ロバートと特定できる髪の輪郭**、片手だけを主役にした接写。左手が蜘蛛の巣のように細く、その一部が自分の手をすり抜ける。画面背景は黒のみで、デジタル粒子・床・石・扉・宇宙模様なし。前ページ①の顔を若干痩せさせても別人化させない。
- **角型日時**「さらに時が過ぎ――」
- **ロバート／歪む録音枠**「……手が、すり抜ける」
- **七星／無尾説明枠**「現実性が、身体そのものから失われていった」
- **出口**：P005で「そんな状態で生きている？」の反応へ。
