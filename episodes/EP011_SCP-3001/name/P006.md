# EP011 / P006 — 帰ってきたもの（ネームv3）

**作品**：SCPと一服 EP011「SCP-3001 レッド・リアリティ」  
**段階**：文章ネームv3・作者確認待ち／既存生成画像は未採用  
**基本**：日本式右→左・上→下／縦書き／各コマ内の発話順を固定。制作管理番号は絵に入れない。  
**参照**：[SCP-3001](https://scp-jp.wikidot.com/scp-3001) ／ [現実錨・用語集](https://scp-jp.wikidot.com/glossary-of-terms)  

**役割**：アナが操作盤と夫の痕跡を見つけ、事故初期の声を聴く。現在の喫煙室へ帰還し、マスター指定の煙のオチへ。

## 物理コマ割り
```

│ ② アナ   │ ① 2005年 │
├──────────┴──────────┤
│ ③ 録音と指輪／横長大     │
├─────────────────────┤
│ ④ 静かな会話／横長小     │
├─────────────────────┤
│ ⑤ ゴールディ／大ゴマ     │
└─────────────────────┘
```

### ① 上段右｜2005年12月23日
**画**：サイト-120の現実性研究室A。装置の試験場内に、**P002〜P005に登場したLSSの同一コントロールパネル**が出現。現実側の研究装置とは区別して形状を固定。  
**角型地の文**「2005年12月23日　サイト-120」  
**モブ研究員**「何かが現れました！」

### ② 上段左｜アナの発見
**画**：アナが現れたコントロールパネルへ近づく。周囲には、形をはっきり描かない不穏な残骸と、**ロバートの結婚指輪**を示す。装置と指輪の位置を固定し、突然別の録音機に置き換えない。  
**アナ／小声**「……ロバート？」  
**禁則**：帰還したのは録音機だけだと断定しない。直接的なグロテスク描写は使わない。

### ③ 中段横長大ゴマ｜過去の声
**画**：アナは同じ操作盤に手を添える。顔のアップに涙。装置の赤灯はごく小さく。指輪はコマの端に位置を保つ。録音はP003の11日目の声とリンクする。  
**角型無尾注記**「事故から11日目の録音」  
**ロバート／録音（装置側から角型細枠／尻尾なし）**「ロバート・スクラントン。39歳……」  
**ロバート／録音**「妻は……アナ……」  
**アナ**：台詞なし。涙で反応。  
**余韻**：①②より背景を削って、肉体の悲劇と事故直後の声の時間差を感じさせる。

### ④ 下段横長・小コマ｜喫煙室へ
**画**：二人に戻る。画面右ゴールディ、左七星。今までの強い演出をやめ、ごく普通の灰皿とタブレットに戻す。タバコは各自右手に1本、**口には別のタバコなし**。  
**ゴールディ**「……博士は戻れなかったんですね」  
**七星**「ああ」  
**注**：七星の発言は「救出されていない」の意。博士の生死は原典で不明。

### ⑤ 下段大ゴマ｜煙のオチ
**画**：ゴールディの赤い瞳のアップ。少し寂しそうだが**涙を誇張しない**。**右手に持った唯一のタバコ**の小さな火。煙が余白へ細く消える。赤い点がP003〜P005の録音灯と響き合う。左端に七星の横顔。  
**ゴールディ／淡い苦笑**「私がそんな空間行ったら、煙になって消えていきそうですね。」  
**七星／短く、低い声**「……縁起でもないこと言うな」  
**吹き出し**：右のゴールディ発話→左の七星。各尻尾はそれぞれの口元へ。煙に文字が重ならないよう、上の余白を残す。  
**作品の出口**：説明やタイトルを追加せず、**煙だけ**を残す。

## 共通の作画・組版契約

- 現在：**喫煙室**。画面左・七星（大柄、眼鏡、無精髭、黒髪＋少量の白髪）、画面右・ゴールディ（小柄な成人女性、金髪ハーフアップ、赤いジト目）。顔・色彩は採用人物シートとEP010幕間の提供画像を優先。
- 二人はそれぞれ**タバコ1本だけ**。基本は各自の右手に1本。手持ち時は口に別のタバコを増やさない。灰皿は机に1個、タブレットは机上で1台、増殖なし。煙の量は必要最小限。
- 過去：**サイト-120研究室**、研究施設の回想。ロバート・スクラントンは事故当時39歳。老年の白髪博士として描かない。アナ・ラングは妻。LSS本体と、博士とともに転移した**LSSコントロールパネル**を区別し、P002〜P006で同じ操作盤を維持。
- SCP-3001：**黒一色に近い非次元**。実体のある地面、瓦礫、建物、扉、星空、廃墟、ワープ通路、反射する床、デジタル世界のピクセル背景を**描かない**。描画上やむなく博士の輪郭を見せる部分は、読者向けの主観的可視化。唯一の持続光は操作盤の**赤い録音表示灯「レッド」**。
- 現在の二人が回想場面へ身体ごと入り込んだような合成を避ける。現在の会話を過去映像に重ねる場合は**七星説明枠／ゴールディ質問枠（無尾）**と役割を明記し、人物顔は配置しない。
- **吹き出し**：人物の発話に限り尻尾1本を正しい口元へ。回想映像中の七星／ゴールディの説明は四角い**枠説明（尻尾なし）**、ロバートのログは**録音・独白**用。台詞が長ければ絵を優先して削る。最終コマだけ通常の会話吹き出し。
- **視覚リズム**：冒頭は明るい日常→事故→黒い余白→身体の輪郭が失われる→記録帰還→日常。赤のスポットカラーは表示灯とタバコの火が主役。SCPの実体イメージは説明図であり、固定の装置外観を創作で断定しない。
