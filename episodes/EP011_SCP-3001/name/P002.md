# P002 — 研究室A、事故（v4）
**作品**：「SCPと一服」EP011 / SCP-3001「レッド・リアリティ」  
**状態**：文章ネームv4、作者確認前。既存画像は全ページ未採用。  
**仕様**：日本漫画の右→左・上→下、縦書き、各発話の話者と尻尾の帰属を固定。P001以外はタイトル・ページ番号・制作番号を画面へ描かない。  
**共通の時系列・キャラクター・小物・誤情報防止**：[PRODUCTION_LOCKS.md](PRODUCTION_LOCKS.md)。本ページと必ず併読。  


**役割**：2000年の事故と、操作盤だけがロバートとともに非次元へ転移した因果を明確化。**回想には七星・ゴールディを一切描かない。**

### ① 右上／事故前
- **画**：サイト-120現実性研究室A。39歳と自己記録する研究員**ロバート（中国系男性・短い黒髪・眼鏡なし）**、妻の**アナ（黒髪をまとめた女性・緑の目）**。どちらも七星・ゴールディに似せない。大きなLSS本体の操作部に**固定形状のコントロールパネル**（横長、左上に小さい赤灯）。
- **角型地の文**「2000年1月2日　サイト-120」
- **角型地の文**「ロバートとアナは、ラング・スクラントン安定機を研究していた」
- **小物**：研究室内のタバコなし。アナの目／髪は原典によるが顔デザインは本作暫定。

### ② 左上／地震
- **画**：研究設備の揺れ。アナが実験機器を押さえ、ロバートが振り向く。
- **角型地の文**「予期せぬ地震で、装置が損傷」
- **SFX**「ガガガッ」
- **禁則**：大爆発、全方向の瓦礫シャワー、爆風で二人が吹き飛ぶ演出は加えない。

### ③ 中段横長／消えるのは二つ
- **画**：ロバートと**LSSコントロールパネルのみ**が現実側から不意に消えようとする。アナの手が届かない。大型LSS本体は現場に残る。
- **ゴールディ／無尾の質問枠（現代からの音声）**「博士は……？」
- **七星／無尾の説明枠**「SCP-3001へ転移した」
- **画面**：回想側アナの実際の叫び声は**入れない**。現在の二人は描かず、質問／説明の枠を上端に置く。

### ④ 下段最大／見ることのできない世界
- **画**：ほぼ全面黒。唯一の**ごく小さな赤い録音灯**。表示は抽象的な赤点のみで、下に床・上下の位置基準・銀河・トンネルを置かない。
- **角型地の文**「SCP-3001　レッド・リアリティ」
- **七星／無尾説明枠**「ヒューム値0.032。極端に現実性の低い非次元だ」
- **出口**：「赤点＝何なのか」をP003へ送る。

## 当ページ固有の不合格
- ロバートが七星の顔・眼鏡・黒白髪に見える。
- LSS本体が丸ごと転移したように描かれる。
- 現代の二人が研究室回想に混入する。
