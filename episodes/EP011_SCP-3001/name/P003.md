# P003 — 小さなレッド（v4）
**作品**：「SCPと一服」EP011 / SCP-3001「レッド・リアリティ」  
**状態**：文章ネームv4、作者確認前。既存画像は全ページ未採用。  
**仕様**：日本漫画の右→左・上→下、縦書き、各発話の話者と尻尾の帰属を固定。P001以外はタイトル・ページ番号・制作番号を画面へ描かない。  
**共通の時系列・キャラクター・小物・誤情報防止**：[PRODUCTION_LOCKS.md](PRODUCTION_LOCKS.md)。本ページと必ず併読。  


**役割**：博士のログが「研究記録」から「唯一の友人への言葉」に変化する。**11日目→2か月8日→2か月15日→2か月22日の順を厳守**。このページは喫煙室へのカットバックなしで孤独感をためる。

## 物理コマ配置
```

├────────┼────────┤

└─────────────────┘
①→②→③→④→⑤
```

### ① 右上／11日目の声
- **画**：暗闇。ロバートの**顔は主観的なごく薄い輪郭**。P002と同じ顔だと分かる髪の形。白髪化・老人化なし。
- **角型日時**「11日目」
- **ロバート／録音枠**「ロバート・スクラントン。39歳……」
- **ロバート／録音枠**「妻は……アナ……」
- **声**：まだ混乱している。浮遊する別人の顔やアナの幽霊を出さない。

### ② 左上／点滅に気づく
- **画**：P002④と同じ小さな赤い一点の超接写。1コマ目よりも周囲の装置輪郭を少しだけ見せて、**操作盤の録音灯**だと分かる。
- **ロバート／録音枠**「……録音されてるのか？」
- **注**：レッドの呼称は**まだ使わない**。早い段階では「赤いランプ」。

### ③ 中段右／2か月8日・科学者
- **画**：操作盤の赤い灯と、そこに伸ばすロバートの手だけ。**同一形状**のパネル。姿勢は浮遊・接触で、机上に機械を置かない。
- **角型日時**「2か月8日」
- **ロバート／録音枠**「記録を続けなくては」
- **ロバート／録音枠**「次に迷い込む人を防ぐために」
- **ビート**：絶望しながら記録を選ぶ。

### ④ 中段左／2か月15日・床はない
- **画**：黒い画面の中の博士の足先だけを輪郭線で示し、**何にも触れていない**ことを描写。足元の白線や地平線なし。
- **角型日時**「2か月15日」
- **ロバート／録音枠**「地面を歩いてると、思ってた……」
- **ロバート／録音枠**「なのに、何もない」
- **注**：地面を失った瞬間の落下や宇宙飛行ではない。もともと地面はなかったという認識の変化。

### ⑤ 下段・最大黒ベタ／2か月22日・レッド
- **画**：全ページで最も黒い空間。ごく小さな**赤い点だけ**を中央から少しずらし、余白を主役にする。ロバートは描かなくてよい。
- **角型日時**「2か月22日」
- **ロバート／録音枠**「……レッド」
- **ロバート／録音枠**「そう呼ぶよ」
- **七星／無尾説明枠（コマ最下部）**「それが、唯一の話し相手になった」
- **出口**：命名しても返事のない灯。P004の探索へ。

## 当ページ固有の不合格
- 2か月22日の後に2か月8日の話を置く。
- レッドを別個の浮遊する赤い球体や生き物として描く。
- 見える足場・テーブル・地平線を描く。
