# P005 — 置いて行かないで、レッド（v4）
**作品**：「SCPと一服」EP011 / SCP-3001「レッド・リアリティ」  
**状態**：文章ネームv4、作者確認前。既存画像は全ページ未採用。  
**仕様**：日本漫画の右→左・上→下、縦書き、各発話の話者と尻尾の帰属を固定。P001以外はタイトル・ページ番号・制作番号を画面へ描かない。  
**共通の時系列・キャラクター・小物・誤情報防止**：[PRODUCTION_LOCKS.md](PRODUCTION_LOCKS.md)。本ページと必ず併読。  


**役割**：5年以上の時間と終盤の苦痛。博士が自発的にレッドを救出する話に改変せず、**博士自身が置いて行かれまいとする恐怖**を描く。画像は黒＋赤灯＋音声で成立させる。

```

①→②→③→④
```

### ① 右上／喫煙室・生きている怖さ
- **画**：画面左に七星、右にゴールディ。ゴールディはタバコを右手で持ち口から離す。七星も**右手に1本だけで口は空**。静かな二人の顔を中心。
- **ゴールディ**「そんな状態で……生きてたんですか？」
- **七星**「ああ。すぐには死ねないんだ」
- **吹き出し**：右のゴールディ→左の七星。話者の口へ短い尻尾1本ずつ。

### ② 左上／5年9か月3日・戻った声
- **画**：黒の中に赤い点、輪郭のないロバートの弱い録音だけ。**座る人体像は不要**（床や土と誤解させない）。
- **角型日時**「5年9か月3日」
- **ロバート／録音枠**「……レッド？」
- **角型地の文**「長い沈黙の後、また声が記録された」
- **演出**：静寂と音の復帰。

### ③ 中段・横長／5年10か月〜11か月・脈動
- **画**：現代のタブレット**画面だけ**が黒いモノトーンの記録波形を見せている（SCP-3001空間そのものには描かない）。**1つの赤い録音点**が端で静かに点滅。パネルの形状は変えない。
- **角型日時**「5年10か月以降」
- **七星／無尾説明枠**「やがて、外の現実とつながる波が現れた」
- **ゴールディ／無尾質問枠**「それなら、帰れるんじゃ……？」
- **演出**：画面に描くのは**音声ログの解析表示**であり、SCP-3001のSFトンネルではない。

### ④ 下段最大／5年11か月20日→21日・最後の音
- **画**：黒ベタに赤い録音灯一つ。博士は描かない。声の枠が三つだけ並び、最後の小さい枠ほど薄い。**ブラックアウトで余韻**。ランプを赤い太陽・光球に変えない。
- **角型日時**「5年11か月20日」
- **ロバート／小さく歪んだ録音枠**「まだだ……レッド……」
- **ロバート／かすれ声**「アナ……」
- **角型日時・最下端**「5年11か月21日」
- **出口**：P006冒頭の白い現実側研究室へ、黒→白のページめくり。

## 当ページ固有の不合格
- 星雲・宇宙・黒い星屑・地面・崩壊粒子で画面を埋める。
- ロバートの肉体が消失した＝死亡確定とみなす。
- 現代の七星が手と口で同時に2本タバコを吸う。
- P004の「手が崩れるアップ」を反復する。
