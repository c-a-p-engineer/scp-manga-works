## v2実画像の自己レビューからの修正

1. P001の七星の初台詞は頭上で、尻尾を七星の口元に固定。説明図を簡潔にする。
2. P002〜P003は現在と過去を混同せず、ロバート博士の事故当時39歳・装置の連続性を明記する。
3. P004は床、瓦礫、扉、建物、デジタル粒子を排除。黒と赤の最小演出で身体の崩壊を描く。
4. P005は「帰還ゲート」を止め、原典のハム音、置いて行かないでほしい恐怖を使う。七星のタバコは1本。
5. P006は同一LSSコントロールパネル、指輪と肉体の残骸の痕跡、11日目の音声と最後のオチを回収。博士の死亡は確定しない。
