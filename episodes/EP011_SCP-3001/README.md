# EP011 — SCP-3001「レッド・リアリティ」

**状態：2026-10-20 pixiv公開済み（作者報告）／完成PNG全6枚を画像内容を変えずGitHubへ整理済み。**

- シリーズ：**SCPと一服**
- 原典：[SCP-3001「レッド・リアリティ」](https://scp-jp.wikidot.com/scp-3001)
- 主要技術：[スクラントン現実錨](https://scp-jp.wikidot.com/glossary-of-terms) ／ **ラング・スクラントン安定機（LSS）は事故に関わる研究装置。現実錨そのものと無造作に同一視しない。**
- 形式：P001〜P006、全6P。日本式右→左、縦書き、グレースケール＋赤い録音灯・タバコの火をアクセント。
- 人物（現在）：七星（セッター）、ゴールディ（バット）。日本の研究室に隣接する専用喫煙室。
- 人物（過去）：ロバート・スクラントン博士、アナ・ラング博士、マシュー・スキナー博士（2005年側）。サイト-120研究室とSCP-3001を回想。
- 作者指定のオチ：ゴールディ「私がそんな空間行ったら、煙になって消えていきそうですね。」／七星「……縁起でもないこと言うな」。

## v4で解消したv3／生成画像の問題

1. **時系列**：P003の「2か月22日」後にP004「2か月8日」が来ていた逆行を解消。過去の事実に沿って段階的に時を進める。
2. **人物分離**：ロバートは七星の顔を流用しない。アナは黒髪・緑目、ゴールディは金髪・赤目。アナとゴールディを同じデザインにしない。
3. **偽資料削除**：P001からロバート／アナの架空の生没年・写真・職歴を削除し、二人の名前と共同研究者／夫妻の関係だけにした。
4. **空間**：SCP-3001内の瓦礫・廃墟・扉・地面・星雲・SFゲート・ピクセル背景を禁止。黒い余白と赤い点で恐怖を描く。
5. **装置**：LSS本体と、一緒に転移しのちに帰還した**同一コントロールパネル**の形状を全6ページで固定する。
6. **話者**：P001の冒頭は七星だけが発話。P006の「何かが現れました！」はスキナー男性、アナは「……ロバート？」。現在／録音／解説の枠形と尻尾を区別。
7. **タバコ**：七星／ゴールディは各自1本、右手保持時には口で追加の1本をくわえない。
8. **結末**：原典におけるロバート博士の死亡・生還を確定しない。救出に失敗したことのみ事実として扱い、作者のラスト2台詞はそのまま。

## 画像と文章ネームの差分

P002中段には、マスターの指定で**小さく七星とゴールディを描いた解説インセット**が入り、名前ラベルを削除した。ヒューム値の数値表記とロバート博士の黒髪は最終修正版を採用。P001資料には博士の肖像シルエットがあるため、v4ネームの「資料に肖像を載せない」とも異なる。**pixiv公開版と同一の採用PNGが組版・コマ割りの正本**である。

ルートへ置かれたPNGは同会話で生成した最終版とGit Blob SHAが一致し、バイナリを変更せず `images/final/` へ整理した。ただしpixiv配信ファイルとのバイト単位の照合は未実施。
