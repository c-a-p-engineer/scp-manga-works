**作品：SCPと一服／正式話数未定／文章ネーム改訂草稿 v3（画像レビュー反映）／未公開**

- 題材：[SCP-710-JP-J「財団神拳」](https://scp-jp.wikidot.com/scp-710-jp-j)（原作者：Kwana）
- 構成：**本編2ページ（P001・P002、各4コマ）＋幕間1ページ**。幕間は本編のページ数に含めない。
- 読み順：日本式RTL（右上→左下）／台詞は原則縦書き
- 登場：七星（主任／セッター）、ゴールディ（バット）、カオス・インサージェンシー構成員、**財団神拳の伝承者**
- 舞台：空の解析室に隣接する喫煙室 → 襲撃警報 → 主任が壁を抜ける → 迎撃通路 → 伝承者との対峙 → 幕間の日常

## 最新の演出ロック／画像レビューからの修正

1. **P001・1コマ目に他の職員を描かない。** 空のデータ解析室の机・画面だけ。煙草の**箱、銘柄、商品ロゴを描かない**。
2. ゴールディは承認済み立ち絵に沿った**金髪ミディアムのハーフアップ**（長いロングウェーブ禁止）。主任は約190cm／100kgの熊のようなガタイ、眼鏡・無精髭・袖まくり白衣。身長差約40cm。
3. **日本式右→左**の吹き出し順を各コマで設計。P001・3コマは**ゴールディ「主任、警備を――」→主任「不要だ」**。P001・4コマは**ゴールディ「主任！ そっちは壁！」→主任「量子歩法！」**。巨大な技名は叫びより先に読ませない。
4. **量子歩法は「壁が無傷で透過」**。ひび割れ・破片・瓦礫・爆発・壁破壊エフェクト禁止。複屈折／残像で透過のみを表現。
5. ゴールディは壁を抜けない。P001の終わりでは壁の手前に取り残され、**P002・2コマ目で迂回通路の扉から追いつく**。他のコマへの先行登場を避ける。
6. **技の取捨選択はユーザーの最新の指示によるもの**。本編では3技（量子歩法／共振パンチ／爆風キャンセリング）をそれぞれ明確に描き、残る原作の技は強制収録しない。
7. P002では敵を**人間の武装構成員**として描く（ロボット・機械兵化禁止）。爆風キャンセリングは**衝撃波の相殺**であり、炎そのものの消滅ではない。
8. **伝承者**は漫画版独自の外見（暗いスーツ、目深の帽子、顔全体が影で見えない）。目・鼻・口・具体的な顔立ちは出さない。道着・長髪武人への変更禁止。
9. P002最終煽りは**「主任 VS 伝承者」**。決着を描かずに幕間へ移る。最後の大ゴマを字幕・技の小解説・リアクションで圧迫しない。
10. ゴールディは全コマで大口を開けない。平和な半目→襲撃の驚き→切迫→壁抜けの驚愕→戦闘時の息を呑む表情→伝承者への警戒、と段階を作る。
11. 七星が緊急迎撃中も一本の煙草をくわえるのはユーザー指定の当話の演出例外。**恒常的に喫煙区画外で喫煙するシリーズ設定へ変更しない**。
12. 幕間の台詞はゴールディ「――って夢を見ましてー」→七星「現実だ」→七星「財団神拳は職員なら誰でも学べるからな」「習うのなら申請しておけ」を維持。原作のA〜Cクラス資料取得・訓練許可は別途維持。
