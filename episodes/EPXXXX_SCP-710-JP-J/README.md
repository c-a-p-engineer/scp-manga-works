## 演出上の重要事項

1. **冒頭は喫煙室で一服中**。七星はくわえた煙草を落とさず壁抜けから戦闘へ向かう。喫煙姿はユーザーが明示した今回の見せ場。
2. **P001最後**はゴールディ「主任！ そっちは壁！」→七星の巨大な描き文字 **「量子歩法！」** →実際にすり抜ける。技と現象を同一コマで読ませる。
3. **P002**で「共振パンチ」「爆風キャンセリング」の原作表記を使い、発動のたびに簡潔な説明を添える。「財団神拳は科学に基づく徒手武術」という説明も冒頭で一度だけ示す。
4. 財団神拳の使い手である敵が立ちはだかり、**七星 vs 継承者、いざ開戦！**という少年漫画的な大引きで本編を止める。勝敗は描かない。
5. **幕間**はゴールディの「って夢を見ましてー」→七星「現実だ」→「財団神拳は職員なら誰でも学べるからな」「習うのなら申請しておけ」で終わる。夢オチにはしない。
6. 原作本文の敵の呼称は「**伝承者**」。本漫画のセリフ／対戦煽りにはユーザー案に沿って「**継承者**」を使用する（脚色）。
7. **くわえタバコでの喫煙室外・戦闘中の喫煙は、シリーズにおける通常の区画規則からの今回限りの意図的な演出例外**。一連の緊急迎撃中のみで、研究室内の通常喫煙や恒常的な規則変更として扱わない。原作にも七星・この戦闘は存在しない。
