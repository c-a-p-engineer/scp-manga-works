## 演出の確定条件・制作ロック

1. 一服中の平和から襲撃へ転じる。**七星はくわえタバコのまま戦う**。作中での喫煙区画外の緊急戦闘シーンは今回だけのユーザー指定の演出例外であり、シリーズ共通の分煙規則は改変しない。
2. P001の重要台詞は **ゴールディ「主任！ そっちは壁！」→七星「量子歩法！」**。大きな「量子歩法！」と壁をすり抜ける画を一体化し、壁に穴を開けない。
3. **原作収録の6技をすべて本編で視覚化**。技を唱える台詞は大きく、解説は技ごとの短い小解説箱とし、画・台詞を覆わない。
4. **敵の名称は「伝承者」で統一**。原作本文には「SCP-710-JP-J伝承者を名乗る一人」とある。旧草稿にあった異なる呼称は破棄する。
5. P002末尾は **「七星 VS 伝承者――今、戦いの幕が上がる！」** で止め、勝敗を描かない。
6. 幕間はゴールディ「――って夢を見ましてー」、七星「現実だ」、七星「財団神拳は職員なら誰でも学べるからな」「習うのなら申請しておけ」。ただし原作の正規の範囲はA〜Cクラスの巻物コピー入手と、**許可制の訓練（就業中は1日3時間まで）**。
7. ゴールディは壁抜け能力を習得していない。七星の後を**通常の通路から追う**。小道具、服装、人物の同一性は既存のキャラクター設定を維持する。
8. 2Pに6技を収めるため、P001は5コマ（量子歩法の大ゴマを優先）、P002は6コマ（4技→確認→伝承者との大引き）。可読性不足ならページ増の再検討を行い、勝手に技を落とさない。
