## 画像自己レビュー・最新指示で修正する問題（v5）
1. **P001**：警告の「主任！そっちは壁！」より「量子歩法！」が先に読める文字の位置を修正。3コマ目も「主任、警備を――」→「不要だ」の順を優先。
2. **P001**：ゴールディの煙草を吸うときは**顔を少し上げて煙を吐き、とろんとする**。主任も喫煙。銘柄・タバコの箱は描かない。ガラス向こうの解析室は**無人**。
3. **P001**：量子歩法は壁が無傷。割れ、破片、爆発はない。主任だけ壁を抜け、ゴールディは回り道。
4. **P002**：技の見せ場は**拳と盾の接触点**／**正拳突きによる衝撃波の相殺面**へ寄る。周囲の襲撃者は人間。主任の一本のくわえタバコを維持。
5. **P002**：伝承者は**スーツ＋目深の帽子＋顔が一切見えない**。原作表記「伝承者」を維持。
6. **P002**：独立した伝承者登場コマを廃止し、俯瞰対峙の大ゴマへ統合。伝承者「お前も使うのか……」→主任「まさか……門外不出の財団神拳を……」→伝承者「私は財団神拳の伝承者だ！」→主任「同門対決……面倒だな」を**［右上①→左上②］→［右中段③→左中段④］**の順で読む。**吹き出し尻尾は伝承者→七星→伝承者→七星に正確に結ぶ。** ゴールディを話者と誤認させない。
7. **P002最終**：高めの3/4俯瞰。**右奥の伝承者と左手前の主任が対峙、ゴールディは主任の真後ろで慌てて身を引き手を伸ばす**。主任「同門対決……面倒だな」→煽り「主任 VS 伝承者」。対戦は始めない。技2コマは寄りで大きく、技名はレタリングSkillのdisplay letteringで演出する。
8. **技の採用範囲**：P001の量子歩法／P002の共振パンチ・爆風キャンセリングの計3技。原作にある他の3技は今回の2Pへ無理に入れない。
9. **ゴールディは共振パンチを見ていない**。爆風キャンセリング時に迂回通路から到着→主任が**「下がって」**と警告→技を初めて目撃して**「爆風を殴った！？」**と驚く。旧台詞は使わない。**完成画像にP001・P002等のページ管理番号を直接描かない**。画像には確認用のコマ番号も入れない。作業ファイルの名前で管理。
10. 幕間は変更せず、ゴールディの「――って夢を見ましてー」→主任「現実だ」、申請のやりとりで締める。
