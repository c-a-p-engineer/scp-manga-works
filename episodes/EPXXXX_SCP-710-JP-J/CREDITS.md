## 一次原作と照合した6技（原作の名称・意味を維持）

| 名称 | 内容の要約 |
| --- | --- |
| **共振パンチ** | 共振現象で、より硬い物体を破壊する |
| **共振遠当て** | 手を振動させて音波を生じさせ、離れた物体を共振破壊する |
| **テレポ遠当て** | 量子もつれ現象を利用して離れた物体を破壊する |
| **爆風キャンセリング** | 正拳突きの衝撃波の波形を爆風に合わせて衝撃を相殺する |

## この漫画の創作要素と留保
- 原作の研究員の代わりに連載登場人物・**七星**が技を使用し、**ゴールディ**が驚く。
- 七星は喫煙室で一服してから、くわえタバコで緊急迎撃する。シリーズ一般の分煙規則とは別の、ユーザー指定による今回限りの演出。
- 6技の使用順、破壊する敵装備、銃撃／爆発への対応、伝承者との対峙は漫画用の再構成。**原作の実戦記録を逐語的に再現するものではない**。
- 幕間で七星が「職員なら誰でも学べる」と要約するのは会話の脚色。原作のクラス別資料取得・許可制の訓練は変えない。
- 「量子」「共振」等の説明は**架空のジョークSCP内の設定**。現実の科学で武術が可能という主張ではない。
