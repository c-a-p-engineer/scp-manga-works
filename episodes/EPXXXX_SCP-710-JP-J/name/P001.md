# SCPと一服 / SCP-710-JP-J「財団神拳」 — 本編 P001「襲撃」

**状態：文章ネーム改訂草稿 v3／正式話数未定／本編2Pの1P目**  
**読み順：右上→左下（日本式RTL）／台詞は原則縦書き／4コマ構成**  
**登場：七星（主任／セッター）、ゴールディ**

## ページの狙い
一服中の平和→突然の襲撃→普段と変わらない主任→**壁を一切壊さずに通り抜ける「量子歩法！」**。技を増やすより、読み順と現象を一目で理解させる。P001では**量子歩法だけ**を大きく見せ、銃弾回避などは描かない。

## コマ割り：4コマ／均等4段にしない

### 1コマ目 — 上段・余白のある横長大コマ／静かな一服
**画**：研究室に隣接する専用喫煙室。**二人だけ**で一服中。窓越しのデータ解析室には無人の机・モニターがあるだけ。**背景に他の職員、モブ、人影を描かない**。小柄なゴールディはゆるい笑顔・半目、主任は白衣の袖をまくって静かに煙草をくゆらせる。ブランド箱、タバコの商品名、商品ロゴは**一切描かない**。金髪・深紅の目・ミディアムのハーフアップ（ゴールディ）と、大柄・眼鏡・無精髭（主任）は正規キャラクター設定どおり。
**画面内題字**：「SCPと一服」
**画面内サブタイトル**：「SCP-710-JP-J 財団神拳」
**読ませる台詞と位置**：
1. **右側・ゴールディ**「一服してる時が、一番平和ですねぇ」
2. **左側・主任**「仕事の合間だからな」
**設計意図**：ゴールディ→主任の順に**右から左**へ視線が流れるよう、人物と吹き出しの位置を決める。ここではあえて台詞2本に圧縮。

### 2コマ目 — 中段右・細長い警報コマ／静寂を断つ
**画**：赤い警告灯、放送スピーカーとゴールディの目元。赤色で警報の印象を作る。ゴールディの口を大きく開けたリアクションはこのコマに限定。
**SFX**「ビーッ　ビーッ」
**警報放送（右側・先に読む）**「カオス・インサージェンシーの襲撃を確認」
**ゴールディ（左側・後に読む）**「えっ、襲撃！？」
**設計意図**：警報の内容を読んでからゴールディの驚きへ。敵組織の説明は追加しない。

### 3コマ目 — 中段左・主任が動き出す斜め構図／出動
**画**：主任は迷いなく喫煙室から廊下へ出て、**廊下の曲がり角ではなく壁へ**向かう。慌てるゴールディは後方から追う。主任は同じ一本の点火済み煙草を口にくわえたまま。
**ゴールディ（右上・先に読む）**「主任、警備を――」
**主任（左下・後に読む）**「不要だ」
**設計意図**：**「警備を――」→「不要だ」**を確実にこの順で読ませる。「不要！？」の追い台詞は削り、次コマへの助走にする。二人が壁へ向かう動線を画面右→左へ通す。

### 4コマ目 — 下段・ページ最大の横長／量子歩法！
**画**：**ゴールディが画面右側に取り残され、主任は右から左へ壁へ向かう。**主任の上半身の一部が壁の向こう側へ連続して透け、足取りは自然。顔と眼鏡・くわえタバコを明瞭に残す。壁は**完全に無傷**。ひび割れ、破片、穴、粉塵、瓦礫、爆発は禁止。透過の軌跡は控えめな薄い屈折／残像のみ。ゴールディは駆け寄り、手を伸ばす。
**ゴールディ（画面右上・先に読む）**「主任！ そっちは壁！」
**主任（画面左寄り・後に読む巨大な技名）**「量子歩法！」
**技の小解説（画面下・読順の最後、余白に収める）**「量子歩法：特殊な歩き方で壁をすり抜ける。」
**読み順の最重要ロック**：右上の叫び→左側の巨大な技名→壁抜けの接触面へ。技名が叫びより先に目に入る配置は禁止。巨大文字で壁と身体の接触面、眼鏡、煙草を覆わない。
**ページ終端**：主任だけ壁の向こうへ消え、ゴールディは通れない。次ページで主任が先に迎撃し、ゴールディは**別の通常の通路／扉から遅れて到着**する。

## 作画・連続性のチェック
- タイトル・サブタイトルは1コマ目に。制作メモやコマ番号は描画しない。
- ゴールディ：**肩にかかる程度の金髪ミディアム／ハーフアップ**。長い腰髪や金髪ロングウェーブにしない。表情を「弛緩→目を見開く→慌てる→驚愕」で変化させる。
- 主任：40代前半、190cm／約100kg、熊のような厚い骨格、黒縁スクエア眼鏡、短い無精髭、袖をまくった白衣と緩いネクタイ。小柄なゴールディとの**約40cmの身長差**を保持する。
- **ブランド名・箱・ロゴは画面に出さない**。煙草の所作のみを見せる。緊急戦闘でくわえタバコが続くのは今回の固有演出であり、通常の区画規則は変更しない。
- 喫煙室の窓外には**空室の解析機器だけ**。その他の研究員は描かない。
- ゴールディが壁を抜けたように見える描写は禁止。
- 技を削ったのは**読ませるための今回の意図的な再構成**。原作の他技を否定する意味ではない。
