# SCPと一服 / SCP-710-JP-J「財団神拳」 — 本編 P001「襲撃」

**状態：文章ネーム草稿／正式話数未定／全2P本編の1ページ目**  
**読む順：右上→左下・右→左（RTL）／日本語セリフは縦書き**  
**登場：七星（セッター）、ゴールディ（バット）**

## ページの役割

平穏な研究室の仕事と一服から、カオス・インサージェンシー襲撃によって状況が一変する。七星が煙草をくわえたまま、何の迷いもなく**壁をすり抜ける**のが最大の見せ場。ゴールディは初見読者と同じ目線。

## コマ構成：4コマ

### 1コマ目 — 上段横長／喫煙室、平和な仕事の合間

**画**：研究室に隣接する専用喫煙室。ガラス越しに普段どおりの解析室・整然とした端末群が見える。仕事の区切りで一服する二人。190cm・100kgの熊のような七星は壁にもたれ、使い込んだ金属ライターをしまい、**点火済みのセブンスターを口にくわえている**。小柄なゴールディも自身のゴールデンバットで一服し、気の抜けた表情。序盤は日常の柔らかな明暗で。

**画面内題字（描画する）**：「SCPと一服」  
**題材サブタイトル（描画する）**：「SCP-710-JP-J 財団神拳」

**ゴールディ（のんびり）**「やっぱり一服してる時間が一番平和ですねぇ」
**七星（淡々と）**「だから仕事の合間に吸うんだ」
**ゴールディ（ぼそり）**「ずっと合間なら最高なんですけど」

**演出**：七星の煙草は以後の全場面でも**同一の1本**として連続。研究室内部での喫煙は描かない。

### 2コマ目 — 中段右／警報

**画**：喫煙室と通路に赤い回転警報灯。室内放送に合わせ、二人の表情に赤い光が差す。静けさを突然断ち切る。

**SFX（大きめ）**：「ビーッ　ビーッ」
**警報放送**「警報、警報。カオス・インサージェンシーの襲撃を確認」
**ゴールディ（驚き）**「えっ、襲撃！？」

**演出**：説明は放送だけ。カオス・インサージェンシーの複雑な由来は本編で講義しない。

### 3コマ目 — 中段左／七星、動く

**画**：七星が立ち上がり、迷わず正面の壁へ向かう。大きな白衣の背中とくわえタバコ。ゴールディは慌てて椅子から立ち、後を追う。

**ゴールディ**「主任、警備を――」
**七星（短く）**「不要だ」
**ゴールディ**「不要！？」

**演出**：七星の動線がそのまま下の大ゴマの壁へ続く。七星の白衣・眼鏡・無精髭・緩いネクタイは固定。

### 4コマ目 — 最下段・ページ最大／量子歩法！

**画**：**壁へ突っ込む七星の半身が、固体の壁に沈み込む瞬間**。壁は割れず穴も開かない。七星はくわえタバコのまま落ち着いた真顔。煙が後ろへ流れる。後方のゴールディが片手を伸ばし、振り切られながら叫ぶ。速い動線＋壁の断面・透過表現を明確に。

**ゴールディ（大声）**「主任！ そっちは壁！」
**七星（必殺技コール・特大描き文字）**「量子歩法！」

**小解説（可視・短く）**「量子歩法：トンネル効果で壁を通り抜ける財団神拳の技。」

**配置ロック**：「主任！ そっちは壁！」→**「量子歩法！」の巨大文字**→壁抜けの視覚結果の順。巨大文字は七星の顔や壁との接触点を隠さない。完成原稿にコマ番号・制作用語は出さない。

**ページ終端**：壁の向こうへ消えてゆく七星、追うゴールディ。P002の敵との遭遇へ続ける。

## P002への継続

- 七星がくわえる**同一の点火済みの1本の煙草**。戦いながら落としたり増えたりしない。
- ゴールディは通常の追跡手段で追う。壁をすり抜ける能力はまだない。
- キャラクターの基準画像は `characters/CHAR-001_BAT.md` と `characters/CHAR-002_SETTER.md`。
- 通常の財団の喫煙区画規則からの意図的な逸脱は**この緊急アクション演出限定**。恒久設定は変更しない。
