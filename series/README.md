# 連載設定（構想中）

## 作品の核

**財団内で「ヤニカスSCP研究室」と呼ばれる、実力はあるが揃いも揃って重度の喫煙者たちを描く連作1P漫画。**

- 形式：原則**1話1P**。毎話1つのSCPと向き合いながら、固定キャストの仕事・関係・成長を積み重ねる
- トーン：不条理コメディを主軸に、SCPごとにホラー、シリアス、感動も展開できる
- 場所：財団の研究室を拠点とする**独自の非公式シリーズ設定**
- 研究室の**通称**：「ヤニカスSCP研究室」（方向性として採用）。公的な部署名・施設名・配属Siteは未定

## メンバーの役割

| 呼称 | 役割 | 基本的な動機 |
| --- | --- | --- |
| **バット** | 金髪赤目の若手天才研究員／主人公 | 怠惰でいるため勤勉に働き、喫煙できる生活を確保する |
| **セッター** | 無精髭・眼鏡・くわえタバコの主任研究員 | 激務をこなしながら、出世より喫煙環境を優先する |
| **峰** | 美貌と実力を兼ねた40歳前後のエージェント | 任務の禁煙から解放され、居心地の良い拠点に戻りたい |

人物の名前・年齢・外見などの確定と仮案は [登場人物一覧](../characters/README.md) を正本にする。

## 研究室の仕組み（独自設定・詳細未確定）

ここは**タバコを吸いたいから集まった部署**というより、優秀だが煙草好きな職員が結果的に集まった研究室。

財団は3人の成果を高く評価している一方、扱うオブジェクトや任務では喫煙条件を厳しく制限することがある。研究者たちの「喫煙できる環境への執着」と「現場・収容手順上の制約」が毎話の小さな衝突を生む。

- 指定喫煙可能区画と実験・収容区画は区別する。財団の安全措置・SCPの収容手順が最優先
- 財団や警備担当の管理を無視してSCPのすぐそばで自由に喫煙できる設定にはしない
- 研究室には煙草由来の匂い、灰皿、使い込んだ換気設備などの生活感がある（適切な区画内）
- 毎話の題材となるSCPは原作条件を確認し、必要なら施設移動・資料解析・出張任務で遭遇理由を作る

## 連載上の人物変化（案）

1. **導入**：吸えるという条件に釣られて来たバットが、財団の仕事の面倒さに直面する
2. **定着**：セッターと峰の専門性を知り、いつもの研究室が居場所になっていく
3. **衝突**：効率・安全・収容方針・喫煙へのこだわりが衝突する
4. **変化**：怠惰のために働くはずのバットが、仲間や異常存在のため自発的に働くときが来る

## 制作・世界観の基本方針

- オリジナルの固定職員と人間関係は本シリーズ固有の設定。SCPは個別原作の異常性を尊重する
- 各話を単体のギャグ・ホラーとして楽しめる形にしながら、長く読むと関係性の変化が見える
- 原作の記述と漫画独自の創作を区別する
- 「普通の研究者としての有能さ」と「生活面のだらしなさ」の両方を描く
- 現実の禁煙・喫煙規制と架空の財団内ルールを混同しない
