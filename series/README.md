# 連載設定（構想中）

## 作品の核

**SCP財団に配属された新人研究員が、異常存在との出会いを通じて成長していく1P連作漫画。**

単なるSCP紹介だけでなく、登場人物の仕事、人間関係、小さな変化を話数間で引き継ぐ。各話単独でも読めるようにしながら、通して読むと主人公の変化が分かるようにする。

## 基本方針

- 当面は**1話1ページ**。必要があれば複数ページも可。
- ジャンルは日常、コメディ、恐怖、感動など、扱うSCPごとに変えてよい。
- 財団職員は継続キャラクター、SCPは原作の設定を尊重したゲストとして扱う。
- 個々のSCPは「原作の事実」と「漫画独自の演出」を分け、原作を確認してから最終稿にする。
- 公式のSCP世界観に単一の正史があると決めつけず、**本シリーズ固有の連続性**を管理する。

## 主人公の成長案（未確定）

1. 新人期：好奇心と恐怖。
2. 理解期：SCPは一様に危険なだけではないと知る。
3. 葛藤期：収容と個別の存在への配慮の間で考える。
4. 転機：後輩へ知識と責任を引き継ぐ。

## 継続性メモ

- 人物の正式な名前・髪型・服装などは [characters/README.md](../characters/README.md) で決める。未承認設定を勝手に確定させない。
- 話数と公開状況は [エピソード一覧](../episodes/README.md) を参照する。
- 別SiteのSCPを扱う場合は、出張、資料閲覧など出会える理由を設計する。
