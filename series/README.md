# 連載設定 — SCP財団 ヤニカス研究室

**サブタイトル：SCPと一服**

> SCPを題材とする非公式の連作漫画。作品タイトル・副題は確定。財団内の正式な部署名は未設定。

## 作品の核

**SCPの解析では極めて優秀だが、全員どうしようもない愛煙家。**

- **形式**：原則1話1P。ただし第1話「新人歓迎」（SCP-403）は2P。毎話SCPを題材にしながら、固定キャストの仕事と関係を積み上げる。
- **トーン**：職場・日常の不条理コメディが主軸。SCPごとにホラー、シリアス、感動も扱える。
- **舞台**：日本国内にある財団の小規模研究室。職員間で「ヤニカス研究室」と呼ばれる。
- **位置づけ**：通称の「ヤニカス研究室」と、作品タイトル「SCP財団 ヤニカス研究室」は区別する。正式な組織名・配属Siteは未定。

## 研究分野・設備

主な専門は**SCP関連データの収集・解析と異常性の研究**。既存の研究資料、観測記録、映像・音声、センサー値、現場の証言等を突き合わせ、異常な規則性の発見、仮説の構築・検証、収容手順への提案を行う。

- 大規模な実験室や独自のSCP収容施設は**基本的に持たない**。解析用の計算機・端末・データ保管設備が中心。
- SCPの種類・専門領域をさらに限定せず、財団内の案件を幅広く扱える。
- 追加実験が必要な場合は他部署の設備と手順を利用する。
- 現地でしか得られない情報はフィールド調査で集める。**必要なら七星とゴールディ自身も現地へ赴く**。

### 喫煙・清潔管理

- 研究室の**隣に専用喫煙室**が設置され、研究区画と喫煙区画は分離される。
- **研究室への出入口にエアシャワー**がある。
- 白衣など研究用の衣類は、洗浄・交換等で**常に清潔に保たれる**。エアシャワーだけで臭気や汚染物がすべて除去できるとは扱わない。
- 灰皿・煙・灰等を解析設備や研究室へ持ち込まない。喫煙室と収容・実験区画は別。
- 財団の安全手順・各SCPの収容規則を最優先し、禁煙区域で自由に吸えるわけではない。

## 3人の役割

| 人物 | 立場・担当 | 行動原理 |
| --- | --- | --- |
| **ゴールディ（バット）** | 財団にスカウトされた新人研究員。七星の研究室へ配属され、SCPデータ解析・異常な規則性の発見・処理自動化を担う | 楽をするためには徹底的に勤勉。**タバコを吸える環境**を採用条件にした |
| **七星（セッター）** | 研究室主任。研究課題の設定、結果の検証、研究の統括、他部署との調整を担う | 責任感が強く仕事を抱え込みがち。出世より現場と居場所を優先 |
| **峰（ミネ）** | **研究室所属ではない**財団フィールドエージェント。潜入・聞き込み・観察・現地記録など、解析に必要なデータを収集する | 荒事は原則避ける凄腕調査員。喫煙仲間として研究室との行き来が多い |

- **ゴールディの入職**：財団が才能を見込んでスカウト。本人は喫煙環境を条件に入職し、七星の研究室へ配属。喫煙は指定区画内に限る。
- **峰の位置づけ**：外部の現場情報を研究室へ持ち込む協力者。七星とは以前から仕事の関係があり、研究室と気が合うため頻繁に顔を出す。
- **峰の任務選択**：**喫煙できない任務は原則、受任前に断る**。一度引き受けた任務では禁煙・収容上の規則に従う。

個別の外見、名前、職務上の性格は[キャラクター一覧](../characters/README.md)と各Character Sheetを正本とする。

## 研究の基本的な流れ（例）

1. 財団内の記録・観測データや研究依頼を受け取る。
2. ゴールディが解析し、七星が研究方針・仮説・必要情報を整理する。
3. 足りない情報を峰が現地収集する。必要なら研究員も現場へ向かう。既存データのみで完結する回もある。
4. 再解析・検証後、研究報告と収容手順等への**提案**をまとめる。

毎話この順番に限定せず、SCP原作の性質に応じて組み立てる。

## 財団内の権限（詳細未決定）

特別な万能権限を持つ研究室ではない。承認済みの資料を解析し、必要な調査・実験を関係部署に相談・申請する。各SCPの収容管理や現場指揮は関係部署の権限に従い、収容手順を独断変更しない。

**正式部署名・Site番号・クリアランス・具体的な権限・研究室設立の経緯は未設定**。必要なエピソードで整合的に決める。

## 連載上の人物変化（案）

1. **導入**：吸えるという条件に釣られて来たゴールディが、財団の仕事の面倒さに直面する。
2. **定着**：七星と峰の専門性を知り、いつもの研究室が居場所になっていく。
3. **衝突**：効率・安全・収容方針・喫煙へのこだわりが衝突する。
4. **変化**：怠惰のために働くはずのゴールディが、仲間や異常存在のため自発的に働くときが来る。

## 制作・世界観の基本方針

- オリジナル職員や小規模研究室はこの非公式シリーズ固有の設定。各SCPの原作条件・観測可能な性質・収容手順を尊重する。
- タバコを毎回オチにする必要はなく、研究・調査の有能さと喫煙への執着の落差を活用する。
- SCPが直接現れず、記録やデータの異常だけで成立する回もある。
- 現実の喫煙の健康影響を否定せず、喫煙可能区域と実験・収容区域を混同しない。
