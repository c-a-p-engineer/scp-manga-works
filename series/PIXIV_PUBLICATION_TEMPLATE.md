# 「SCPと一服」制作・pixiv公開テンプレート

> 出典：[EP001「新人歓迎／SCP-403」公開記録](../episodes/EP001_SCP-403/PUBLICATION.md)。
> 本テンプレートは**画作りと公開記録の再利用可能な参考事例**。題材・ページ数・コマ割り・オチは毎回最適化する。彩色のみ、以下の「シリーズ標準彩色」を既定とし、各話の演出に応じた意図的な例外を認める。

## 作品の魅力

一服のお供に、SCPをひとつ。財団でも一流の研究・調査能力を持つ愛煙家たちが、摩訶不思議なSCPの異常性を調べる中で繰り広げる**職場の掛け合い・不条理・意外な発見**を描く非公式漫画。基本は短く、SCPの個性によってコメディ、ホラー、感動などのトーンを選ぶ。

## シリーズ標準彩色（2026-10-12 採用）

第2話 SCP-4999 の試作 P001・P002 で採用を決めた**塗りと陰影の方向性**。これは作品全体の既定パレットであり、**試作画像の顔・髪型・体型・服装・構図を正本として採用するものではない**。

- **ベース**：低彩度のモノクロ／グレースケール主体。白・黒に加え、中間調を豊かに使い、全体にごく弱い暖かみを残す。彩度の高いフルカラーを既定にしない。
- **塗り**：アニメ／漫画らしい明瞭な輪郭線に、滑らかな濃淡、柔らかい落ち影、繊細なスクリーントーンを重ねる。フォトリアルな肌や過剰なテクスチャで人物像を変えない。
- **人物**：肌・髪・衣装にはグレーの階調で立体感を付ける。瞳など人物同一性に重要な色（新人の深紅など）は、基準設定と矛盾しない範囲で低彩度の微かな色味を残してよい。**色味を落とすことと、髪型・瞳色・性別・年齢印象・体格・衣装の変更は別問題**。
- **背景**：通常の解析研究室は明瞭な線と柔らかい階調。監視カメラ映像・資料・異常な事象には、必要に応じて粒子、ノイズ、強い黒、コントラスト差を使って画面の出所を区別する。
- **スポットカラー**：SCPの異常性・危険・感情に意味がある場合は、赤／橙などを限定的に使える。目立たせること自体を目的に無関係な色を増やさない。
- **例外**：公開済みEP001の異常発火に用いた赤・橙はそのまま維持する。ホラー、感動、別の異常性などで標準から外す場合は、各話の演出意図に明記すればよい。

### 生成時の優先順位と受入

1. **キャラクター同一性**：`characters/CHAR-001_BAT.md`、`CHAR-002_SETTER.md`、`CHAR-003_MINE.md` と各採用・参照PNGの実体が優先。試作ページの人物描写は、色塗り以外の模写元にしない。
2. **コマ・文字・意味**：各話ネーム、Studio の実際の Clean／生成用Packageに従う。彩色スタイルはコマ順・画角・吹き出し内容・衣装・顔を上書きしない。
3. **塗りの受入**：完成候補を、低彩度グレー基調・柔らかな陰影・必要なスポットカラー・背景の読みやすさの観点で確認する。人物同一性は別に、正規参照PNGとコマごとに照合する。
4. **承認済み画像との境界**：SCP-4999の今回の生成画像は「塗りの方向性」だけが採用対象。キャラずれ等が残るため、完成原稿／新しいキャラクター基準画像としては自動採用しない。

## 演出・表現の引き継ぎ方

| 項目 | EP001で効いた表現 | 次回の考え方 |
| --- | --- | --- |
| 人物導入 | セッター190cm・ゴールディ150cmの大きな身長差と一言「でっか…」 | キャラの違いを**説明より構図**で見せる |
| 色 | モノクロ基調、異常発火だけ赤・橙に彩色 | **上記「シリーズ標準彩色」**を既定とする。低彩度グレー＋柔らかな陰影を基本にし、異常性や感情に意味がある箇所のみ限定的な色を選ぶ |
| リズム | 平凡な一服→炎の突然の変化→驚き→ブラックコメディ | 普通状態・条件変化・結果を因果順に見せる。毎回喫煙をオチにしない |
| 文字 | 日本漫画のRTL、縦書きの吹き出し、音を強調する効果音 | 吹き出しの読み順、正確な固有名詞、コマでの分かりやすさを検査 |
| SCPの紹介 | P001の題字・SCP番号、P002終端の解説 | 読みの邪魔にならずネタバレを損なわない位置に配置。省略も可 |
| 連続性 | キャラクター参照PNGと各話内の姿勢・道具を分ける | Character Sheetは**人物identity**、Cleanは**コマ割り**、正規ネームは**演出意図** |
| ボリューム | 初回は2P | 基本1P、必要なら2P以上。演出に合わせる |

### 漫画制作のチェックポイント

1. SCPの記事を**原文と必要なら日本語訳**で読み、異常性の発動条件・収容規則・原作者を確認。原作との違いは意図した脚色として明示。
2. 文章ネーム→Studioの現行手順に従いBlueprintコンパイル。日本式の**右上から左下の読み順・縦書き**を検証。
3. 実際のCharacter Sheet画像をモデルに渡す。**URLを置くだけでは人物identity参照にはならない**。
4. 作画後はページ単位で人物同一性、SCPの異常性、台詞の誤字、手・小物・火と煙の位置、コマ順を検証。
5. 採用したPxxx.pngのみ、各話の `images/final/` に保存。未採用は `images/drafts/` に隔離。
6. 公開してから `PUBLICATION.md`、`episodes/README.md`、`CREDITS.md` を更新。未検証の公開設定やタグを事実として記録しない。
